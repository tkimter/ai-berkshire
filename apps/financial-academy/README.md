# 복리학당 · 한 회사를 제대로 읽기

기업 연구를 위한 한국어 인터랙티브 실적 읽기 강의다. 개념을 읽고, 변수를 바꿔 실험하고, 장별 연습을 마친 뒤, 마지막에 종합 시험을 통과한다.

원본 저장소(`xbtlin/ai-berkshire`)의 중국어 강의를 한국어로 옮긴 것이다. 원저자가 운영하는 온라인 사이트와는 별개이며, 이 폴더의 소스를 로컬에서 실행해 쓴다.

## 강의와 수료 조건

- 12개 장, 개념 72개: 재무제표 지도, 손익계산서, 재무상태표, 현금흐름, 이익의 질, 운전자본, ROE/ROIC, 부채, 주당 가치, 주석과 감사, 산업별 읽기, 밸류에이션.
- 장별 문제 48개, 수료 문제 24개. 수치 계산, 상황 판단, 문제별 해설을 포함한다.
- 인터랙티브 실험 3개: 이익과 현금, 듀폰 ROE, 성장과 밸류에이션.
- 틀린 문제는 자동으로 모이고, 다시 풀어 맞히면 복습 목록에서 빠진다. 공식 빠른 찾기, 공식 자료 링크, 수료 기록 인쇄를 제공한다.
- 장의 개념을 모두 학습해야 관문에 도전할 수 있고, 장마다 **3/4** 이상 맞혀야 한다. 12개 장을 모두 통과하면 수료 시험이 열린다.
- 수료하려면 **21/24** 이상 맞히고 **핵심 리스크 문제 4개를 모두 맞혀야** 한다. 오답 복습은 정식 수료 시험을 대신하지 않는다.

장 읽기는 이해를 확인하는 것이 기준이며 카운트다운이 없다. 시험은 시간 제한이 없고, 계산기를 쓸 수 있으며, 복습 뒤 재응시할 수 있다. 개인 학습 수료 기록일 뿐 직업 자격 인증이 아니다.

## 로컬 실행

Node.js **22.13.0 이상**과 npm이 필요하다. 저장소 루트에서 실행한다.

```bash
cd apps/financial-academy
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_silly_power_pack.sql
npm run dev
```

터미널에 표시되는 주소로 접속한다. 기본 로컬 개발 주소는 `http://localhost:5173`이다. 처음 실행할 때는 위의 로컬 데이터베이스 마이그레이션을 적용해야 하고, 그 뒤에는 같은 마이그레이션을 다시 실행하지 않는다.

깨끗한 클론은 기본적으로 portable 개발 설정을 쓴다. 로컬 루프백 주소의 개발 서버에서만 "로그인"을 누르면 템플릿이 제공하는 로컬 모의 신원을 쓴다. 로컬 D1 데이터는 `.wrangler/`에 저장된다. 온라인 데이터베이스에 연결하지 않으며, 온라인 계정 동기화를 검증했다는 뜻도 아니다.

```bash
npm test
npm run typecheck
npm run build
```

`npm test`는 문제 은행 구조, 장과 수료 점수의 경계, 핵심 문제 거부, 수치 입력, 답 숨김, 오답의 생애 주기, 수료 상태를 검사한다. `npm start`는 빌드한 Worker를 미리 보지만 ChatGPT 로그인을 모사하지 않는다. 모의 신원이 필요하면 `npm run dev`를 쓴다.

## 배포와 계정 진도

이 앱은 **Vinext / React + Cloudflare Worker + D1** 애플리케이션이다. GitHub Pages로 바로 호스팅할 수 있는 순수 정적 웹페이지가 아니다. GitHub Pages는 `/api/progress`를 실행하거나 계정 진도를 저장할 수 없다.

- `.openai/hosting.json`은 `DB` 바인딩을 유지하며, 원본 사이트의 계정 전용 `project_id`는 제거돼 있다.
- Sites에서 새 사이트를 만들 때는 새 사이트가 돌려주는 ID에 바인딩한다. 데이터베이스 마이그레이션은 소스와 함께 제공한다. 기존 사이트를 갱신할 때는 그 사이트 자신의 ID를 쓴다.
- 운영 환경은 신뢰할 수 있는 Sites 진입점이 주입하는 신원 정보에 의존하고, API는 현재 사용자별로 읽기와 쓰기를 격리한다. 다른 환경에 직접 배포할 때는 반드시 믿을 수 있는 인증을 연결하고 이 신원 헤더를 보호해야 한다. 클라이언트가 보낸 신원 헤더를 그대로 믿으면 안 된다.
- 이 저장소에는 학습 기록, 데이터베이스 파일, 환경 비밀값, 배포 자격 증명이 없다. 소스를 복사해도 기존 사이트의 학습 진도는 옮겨지지 않는다.
- GitHub에 푸시해도 배포된 사이트는 자동으로 갱신되지 않는다. 강의나 코드를 고친 뒤에는 따로 빌드해 배포해야 한다.

## 콘텐츠 유지보수

문제를 추가하거나 고칠 때는 문제 ID를 안정적으로 유지한다. 강의 구조, 문제 수, 통과 기준을 바꾸면 화면 문구, 채점 로직, 테스트를 함께 고쳐야 한다. 기존 학습 기록은 ID로 연결되므로, 의미를 바꿀 때는 명확한 버전 마이그레이션을 설계한다.

`lib/curriculum.json`의 `stage` 값(`기초`/`심화`/`실전`)은 `app/academy.tsx`의 필터와 `app/globals.css`의 `.stage-*` 클래스가 그대로 쓴다. 이 값을 바꾸면 세 곳을 함께 바꾼다.

모든 계산 사례는 학습용 가정이며 통화 단위는 위안이다. 텐센트, 콰이쇼우, 핀둬둬, 메이퇀, 팝마트, 마오타이, Google, JD헬스, 모던덴탈은 읽기 문제를 설명하려고 쓴 것이며, 강의가 이들의 최신 실적을 공시한다는 뜻이 아니다. 회계기준, 기간, 통화, 귀속 기준은 각각 확인해야 한다. 이 프로젝트는 학습과 연구용이다.
