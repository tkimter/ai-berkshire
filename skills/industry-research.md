# 산업 투자 연구: 산업 체인 전경 스캔 + 4대 거장 개별 종목 분석 프레임워크

$ARGUMENTS 산업에 대해 체계적인 산업 체인 투자 연구를 수행한다.

## 연구 목표

하나의 투자 테마/논리 사슬에서 출발해 다음을 완수한다:
1. 투자 논리 사슬의 고리를 하나하나 검증한다
2. 완전한 산업 체인 전경도를 그린다
3. 전 세계 모든 상장사를 스캔한다(A주/홍콩 주식/미국 주식/국제)
4. 세부 고리마다 선두 회사에 4대 거장 프레임워크 분석을 수행한다
5. 산업 차원의 포트폴리오 배분 제안을 출력한다

---

## 1단계: 투자 논리 사슬 구축과 검증

### 1.1 논리 사슬을 그린다
"기저 추세"에서 "수혜 종목"까지의 인과 관계를 화살표 사슬로 표현한다. 예:
```
기저 추세 A
    → 수요 B를 유발
        → 병목/필수 수요 C를 창출
            → 수혜 산업 체인 D
```

### 1.2 고리별 검증
논리 사슬의 화살표마다 의문을 제기하고 증거를 찾는다:

| 고리 | 핵심 가정 | 검증 방식 | 데이터 출처 |
|------|---------|---------|---------|
| A→B | | 산업 데이터/전망 검색 | |
| B→C | | 수급 분석 검색 | |
| C→D | | 실제 사례/계약 체결 검색 | |

### 1.3 "이미 일어난 검증 사건"을 찾는다
이 논리 사슬을 뒷받침하는 **이미 계약됐거나 이미 실현된 실제 상업적 사건**(전망이 아닌 것)을 나열한다. 예: 대기업의 구매 계약, 정책 문서, 산업 보고서 등.

---

## 2단계: 산업 체인 전경도 작성

### 2.1 산업 체인 구조를 그린다
산업을 업스트림→미드스트림→다운스트림→보조 고리로 분해한다. 예:
```
업스트림: 원자재/자원 채굴 → 소재 가공/정제
미드스트림: 핵심 설비 제조 → 시스템 통합/엔지니어링 건설 → 신기술 연구개발
다운스트림: 운영/서비스 → 최종 고객
보조: 검사/인증 → 유지보수 서비스 → 금융 수단(ETF/신탁)
```

### 2.2 고리마다 "사업 특성"을 식별한다
고리마다 다음을 표기한다:

| 고리 | 비즈니스 모델 | 매출총이익률 구간 | 경쟁 구도 | 장벽 유형 | 경기 민감도 |
|------|---------|-----------|---------|---------|--------|
| | 자원 판매/설비 판매/서비스 판매/임대료 수취 | | 독점/과점/완전 경쟁 | 자원/인허가/기술/규모 | 강/중/약 |

### 2.3 "목줄을 쥔 병목 고리"를 표시한다
산업 체인에서 공급이 가장 빠듯하고, 대체가 가장 어렵고, 이익률이 가장 높은 고리를 식별한다 — 최고의 투자 대상은 흔히 여기에 있다.

## AI 리서치 편향 자각: 산업 연구의 특수한 함정

산업 연구에서는 AI 데이터 편향이 독특한 방식으로 증폭된다:

**산업 차원의 편향**:
| 편향 유형 | 양상 | 대응 |
|---------|------|------|
| 성숙 산업 선호 | 전통 산업(은행/에너지/소비재)은 자료가 극히 많아 AI 분석이 "더 확실해" 보인다 | 확실성은 비즈니스 모델에서 나오지 리서치 보고서 수에서 나오지 않는다 |
| 신흥 산업 저평가 | 신산업(AI 응용/합성생물학 등)은 자료가 적어 AI 분석이 보수적으로 치우친다 | "현재 데이터"가 아니라 "종국적 사고"로 산업 가치를 판단한다 |
| 선두 기업 선호 | 대기업 자료가 소기업보다 훨씬 많아 AI는 태생적으로 선두 기업을 추천하는 경향이 있다 | 소기업의 위험 대비 수익이 더 좋을 수 있다. AI 분석 분량이 짧다고 무시하지 않는다 |
| 상장사 선호 | 상장사만 스캔하면 산업 체인의 핵심 비상장 플레이어를 놓친다 | 비상장 회사를 반드시 검색하고 "향후 IPO 후보"로 표기한다 |
| 영어 선호 | AI는 영어 자료 처리 능력이 더 강해 중국/아시아 시장 플레이어를 저평가할 수 있다 | 반드시 중국어와 영어 정보원을 함께 검색한다 |

**산업 체인 스캔에서의 편향 방지 조치**:
1. 고리마다 "AI가 쉽게 찾는 회사"만 나열하지 말고 "비인기지만 우량할 수 있는 종목"을 능동적으로 검색한다
2. 정보가 희소한 소형주에 대해 분석 분량이 짧다는 이유로 추천도를 낮추지 않는다 — 보고서 길이가 아니라 핵심 질문(사업의 본질, 해자, 경영진)으로 평가한다
3. 최종 보고서에 회사별 "정보 충분도"(A/B/C급)를 표기해 독자가 AI 분석의 신뢰 수준을 알 수 있게 한다

## 3단계: 글로벌 상장사 스캔

Task 도구로 백그라운드 Agent를 띄워 이 산업의 모든 상장사를 전면 검색한다.

### 검색 목록
- 미국 주식(NYSE/NASDAQ/NYSE American) 관련 회사
- A주(상하이/선전) 관련 회사
- 홍콩 주식 관련 회사
- 기타 국제 시장(일본/한국/유럽/호주 등)
- 산업 ETF
- 핵심 비상장 회사(향후 IPO 가능)

### 회사마다 수집할 것
- 회사명(중국어·영어)
- 종목 코드와 거래소
- 시가총액(근사치)
- 한 문장 설명(산업 체인에서의 위치와 역할)
- 순수 종목 여부(순수 원전 vs 다각화 사업 중 원전 사업 보유)
- 산업 체인 소속 고리

### 출력 형식
산업 체인 고리별로 분류하고, 고리마다 표 하나에 스캔된 모든 회사를 담는다.
이어서 투자 확실성에 따라 계층을 나눈다:
- **Tier 1**: 대형주, 순수 종목, 산업 선두
- **Tier 2**: 중형주, 순수 또는 높은 비중, 세부 분야 선두
- **Tier 3**: 소형주, 개발 단계, 고위험·고탄력
- **Tier 4**: 다각화 회사 가운데 관련 사업을 가진 대형 기업

---

## 4단계: 고리별 선두 회사 4대 거장 분석

산업 체인 고리마다 **Tier 1과 Tier 2 회사**에 아래 분석을 수행한다(Tier 3/4 회사는 간략한 논평으로 충분하다):

### 4.1 사업의 본질(돤융핑)
- 이 회사가 산업 체인에서 무엇을 하는지 한 문장으로 정의한다
- 매출 구조와 증가율
- 매출총이익률/순이익률 수준과 추세
- 현금흐름 특성
- **추궁**: 이것은 좋은 사업인가? 왜 그런가?

### 4.2 해자(버핏)
다섯 가지 해자로 평가한다(★1-5):

| 해자 | 강도 | 증거 |
|--------|------|------|
| 브랜드/가격 결정력 | | |
| 전환 비용 | | |
| 네트워크 효과 | | |
| 규모 효과 | | |
| 기술/인허가 장벽 | | |

**추궁**: 10년 뒤에도 해자가 남아 있는가?

### 4.3 리스크(멍거)
- 이 회사는 어떻게 실패할 가능성이 가장 큰가?
- 최악의 시나리오에서 얼마의 가치가 있는가?
- 똑똑한 사람들은 왜 사지 않는가?

### 4.4 경영진(돤융핑+버핏)
- CEO/창업자는 누구인가? 핵심 의사결정 기록
- 지분율과 이해관계 정렬
- 간평(A/B/C급)

### 4.5 밸류에이션 스냅샷
- 현재 PE/PS/EV/EBITDA
- 같은 고리의 경쟁사와 비교
- 간평: 비싸다/합리적이다/싸다

### 4.6 추천도
★1-5로 표기한다:
- ★★★★★ = 핵심 포지션 후보
- ★★★★☆ = 위성 포지션 후보
- ★★★☆☆ = 관찰 명단
- ★★☆☆☆ = 고위험 옵션
- ★☆☆☆☆ = 추천하지 않음

## 5단계: 산업 차원의 리스크 평가(멍거의 "체크리스트")

### 5.1 시스템 리스크 목록

| 리스크 | 확률 | 영향 | 대응 전략 |
|------|------|------|---------|
| 투자 논리 사슬의 어느 고리가 반증됨 | | | |
| 대체 기술 출현 | | | |
| 정책/규제 블랙스완 | | | |
| 수요의 경기 순환적 조정 | | | |
| 밸류에이션 거품 붕괴 | | | |

### 5.2 역사적 유추
역사에서 유사한 산업 체인 투자 테마를 찾아 그 최종 결말을 분석한다:
- 유추 대상 산업은 무엇인가?
- 최종 승자는 누구였는가?(업스트림/미드스트림/다운스트림?)
- 대다수 투자자는 돈을 벌었는가, 잃었는가?
- 현재 산업에 주는 시사점은 무엇인가?

### 5.3 편향 자가 점검
- 서사 편향: 이야기가 지나치게 완벽하지 않은가?
- 앵커링 효과: 최근 상승폭에 앵커링되지 않았는가?
- 군중 효과: "모두가 사고 있어서"가 아닌가?

## 6단계: 문명 추세 판단(리루 프레임워크)

- 이 산업이 기대는 기저 추세는 "문명 차원의 패러다임 전환"인가, "단계적 열풍"인가?
- 역사에서 가장 가까운 기술 혁명 유추는 무엇인가?
- 10~20년 뒤 이 산업의 종국은 무엇인가?
- 산업 체인에서 "승자 독식"이 나타날 가능성이 가장 큰 고리는 어디인가?
- 전복될 가능성이 가장 큰 고리는 어디인가?

## 7단계: 포트폴리오 배분 제안

### 7.1 추천 포트폴리오
아래 구조로 출력한다:

| 계층 | 비중 | 종목 | 소속 고리 | 핵심 논리 |
|------|---------|------|---------|---------|
| **핵심 포지션** | 테마 비중의 50-60% | | | 가장 확실하고 해자가 가장 넓다 |
| **위성 포지션** | 테마 비중의 25-35% | | | 탄력이 크고 확실성은 다소 낮다 |
| **옵션 포지션** | 테마 비중의 5-15% | | | 고위험·고수익, 0이 될 수 있다 |
| **ETF 대체** | 위 전부를 대체 가능 | | | 종목을 고르기 싫은 사람을 위한 "게으른 방안" |

### 7.2 매수/매도 신호

| 신호 유형 | 구체적 조건 |
|---------|---------|
| 비중 확대 신호 | |
| 비중 축소 신호 | |
| 전량 매도 신호 | |

### 7.3 테마 비중 상한 제안
투자 논리 사슬의 확실성과 위험 정도에 따라 이 테마가 전체 포지션에서 차지할 상한 비율을 제안한다.

## 출력 요건

1. 모든 분석은 데이터로 뒷받침하고 데이터 출처를 붙인다
2. 핵심 데이터는 Markdown 표로 제시한다
3. 산업 체인 전경도는 코드블록의 텍스트 도표로 나타낸다
4. 고리마다 선두 회사를 최소 2~3곳 분석한다
5. 글로벌 회사 스캔은 최대한 빠짐없이 한다(A주/홍콩 주식/미국 주식/국제)
6. 마지막에 전체 보고서를 `~/[산업명]산업체인투자연구보고서.md` 에 저장한다
7. 결론은 명확해야 하며 구체적인 종목, 비중, 가격 구간 제안을 낸다
8. 분석 모듈마다 끝에 해당 거장의 "추궁"을 둔다

## 데이터 표본 점검(출고 승인 절차)

보고서를 저장한 뒤 데이터 표본 점검을 수행하고, 통과해야 발행할 수 있다:

```bash
# Step 1 — 표본 점검 목록 추출(15% 무작위 표본)
python3 tools/report_audit.py extract \
  --report <보고서 파일 경로>

# Step 2 — 목록의 항목마다 신뢰할 수 있는 정보원에서 수치를 가져온다(skills/financial-data.md 참고)

# Step 3 — 출고 승인/반려 판정 출력
python3 tools/report_audit.py verdict \
  --results '<작성한 JSON>' \
  --report <보고서 파일명>
```

**【출고 승인】** 전부 통과 → 보고서 발행 가능; **【반려】** 불통과 항목 있음 → 수정 후 재심사.
