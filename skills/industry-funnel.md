# 산업 퍼널 선별: 전체 시장에서 3개사까지 좁히는 가치투자 정선 절차

$ARGUMENTS 산업/방향에 대해 퍼널식 가치투자 선별을 수행한다. 전체 시장 스캔에서 시작해 층마다 걸러 최종 선정 종목 3개사까지 좁힌다.

## 적용 상황

어떤 산업이나 투자 방향(예: "AI 컴퓨팅 파워", "혁신 신약", "로봇")을 말하고, 다음을 원할 때:
1. 중요한 종목을 하나도 빠뜨리지 않는다(A주, 홍콩 주식, 미국 주식, 비상장 후보 포함)
2. 통일된 기준으로 "스토리 주식"과 질이 부족한 회사를 걸러낸다
3. 정말로 심층 연구할 가치가 있는 선두 3개사에 힘을 집중한다
4. 층마다 명확한 유지/탈락 기준이 있어, 복기와 추적이 가능하다

`industry-research` 와의 차이:
- `industry-research` 는 산업 사슬 구조와 전체 그림, 단계별 단면에 무게를 둔다
- `industry-funnel` 은 개별 종목 선별 퍼널에 무게를 두고, 전체 시장에서 층마다 걸러 3개사까지 좁힌다

둘은 서로 보완할 수 있다: 먼저 `industry-research` 로 산업 사슬 구도를 파악하고, 그다음 `industry-funnel` 로 종목을 정선한다.

---

## 퍼널 구조 개관

```
1층: 전체 시장 스캔       30-60개사   (활성도+상승률+시가총액 상위 30의 합집합)
        ↓ 가치투자 5개 필수 지표
2층: 1차 선별            ≤ 10개사   (5개 모두 합격 + 해자 ★★★ 이상)
        ↓ 정밀 분석
3층: 정밀 분석           ≤ 10개사   (회사당 300-500자 구조화 분석)
        ↓ 최종 선정
4층: 4대 거장 심층 분석    3개사     (회사당 800-1200자, 버핏·멍거·돤융핑·리루 4개 관점)
        ↓
출력: 투자 의견 + 실행 신호 + 비중 의견
```

층마다 "걸러진 종목"에는 반드시 탈락 사유를 남긴다. 블랙박스는 안 된다.

## 1단계: 전체 시장 스캔 입구

### 1.1 활성 종목 정의(세 유형의 합집합)

**A 유형 - 거래 활성도**:
- 최근 30일 일평균 거래대금 순위가 산업 내 상위(A주/홍콩 주식/미국 주식 각각 상위 30)

**B 유형 - 상승률 순위**:
- 최근 30일 상승률 상위 20
- 최근 90일 상승률 상위 20
- 둘의 합집합

**C 유형 - 시가총액 기준**:
- 산업 내 시가총액 상위 30(등락 무관)

최종 스캔 풀 = A ∪ B ∪ C, 예상 30-60개사.

### 1.2 반드시 검색해야 하는 시장

| 시장 | 권장 출처 |
|------|---------|
| A주(상하이·선전) | 同花顺/东方财富 업종 섹터, 通达信 |
| 홍콩 주식 | 富途/同花顺 홍콩 주식, HKEX 업종 분류 |
| 미국 주식 | NASDAQ/NYSE 업종 ETF 보유 종목, Yahoo Finance |
| 국제 시장 | 일본·한국·대만·유럽의 관련 회사를 빠뜨리면 안 된다(특히 반도체, 전자) |
| 비상장 회사 | "향후 IPO 후보" 소절을 따로 두고, 최신 기업가치와 잠재 IPO 시점을 밝힌다 |

### 1.3 출력 형식

| 회사명 | 코드 | 시장 | 시가총액 | 주력 사업 한 문장 | 해당 산업 비중 | 선정 유형(A/B/C) |
|-------|------|-----|------|----------|-----------|----------------|

**핵심 자체 점검**:
- 산업 비중 < 30%인 "곁다리 종목"은 신중히 다루고, "순수 종목 아님"이라고 표기한다
- 중국/아시아 시장을 영문 자료가 적다는 이유로 빠뜨리지 않는다
- 소형주를 AI가 선두 기업을 선호한다는 이유로 빠뜨리지 않는다

## 2단계: 가치투자 5개 필수 지표 1차 선별 → ≤ 10개사

1단계의 30-60개사에 대해, 회사마다 5개 필수 지표를 적용한다.

### 2.1 5개 필수 지표

| # | 지표 | 통과 기준 | 완화 조건 | 데이터 출처 |
|---|------|---------|---------|---------|
| 1 | PE 밸류에이션 | 합리적(과거 구간, 동종업계와 비교) | 고성장은 PEG < 1.5까지 완화 가능 | 실적+wind/同花顺 |
| 2 | ROE | > 15% 또는 최근 3년 추세 개선 | 중자산 산업은 완화 가능 | 실적 |
| 3 | 영업현금흐름 | 양수이고 순이익 대비 > 70% | — | 실적 |
| 4 | 부채비율(자산 대비) | < 60% | 공익사업/전력은 70%까지 완화 가능 | 실적 |
| 5 | 해자 간이 평가 | ★★★ 이상 | — | 정성 판단 |

**해자 5유형**:
- 브랜드/가격 결정력
- 전환비용/사용자 충성도
- 네트워크 효과
- 규모의 효과
- 기술/인허가/자원 장벽

### 2.2 출력 형식

| 회사 | PE | ROE | 현금흐름/순이익 | 부채비율 | 해자 | 종합 | 유지/탈락 | 탈락 사유 |
|------|----|----|-----------|-------|-------|------|------|---------|

**유지 규칙**:
- 5개 모두 합격 → 바로 유지
- 4개 합격 + 1개 근접 → 유지하되 노란색으로 표시
- 4개 미만 → 탈락, 사유를 밝힌다

**목표**: ≤ 10개사 유지. 너무 많이 남으면(> 12), 해자 기준을 ★★★★로 올려 한 번 더 거른다.

## 3단계: 정밀 분석(≤ 10개사, 회사당 300-500자)

1차 선별에서 남은 회사에 대해, 회사마다 구조화 분석을 한다.

### 3.1 회사별 분석 템플릿

```
## {회사명}({코드})

**한 문장 비즈니스 모델**:
(무엇을 팔고, 누구에게 팔고, 어떻게 돈을 받는가)

**재무의 질**:
- 매출 성장률 / 이익 성장률 / 매출총이익률 / ROE / 현금흐름
- 핵심 변화(최근 1-2년 가장 중요한 재무 전환점)

**해자의 깊이**:
- 주된 해자 유형 + 구체적 증거
- 해자가 5년 뒤에도 남아 있을지에 대한 간단한 판단

**주요 리스크(상위 3)**:
1.
2.
3.

**밸류에이션 간이 평가**:
- 현재 PE/PS/EV/EBITDA + 과거 구간 내 위치
- 동종업계 비교
- 한 문장 결론: 비쌈 / 합리적 / 쌈

**최종 선정 3개사에 포함?**: 예 / 아니오(사유)
```

### 3.2 최종 선정 3개사의 선택 기준

점수순으로 상위 3개를 뽑는 것이 아니라, "포트폴리오 상호보완성"에 따라 뽑는다:
- "고확실성 저탄력"(버핏형) 최소 1개사
- "중간 확실성 중간 탄력"(성장형) 최소 1개사
- "고탄력 고위험"(옵션형) 1개사는 선택 사항

어떤 세부 분야에서 충분히 좋은 3개사를 찾지 못하면, 머릿수를 채우지 말고 차라리 "최종 선정 2개사 + 관찰 1개사"라고 쓴다.

## 4단계: 4대 거장 심층 분석(3개사, 회사당 800-1200자)

최종 선정 3개사에 대해 4대 거장 관점의 심층 분석을 수행한다.

### 4.1 돤융핑 관점: 사업의 본질

- 이 회사가 어떤 사업을 하는지 한 문장으로 정의한다
- 좋은 사업인가? 왜 그런가?
- 이 회사의 "본분"은 무엇인가? 경영진이 벗어난 적은 없는가?
- 비즈니스 모델의 "지속성"은 어디에 있는가?

### 4.2 버핏 관점: 해자의 깊이

- 다섯 유형의 해자로 평점을 매기고(★1-5), 구체적 증거를 나열한다
- 10년 뒤에도 해자가 남아 있는가?
- 지금 매수할 때의 "안전마진"은 어디에 있는가?

| 해자 | 강도 | 구체적 증거 |
|-------|------|---------|
| 브랜드/가격 결정력 | | |
| 전환비용 | | |
| 네트워크 효과 | | |
| 규모의 효과 | | |
| 기술/인허가 장벽 | | |

### 4.3 멍거 관점: 리스크와 실패 유형

- 이 회사는 어떻게 실패할 가능성이 가장 높은가?(상위 3개 실패 경로를 나열)
- 최악의 시나리오에서 얼마의 가치가 있는가?(초간단 밸류에이션)
- 똑똑한 사람들은 왜 사지 않는가?(역방향 논증)
- 도덕/컴플라이언스/경영진 리스크가 있는가?

### 4.4 리루 관점: 문명 차원의 추세 속 위치

- 이 회사가 속한 분야는 "문명 차원의 패러다임 전환"인가, "한때의 열풍"인가?
- 역사상 가장 가까운 기술혁명의 유사 사례는?
- 10-20년 뒤 이 회사의 최종 국면은?
- 승자독식 구도인가?

### 4.5 종합 추천도

```
추천도: ★★★★☆
포지션 유형: 핵심 / 위성 / 옵션 / 관찰
권장 매수 구간: 현재가 / N% 조정 시 / 인내심 있게 대기
권장 보유 비중: 해당 테마 포지션의 X%
핵심 모니터링 지표: (이 회사의 논리가 뒤집혔다는 신호는 무엇인가)
```

## 5단계: 종합 출력

보고서 끝에 통합한다:

### 5.1 최종 선정 3개사 조합표

| 회사 | 유형 | 추천도 | 권장 비중 | 핵심 논리 | 핵심 리스크 |
|------|------|-------|---------|---------|---------|
| A | 핵심 | ★★★★★ | 50-60% | | |
| B | 위성 | ★★★★☆ | 25-35% | | |
| C | 옵션 | ★★★☆☆ | 5-15% | | |

### 5.2 산업 단위 ETF 대안

종목을 고르고 싶지 않다면, 관련 ETF 1-3개(A주/홍콩 주식/미국 주식)를 나열한다.

### 5.3 산업 전체의 위치 판단

- 산업 PE/PB의 과거 백분위
- 자금 흐름(북향자금, ETF 설정·환매, 셀사이드 커버리지 밀도)
- 전체적으로 "초기/확장/성숙/쇠퇴" 중 어느 단계에 있는가

### 5.4 정보 충분도 자체 평가(필수 기재)

| 차원 | 등급 | 설명 |
|-----|------|-----|
| 회사 재무 데이터의 완결성 | A/B/C | |
| 밸류에이션 데이터의 시의성 | A/B/C | |
| 산업 구도 판단 | A/B/C | |
| 경영진 정보 | A/B/C | |

A = 데이터가 충분하고 신뢰할 수 있음. B = 일부 누락이 있으나 주된 결론에 영향 없음. C = 누락이 많아 결론을 신중히 다뤄야 함.

### 5.5 갱신 대기 데이터 포인트

명확히 나열한다: 어떤 데이터가 추정치인지, 어떤 데이터가 추후 확인이 필요한지, 어느 분기 실적을 중점 추적해야 하는지.

### 5.6 자료 출처 목록

데이터/결론 각각의 출처 링크를 분류해 나열한다(실적, 리서치 보고서, 뉴스, 산업 보고서).

## AI 연구 편향 자각(중요)

퍼널 선별 과정에서 AI가 빠지기 쉬운 함정:

| 편향 | 양상 | 대응 |
|------|-----|------|
| 선두 기업 선호 | 대형주는 자료가 많고 분석 분량이 길어, "더 좋아" 보인다 | 필수 지표와 해자 평점으로 순위를 매기고, 보고서 분량으로 매기지 않는다 |
| 영어 선호 | 미국 주식은 자료가 풍부하고, A주·홍콩 주식은 저평가되기 쉽다 | 반드시 중국어와 영어로 모두 검색하고, A/H 회사를 빠뜨리지 않는다 |
| 스토리 선호 | 높은 상승률 + 언론의 관심 = 더 좋아 보이는 "AI 테마주" | "AI 매출 비중" vs "AI 스토리 비중"을 구분하고, 실제 사업을 본다 |
| 현재 선호 | 지금 재무가 좋은 회사가 선정되기 쉬워, 전환기의 다크호스를 놓칠 수 있다 | 2층 1차 선별에서 "추세 개선"을 완화 조건으로 허용한다 |
| 상장 선호 | 상장사만 보면 그 분야 최고의 플레이어를 놓칠 수 있다 | 반드시 "향후 IPO 후보"를 나열하고, 기업가치와 시간 창을 표기한다 |

## 출력 요구사항

1. **보고서 위치**: `reports/{산업명}-funnel-{YYYYMMDD}.md`(산업 보고서는 reports/ 루트 디렉터리에 둔다)
2. **언어**: 한국어
3. **문체**: 직설적이고 날카롭게, 군더더기 없이
4. **데이터**: 모든 데이터에 출처를 표기한다. 추정치에는 "추정"이라고 표기한다
5. **입장을 미리 정하지 않는다**: 먼저 데이터 제시 → 논리 전개 → 결론 도출
6. **정반 양면**: 핵심 판단마다 반대 논거를 붙인다
7. **층마다 탈락 기록을 남긴다**: 탈락한 회사도 이름+사유를 남긴다

## 데이터 표본 점검(출고 승인 절차)

보고서를 쓴 뒤 데이터 표본 점검을 수행하고, 통과해야 발행할 수 있다:

```bash
# Step 1 — 표본 점검 목록 추출(15% 무작위 표본)
python3 tools/report_audit.py extract \
  --report <보고서 파일 경로>

# Step 2 — 목록의 각 항목을 신뢰할 수 있는 출처에서 조회(skills/financial-data.md 참조)

# Step 3 — 통과/반려 판정 출력
python3 tools/report_audit.py verdict \
  --results '<채워 넣은 JSON>' \
  --report <보고서 파일명>
```

**【통과】** 전부 통과 → 보고서 발행 가능. **【반려】** 불통과 항목 있음 → 수정 후 재심사.
