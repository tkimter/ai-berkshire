# 실적 정독: 1차 자료 심층 해석

$ARGUMENTS 에 대해 실적 정독 분석을 수행한다.

**지원 입력 형식**: `회사명 분기`. 예: `텐센트 2025Q4`, `PDD 2025연간보고서`, `메이퇀 최신`(기본값은 가장 최근 분기를 읽는다)

> "나는 셀사이드 리서치 보고서를 보지 않는다. 원본 실적 보고서만 읽는다." —— 리루
>
> "나는 매일 500쪽을 읽는다. 지식은 그렇게 쌓인다. 복리처럼." —— 버핏

## 설계 이념

대다수 AI 투자 리서치 도구는 2차 정보(뉴스, 리서치 보고서 요약, 데이터 사이트)에 의존한다. 그러나 버핏과 리루의 핵심 역량은 **1차 자료를 읽는 것**이다 — 연간보고서, 분기보고서, 컨퍼런스콜 기록.

2차 정보의 문제:
- 걸러져 있다 — 애널리스트는 자기 견해에 유리한 데이터를 선택적으로 제시한다
- 시차가 있다 — 남들이 소화를 끝냈을 때는 alpha가 이미 사라졌다
- 맥락이 없다 — "매출 15% 성장"은 성장의 질에 대한 경영진의 논의에서 떨어져 나와 있다

이 Skill은 1차 자료를 직접 해석하며, 버핏과 리루가 실제로 들여다볼 내용에 집중한다.

## 실행 절차

### 사전 단계: 자료 입수 가능성 등급

| 등급 | 특징 | 영향 |
|------|------|------|
| A급 | 원문 전체를 확보(10-K/연간보고서/컨퍼런스콜 기록) | 모든 단계를 정상 수행한다 |
| B급 | 원문 일부 또는 제3자 취합본만 확보 | "원본 출처 아님"으로 표기하고 주석 분석의 비중을 낮춘다 |
| C급 | 뉴스 보도와 데이터 사이트 요약뿐 | 핵심 재무 데이터 변화에 집중하고 주석 발굴은 건너뛰며 "1차 자료 부족"으로 표기한다 |

### 1단계: 1차 자료 확보

Task 도구로 백그라운드 Agent 여러 개를 띄워 아래 원자료를 **병렬**로 확보한다:

1. **실적 보고서 원문**: 회사 IR 페이지, SEC EDGAR(미국 주식 10-K/10-Q), 홍콩거래소 披露易(HKEXnews, 홍콩 주식), 巨潮资讯网(A주)에서 확보한다
2. **실적 컨퍼런스콜 기록/녹음**: Seeking Alpha, 회사 IR 페이지, 雪球 등에서 확보한다
3. **경영진의 주주서한**(연간보고서가 있는 경우): 전문을 읽는다
4. **투자자의 날/애널리스트의 날 자료**(최근에 있었다면)

원문 전체를 확보할 수 없으면 `skills/financial-data.md` 규범에 따라 표준 데이터 소스로 조합한다(미국 주식: macrotrends+stockanalysis; 홍콩 주식: aastocks+macrotrends; A주: 东方财富+巨潮资讯; 대만 주식: FinMind `tools/twstock_data.py`+Goodinfo). 단, 반드시 "원본 실적 보고서 아님, 제3자 취합본"이라고 표기하고, 핵심 데이터의 두 출처 간 오차가 1%를 넘으면 표시한다.

### 2단계: 핵심 재무 데이터 추출과 검증

#### 2.1 매출과 손익계산서

| 지표 | 당기 | 전기 | YoY 변화 | 경영진 가이던스 | 달성 여부 |
|------|------|------|---------|-----------|---------|

반드시 포함할 것:
- 총매출과 사업별/지역별 매출 분해
- 매출총이익, 매출총이익률 변화
- 영업이익, 영업이익률 변화(GAAP와 Non-GAAP 구분)
- 순이익(비경상 손익의 영향에 주의)
- EPS(기본 vs 희석)

#### 2.2 현금흐름표(버핏이 가장 중시한다)

| 지표 | 당기 | 전기 | 변화 | 주목점 |
|------|------|------|------|--------|

반드시 포함할 것:
- 영업현금흐름 대 순이익 비율(>100%가 바람직, <80%는 경계)
- 자본적 지출과 그 구성(유지성 vs 확장성)
- 잉여현금흐름 = 영업현금흐름 - 자본적 지출
- 자사주 매입 금액, 배당 금액
- 현금 및 현금성자산 기말 잔액

#### 2.3 재무상태표 건전성

반드시 포함할 것:
- 현금+단기투자 vs 이자부 부채
- 순현금/순부채 변화 추세
- 매출채권 회전일수 변화(신용 조건을 풀어 매출을 끌어올리고 있지 않은가?)
- 재고 회전일수 변화(재고가 쌓이고 있지 않은가?)
- 영업권 및 무형자산 비중(손상 위험이 있는가?)

**데이터 검증**: `tools/financial_rigor.py` 로 핵심 데이터를 검증한다:

```bash
# 매출과 순이익 교차 검증(출처 최소 2곳)
python3 tools/financial_rigor.py cross-validate \
  --metric "revenue" --values 108.3e9 107.9e9 --sources "회사 실적보고서" "Yahoo Finance"

# 시가총액 검증
python3 tools/financial_rigor.py verify-market-cap \
  --price 101 --shares 1.488e9 --reported 1.44e11 --currency USD

# 밸류에이션 지표 검산
python3 tools/financial_rigor.py verify-valuation \
  --price 101 --eps 9.6 --bvps 26.5 --fcf-per-share 10.2
```

### 3단계: 경영진 논의 정독(MD&A)

버핏과 리루가 가장 많은 시간을 쓰는 부분이다. 숫자를 보는 것이 아니라 **경영진이 어떻게 말하는지 듣는 것**이다.

#### 3.1 경영진 어조 분석

경영진 논의/컨퍼런스콜 발언을 단락별로 읽고 아래 신호를 표기한다:

| 신호 유형 | 구체적 양상 | 예시 |
|---------|---------|------|
| 🟢 **솔직함 신호** | 문제를 먼저 인정하고 구체적 원인을 제시한다 | "이번 분기 이익률 하락은 주로 X 분야 투자가 예상을 넘었기 때문이다" |
| 🟢 **명료함 신호** | 전략 서술이 구체적이고 정량 목표가 있다 | "우리는 향후 12개월 안에 X 사업의 시장 점유율을 15%에서 20%로 끌어올릴 계획이다" |
| 🔴 **모호함 신호** | "우리는 믿는다", "장기적으로 보면" 같은 실질 없는 말을 대량으로 쓴다 | "우리는 미래에 대해 확신으로 가득 차 있다" |
| 🔴 **화제 전환 신호** | 직접적인 질문을 피하고 다른 화제로 넘긴다 | 이익률을 물었는데 매출 증가율 이야기로 돌린다 |
| 🔴 **외부 귀인** | 문제를 모두 거시/산업/경쟁사 탓으로 돌린다 | "거시 환경의 영향으로..." |

#### 3.2 약속 추적

직전 실적 보고서/컨퍼런스콜에서 경영진의 구체적 약속을 추출해 당기 실제 상황과 대조한다:

| 전기 약속 | 당기 이행 상황 | 평가 |
|---------|------------|------|
| "하반기 이익률이 X%로 회복될 것" | 실제 Y% | ✅달성 / ❌미달성 / ⚠️부분 달성 |

**돤융핑**: "경영진이 믿을 만한지 보는 가장 간단한 방법은 예전에 한 말을 지켰는지 보는 것이다."

#### 3.3 핵심 질문 식별

컨퍼런스콜 Q&A에서 애널리스트의 가장 날카로운 질문과 경영진의 답변 수준을 추출한다:

| 애널리스트 질문 | 경영진 답변 | 답변 수준(1-5) | 회피 여부 |
|-----------|-----------|:------------:|:-------:|

### 4단계: 주석과 숨은 정보 발굴

실적 보고서 주석에는 경영진이 쉽게 보여 주고 싶지 않은 정보가 숨어 있다:

#### 4.1 필수 점검 주석 항목

- [ ] **관계자 거래**: 대주주/관계자와의 거래 조건이 공정한가?
- [ ] **주식 보상**: 옵션/RSU의 희석 효과는 얼마나 큰가? 행사가는 얼마인가?
- [ ] **우발 부채**: 소송, 보증, 약정 등 부외 위험
- [ ] **회계 정책 변경**: 수익 인식 방식, 감가상각 연수 등을 바꾸지 않았는가?
- [ ] **부문 정보**: 사업별 이익률 차이, "좋은 사업이 나쁜 사업을 보조"하고 있지 않은가
- [ ] **고객/공급사 집중도**: 상위 5대 고객/공급사 비중

#### 4.2 이상 신호 탐지

- [ ] 매출채권 증가율 > 매출 증가율(유통 채널에 밀어내기를 하고 있을 수 있다)
- [ ] 재고 증가율 > 매출 증가율(재고가 쌓이고 있을 수 있다)
- [ ] 영업현금흐름 < 순이익이고 격차가 확대(이익의 질이 의심스럽다)
- [ ] 자본화 지출이 갑자기 증가(이익을 미화하고 있을 수 있다)
- [ ] 비경상 이익 비중이 갑자기 상승

### 5단계: 과거 데이터와 대조

#### 5.1 추세 분석

당기 핵심 지표를 최소 4개 분기(또는 3개년 연간보고서)의 시계열에 놓는다:

| 지표 | Q-4 | Q-3 | Q-2 | Q-1 | 당기 | 추세 판단 |
|------|-----|-----|-----|-----|------|---------|

중점 주목:
- 이익률은 개선되고 있는가, 악화되고 있는가?
- 매출 증가율은 가속하고 있는가, 감속하고 있는가?
- 현금흐름의 질은 높아지고 있는가, 낮아지고 있는가?
- 자본적 지출 강도는 늘고 있는가, 줄고 있는가?

#### 5.2 경영진 가이던스와 대조

| 지표 | 경영진의 기존 가이던스 | 실제 결과 | 편차 | 해석 |
|------|--------------|---------|------|------|

### 6단계: 정독 보고서 출력

#### 보고서 구조

```
1. 핵심 데이터 한눈에 보기(한 쪽짜리 표)
2. 당기의 가장 중요한 변화 3가지(500자 이내)
3. 경영진 어조와 약속 추적
4. 주석 속 숨은 정보
5. 핵심 질문(컨퍼런스콜 Q&A 발췌)
6. 투자 논거와의 관계(보유 중인 경우)
7. 결론: 이번 실적은 무엇을 바꿨는가?
```

#### 결론이 반드시 명확히 답해야 할 것

1. **이번 실적은 예상 상회인가, 예상 부합인가, 예상 하회인가?**("대체로 부합"이라고 해 놓고 양쪽 이야기를 잔뜩 늘어놓아서는 안 된다)
2. **투자 논거에 미치는 영향**: 강화 / 영향 없음 / 약화 / 붕괴
3. **다음에 주목할 촉매는 무엇인가?**
4. **이미 보유 중이라면 비중 확대/보유/비중 축소 중 무엇인가?**

### 7단계: 보고서 저장

보고서를 `reports/{회사명}-earnings-{기간}.md` 에 저장한다. 예: `reports/텐센트-earnings-2025Q4.md`

### 8단계: 데이터 표본 점검(출고 승인 절차)

보고서를 저장한 뒤 데이터 표본 점검을 수행하고, 통과해야 발행할 수 있다:

```bash
# Step 1 — 표본 점검 목록 추출
python3 tools/report_audit.py extract \
  --report reports/{회사명}-earnings-{기간}.md

# Step 2 — 목록의 항목마다 신뢰할 수 있는 정보원에서 수치를 가져온다(skills/financial-data.md 참고)

# Step 3 — 출고 승인/반려 판정 출력
python3 tools/report_audit.py verdict \
  --results '<작성한 JSON>' \
  --report {보고서 파일명}
```

**【출고 승인】** 전부 통과 → 발행; **【반려】** 불통과 항목 있음 → 수정 후 재심사.

## 핵심 원칙

- **원문을 읽고 요약을 읽지 않는다**: 가능한 모든 수단으로 1차 자료를 확보한다
- **변화를 보고 절대값을 보지 않는다**: 추세가 숫자 자체보다 중요하다
- **어조를 듣고 내용만 듣지 않는다**: 경영진이 어떻게 말하는지는 무엇을 말했는지만큼 중요하다
- **주석을 살피고 본문만 보지 않는다**: 악마는 디테일에 숨어 있다
- **결론을 내고 취합에 그치지 않는다**: 정독의 목적은 판단을 세우는 것이지 실적을 되풀이하는 것이 아니다
