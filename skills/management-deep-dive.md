# 경영진 심층 연구: 주식을 사는 것은 사람을 사는 것이다

$ARGUMENTS 에 대해 경영진 심층 연구를 수행한다.

**지원 입력 형식**: `회사명` 또는 `인명 회사명`. 예: `메이퇀`, `왕싱 메이퇀`, `젠슨 황 엔비디아`

> "주식을 사는 것은 사람을 사는 것이다. 믿을 수 있는 사람을 찾아 장기 보유하라." —— 돤융핑
>
> "경영진을 평가하려면, 아무도 보지 않을 때 그들이 무엇을 하는지 봐야 한다." —— 버핏

## 설계 철학

대부분의 투자 분석은 경영진 평가가 겉핥기에 머문다: 이력, 지분율, 보수. 그러나 버핏은 많은 시간을 들여 **경영진과 밥을 먹고 이야기를 나누고**, 리루는 **자기 투자의 본질은 사람에 대한 투자**라고 말하며, 돤융핑은 **주식을 사는 것은 사람을 사는 것**이라고 말한다.

이 Skill은 `/investment-research` 5단계 경영진 평가의 **심화판**이다. 표준 투자 연구에서 경영진 평점이 불확실하거나(★★★ 이하), 경영진이 핵심 투자 논리일 때 이 Skill로 심층 연구를 한다.

AI는 경영진과 밥을 먹을 수 없지만, 공개 정보로 다음은 할 수 있다:
- **경영진의 말과 행동이 일치하는지 추적한다**(약속 vs 이행)
- **중대한 자본 배분 결정 하나하나의 수익을 분석한다**
- **어려운 시기의 결정에서 품성을 추론한다**
- **직원/입점 상인/고객의 피드백으로 측면 검증한다**

## 실행 절차

### 1단계: 핵심 경영진 식별 및 병렬 데이터 수집 시작

WebSearch로 다음 핵심 인물을 확인한다:

| 역할 | 이름 | 재임 기간 | 배경 | 지분/옵션 |
|------|------|------|------|----------|
| CEO/이사회 의장 | | | | |
| CFO | | | | |
| 창업자(현직이 아닌 경우) | | | | |
| 실질 지배자(CEO와 다른 경우) | | | | |
| 기타 핵심 임원 | | | | |

**주의**: "누가 결정을 내리는가"와 "누구 이름이 직함에 올라 있는가"를 구분한다. 창업자가 물러났어도 여전히 정신적 지주인 회사가 있다(예: 핀둬둬의 황정).

핵심 인물을 확인한 뒤, Task 도구로 백그라운드 Agent 여러 개를 시작해 다음 데이터를 **병렬**로 수집한다:
1. Agent 1: CEO 공개 발언과 예측 기록(주주서한, 컨퍼런스콜, 인터뷰, 소셜미디어)
2. Agent 2: 자본 배분 결정 기록(인수합병, 자사주 매입, 배당, 신사업 투자)
3. Agent 3: 지배구조와 보수(지분 구조, 특수관계자 거래, 임원 보수)
4. Agent 4: 측면 검증 정보(직원 평가, 고객 피드백, 업계 평판)

### 2단계: CEO 능력범위 평가

#### 2.1 전략적 안목

CEO의 지난 5년 공개 발언(주주서한, 컨퍼런스콜, 인터뷰, 소셜미디어)을 검색해, 다음 문제에 대한 판단을 추출한다:

| 시점 | CEO의 판단/예측 | 실제 결과 | 정확도 |
|------|--------------|---------|:------:|
| | "우리는 X 시장이 ...할 것으로 본다" | X 시장은 실제로... | ✅/❌ |
| | "향후 3년 우리의 중점은 ...이다" | 실제 실행은... | ✅/❌ |

**핵심 질문**:
- CEO가 시장보다 앞서 올바른 판단을 내린 적이 있는가?
- CEO가 모두가 낙관할 때 냉정을 유지한 적이 있는가?
- CEO의 산업 추세 이해는 시장을 따라가는 것인가, 독립적 사고인가?

#### 2.2 실행 능력

| 차원 | 평가 | 증거 |
|------|------|------|
| 전략에서 실행까지 | 말한 일을 해냈는가? | |
| 조직 역량 | 인재를 끌어들이고 붙잡아 둘 수 있는가? | |
| 위기 대응 | 어려움을 만났을 때 어떻게 대응하는가? | |
| 반복 개선 속도 | 실수한 뒤 바로잡는 속도가 빠른가? | |

### 3단계: 정직성 평가(가장 중요)

**버핏**: "우리는 세 가지 자질을 찾는다: 정직, 지능, 에너지. 첫 번째가 없으면 나머지 둘이 당신을 망친다."

#### 3.1 약속 vs 이행 추적

지난 3년의 실적 컨퍼런스콜, 주주서한, 공개 인터뷰에서 경영진이 한 **구체적 약속**을 추출한다:

| # | 시점 | 약속 내용 | 약속한 자리 | 이행 여부 | 평가 |
|---|------|---------|---------|---------|------|
| 1 | | "2025년에 X 사업의 흑자를 달성하겠다" | 2024년 연간 실적 컨퍼런스콜 | | ✅/⚠️/❌ |
| 2 | | "$X억 규모의 자사주 매입을 계획한다" | 2024년 주주서한 | | ✅/⚠️/❌ |

**이행률 통계**:

| 약속 이행률 | 평가 |
|:---------:|------|
| >80% | 우수——말한 대로 한다 |
| 60-80% | 합격——큰 방향은 맞지만 실행에 편차가 있다 |
| 40-60% | 우려스러움——약속은 많고 결과물은 부족하다 |
| <40% | 심각한 문제——신뢰할 수 없다 |

#### 3.2 어려운 시기의 모습

회사 역사상 겪은 중대한 위기/어려움(주가 폭락, 실적 miss, 규제 충격, 경쟁 심화)을 검색해, 경영진의 대응을 분석한다:

| 위기 사건 | 시점 | 경영진 반응 | 사후에 돌아본 평가 |
|---------|------|-----------|-------------|

**주목할 점**:
- 먼저 나서서 소통했는가, 피했는가?
- 원인을 내부에서 찾았는가, 외부 탓으로 돌렸는가?
- 그 기회에 어렵지만 옳은 일을 했는가, 단기적으로 시장의 비위를 맞추는 쪽을 택했는가?

#### 3.3 이해관계자에 대한 태도

| 이해관계자 | 경영진 태도 | 증거 | 평가 |
|-----------|-----------|------|------|
| 주주 | 존중/무시/이용 | | |
| 직원 | 선대/착취/무관심 | | |
| 고객/사용자 | 고객 중심/단기 쥐어짜기 | | |
| 입점 상인/공급업체 | 공정한 협력/극단적 단가 압박 | | |
| 규제/사회 | 규정 준수와 협조/편법 줄타기 | | |

**리루**: "이해관계자에 대한 태도가 기업의 장기 생명력을 결정한다. 단기적 착취는 효율을 높일 수 있지만, 장기적으로는 생태계를 해친다."

### 4단계: 자본 배분 능력

버핏이 가장 중시하는 경영진의 능력이다——**1원을 벌 때마다, 경영진은 그것을 얼마로 만들 수 있는가?**

#### 4.1 자본 배분 결정 기록

회사의 지난 5년 중대한 자본 배분 결정을 검색해, 건별로 평가한다:

**인수합병 기록**:

| 시점 | 인수 대상 | 금액 | 전략적 논리 | 사후 수익 | 평점(1-5) |
|------|---------|------|---------|---------|:---------:|

**자사주 매입 기록**:

`tools/financial_rigor.py verify-valuation` 으로 매입 당시와 현재의 PE 등 밸류에이션 지표를 검증한다.

| 시점 | 매입 금액 | 평균 매입가 | 당시 PE | 사후 평가 | 평점(1-5) |
|------|---------|-----------|:------:|---------|:---------:|

**배당 기록**:

| 연도 | 배당 금액 | 배당성향 | 같은 기간 FCF | 지속 가능 여부 |
|------|---------|:------:|---------|:---------:|

**신사업 투자**:

| 시점 | 투자 분야 | 누적 투입 | 현재 상태 | 수익 평가 | 평점(1-5) |
|------|---------|---------|---------|---------|:---------:|

#### 4.2 자본 배분 평점

| 차원 | 평점(1-5) | 설명 |
|------|:---------:|------|
| 인수합병 규율 | | 합리적인 가격에 인수했는가? 인수 후 통합은 어땠는가? |
| 자사주 매입 타이밍 | | 저평가일 때 매입하고 고평가일 때 멈췄는가? |
| 배당의 합리성 | | 배당성향이 FCF와 맞는가? |
| 신사업 투자 | | 성공률은 어떤가? 손절 규율은 어떤가? |
| 현금 관리 | | 현금 보유가 합리적인가? 지나치게 쌓아 두지 않았는가? |
| **종합 평점** | | |

**버핏의 기준**: 이상적인 경영진은 좋은 기회가 있을 때 과감히 투자하고, 좋은 기회가 없을 때 적극적으로 자사주 매입/배당을 하며, 비싼 값의 인수합병은 결코 하지 않는다.

#### 돤융핑의 "사람을 산다" 기준

> 다음 세 가지 질문에 답한다:
> 1. **이 사람은 정직한가?**(성실하고, 주주의 이익을 가로채지 않는다)
> 2. **이 사람은 능력이 있는가?**(전략적 안목+실행력+자본 배분)
> 3. **이 사람에게 돈을 10년간 맡기고 싶은가?**
>
> 세 가지 모두 "예" = ★★★★★(5점)
> 앞의 두 가지가 "예" = ★★★★(4점)
> 첫 번째만 "예" = ★★★(3점)
> 첫 번째가 "예"가 아님 = ★(1점, 투자하지 않는다)

## 핵심 원칙

- **정직성은 단 하나로도 탈락시키는 항목이다** — 능력 부족은 배워서 메울 수 있지만, 품성의 문제는 고칠 수 없다
- **말이 아니라 행동을 본다** — 경영진이 무엇을 말했는지는 중요하지 않다. 무엇을 했는지가 중요하다
- **어려움 속에서 진실을 본다** — 순풍일 때는 누구나 좋은 CEO다. 역풍일 때 진짜 실력이 드러난다
- **자본 배분은 최종 시험이다** — 돈을 버는 것은 쉽고, 번 돈을 잘 배분하는 것이 어렵다
- **경영진과 사랑에 빠지지 않는다** — 객관성을 유지한다. 존경하는 사람도 큰 실수를 할 수 있다
