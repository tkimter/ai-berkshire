# 비상장 기업 리서치: 멀티 Agent 병렬 심층 리서치 프레임워크

$ARGUMENTS 에 대해 팀 방식의 심층 리서치 분석을 수행한다. 앤트그룹, 샤오훙수, SpaceX, Stripe 같은 비상장 기업을 위해 설계했다.

**최종 목표**: 정보가 본질적으로 희소한 조건에서 이 회사의 **진짜 가치**를 최대한 복원한다. 시장이 매긴 밸류에이션이 아니라, 사업 자체가 얼마짜리인지를 본다.

## 프레임워크 특징

비상장 기업 리서치와 상장 기업 리서치의 핵심 차이:
- **표준화된 재무보고서 없음**: 여러 출처를 짜 맞추고 교차 검증해야 한다
- **밸류에이션 기준점 부족**: 투자 유치 라운드, 비교기업법, 시나리오 추정에 의존한다
- **정보 비대칭이 큼**: "퍼즐 맞추기"식 리서치 방법이 더 많이 필요하다
- **엑시트 경로 불확실**: IPO/인수합병/구주 양도 모두 가능하다

## AI 리서치 편향 자각(본 프레임워크의 핵심 전제)

비상장 기업은 AI 리서치 편향이 가장 심한 영역이다. 아래 함정을 항상 경계한다:

**핵심 모순**: AI는 이미 있는 정보를 구조화하는 데 강하지만, 비상장 기업의 정보는 본질적으로 희소하다. 그 결과:
1. **거짓 보수성**: 자료가 적으면 AI는 보수적이거나 모호한 결론을 내는 경향이 있다. 그러나 자료가 적다≠회사가 나쁘다
2. **거짓 정밀성**: 보고서 템플릿을 채우려고 AI가 "합리적 추측"을 "근거 있는 분석"으로 위장할 수 있다
3. **비교 대상의 함정**: 상장사와 억지로 비교하면 상장사의 밸류에이션 논리를 그대로 물려받아 비상장 기업 고유의 가치를 놓친다
4. **생존자 편향**: 인터넷에서 검색되는 회사 정보는 대체로 긍정 쪽으로 치우친다(회사가 스스로 퍼뜨리는 것은 대부분 좋은 소식이다)

**대응 원칙**:
- 추측으로 표를 채워 확실한 척하느니, 비워 두고 "모른다"고 쓴다
- 모든 데이터 포인트에 신뢰도(🟢높음/🟡중간/🔴낮음)를 표기해 독자가 스스로 판단하게 한다
- "검증 가능한 사실"과 "AI의 추론"을 구분하고 서로 다른 서식으로 표기한다
- 정보가 극도로 희소한 회사는 "제1원리 모드"로 전환한다. 보고서의 완결성을 좇지 않고 핵심 질문 몇 개에만 답한다:
  1. 이 사업은 어떤 실제 문제를 해결하는가? 수요는 진짜 수요인가, 가짜 수요인가?
  2. 왜 이 팀인가? 이들만의 고유한 강점은 무엇인가?
  3. 성공하면 천장은 얼마나 높은가? 실패한다면 어디서 죽을 가능성이 가장 큰가?
  4. 현 단계의 핵심 검증 지점은 무엇인가?

**정보 비대칭을 역이용한다**: 시장에 비상장 기업 정보가 적다→가격 결정 효율이 낮다→바로 그것이 초과수익의 원천일 수 있다. AI 리서치의 목표는 정보 비대칭을 없애는 것(불가능하다)이 아니라, 제한된 정보에서 가장 핵심적인 판단 근거를 뽑아내는 것이다.

**매출 측면**:
- 총매출 규모와 성장률(최근 3년, 연간/분기 단위)
- 매출 구조 분해(사업 라인/제품 라인별)
- 매출 성장 동인 분해: 양(사용자/거래량) × 가격(ARPU/객단가)
- 매출의 계절적 변동 패턴

**비용 측면**:
- 매출총이익률 추정(동종 상장사와 비교하고 선정 논리를 설명한다)
- 연구개발비율 추정(직원 수 × 1인당 급여, 또는 R&D 인력 비중으로 추정)
- 판매비율 추정(고객 획득 채널과 광고 집행 데이터로 추정)
- 관리비율 추정

**이익 측면**:
- 영업이익/EBITDA 추정
- 순이익/조정 순이익 추정
- 흑자 타임라인: 언제 흑자가 됐는가? 아직 적자라면 언제로 예상되는가?

**현금흐름 측면**:
- 영업현금흐름 판단(플러스/마이너스, 스스로 현금을 창출하는가)
- 자본적 지출 수준과 추세
- 잉여현금흐름 추정
- 보유 현금/현금 소진 속도(투자 유치 금액, 투자 유치 간격, 직원 수로 추정)
- 현금 런웨이: 현재 소진 속도로 얼마나 버티는가?

**효율 지표**:
- 직원 수와 인당 효율(1인당 매출, 1인당 이익)
- 자본 효율: 투자 유치 1위안당 매출이 얼마나 나오는가
- 동종 상장사와 효율 지표 비교

### 3. 재무 데이터 교차 검증
- 같은 지표에 출처가 여럿이면 모두 나열하고 차이를 설명한다
- 서로 다른 방법으로 같은 지표를 추정해 결과가 수렴하는지 확인한다
- 검증할 수 없는 "단독 출처" 데이터를 표시한다

| 지표 | 출처 A(데이터/시점) | 출처 B(데이터/시점) | 차이 | 채택 판단 |
|------|-------------------|-------------------|------|---------|

### 4. 투자 유치 이력과 밸류에이션 변천
전체 투자 유치 타임라인을 정리한다:

| 라운드 | 시점 | 금액 | 프리머니 밸류에이션 | 포스트머니 밸류에이션 | 리드 투자자 | 팔로우 투자자 | 밸류에이션 증가 배수 | 비고 |
|------|------|------|---------|---------|--------|--------|------------|------|

분석:
- 밸류에이션 성장 곡선이 건강한가(라운드별 증가 배수가 합리적인가)
- 투자 유치 간격이 합리적인가(너무 잦다=현금 소진이 빠른가? 너무 드물다=투자 유치가 어려운가?)
- 밸류에이션 역전(Down Round)이 있었는가
- 기존 주주가 계속 추가 투자하는가(신뢰 신호)
- 최신 라운드의 투자 조건 추정:
  - 청산 우선권(1x/2x/participating)
  - 희석 방지 조항(full ratchet/weighted average)
  - 베팅 조항(실적/상장 시점)
  - 이 조항들이 보통주 가치에 미치는 영향

### 5. 밸류에이션 분석(여러 방법 교차)

**방법 1: 최근 투자 유치 밸류에이션법**
- 최근 라운드의 밸류에이션과 시점
- 청산 우선권 등 조항을 고려한 "보통주 환산 밸류에이션"(통상 20-40% 할인이 필요하다)
- 현재까지의 시차 조정
- 이 라운드 투자자의 동기 분석(재무적 투자 vs 전략적 투자, 전략적 투자자는 프리미엄을 낼 수 있다)

**방법 2: 상장 비교기업법**
- 상장 비교기업 3-5곳을 고르고 선정 이유를 설명한다
- 핵심 배수 비교:

| 비교기업 | P/S | P/E | EV/EBITDA | EV/Revenue | 성장률 | 이익률 |
|---------|-----|-----|-----------|------------|------|--------|

- 적용하는 조정:
  - 유동성 할인: 20-30%(구체적 적용값과 이유를 표기한다)
  - 성장률 프리미엄/할인
  - 규모 할인
  - 규제/정책 리스크 할인

**방법 3: DCF 시나리오 분석**
세 가지 시나리오, 각각 핵심 가정을 나열한다:

| 가정 | 비관 | 중립 | 낙관 |
|------|------|------|------|
| 향후 5년 매출 CAGR | | | |
| 최종 상태 영업이익률 | | | |
| 최종 상태 성장률 | | | |
| WACC | | | |
| 터미널 배수(EV/EBITDA) | | | |

모든 가정에는 논거가 있어야 하며, 근거 없이 가정해서는 안 된다.

**방법 4: 최종 국면 시가총액 역산법**
- 5년/10년 뒤 이 사업이 최종 상태에서 차지할 시장 지위를 가정한다
- 최종 상태 매출과 이익률 가정
- 최종 상태 적정 배수(동종 산업의 성숙 기업 참고)
- 현재 적정 밸류에이션 구간을 역산한다
- 내재 연환산 수익률

**방법 5: 거래 사례 비교법**
- 동종 산업의 최근 2년 인수합병/투자 유치 거래
- 거래 배수(P/S, P/E)
- 거래 배경과 프리미엄/할인 요인

### 6. 밸류에이션 종합 판단

| 방법 | 밸류에이션 구간 | 신뢰도 | 가중치 | 가중 밸류에이션 |
|------|---------|--------|------|---------|

- 방법별 밸류에이션이 수렴하는가? 차이가 크면 원인을 분석한다
- 최종 밸류에이션 구간은 "적정 밸류에이션"과 "보수적 밸류에이션"(안전마진 밸류에이션)을 구분해 제시한다

1. **데이터 충돌 중재**:
   - 각 Agent 보고서에서 핵심 데이터를 추출한다
   - 서로 다른 Agent가 인용한 같은 데이터가 일치하는지 식별한다
   - 충돌하는 데이터를 중재한다: 모든 출처를 나열하고, 어느 것을 왜 채택하는지 설명한다

2. **신호 일관성 검증**:
   - 사업 성장 신호(business-decoder) vs 채용 신호(signal-miner)가 일치하는가?
     (사업이 빠르게 성장한다는데 채용이 줄고 있다면 설명이 필요하다)
   - 기술 선도 서사(tech-ip)를 특허/인재 데이터(signal-miner)가 뒷받침하는가?
   - 밸류에이션 수준(financial-detective) vs 경쟁 지위(competitive-mapper)가 맞아떨어지는가?
   - 경영진의 공개 서사(risk-governance) vs 실제 행동 신호(signal-miner)가 일치하는가?

3. **정보 퍼즐 복원**:
   - 보고서 6건의 정보 조각을 맞춰 더 완전한 그림을 복원할 수 있는지 본다
   - 정보의 "백색 구역"(확인된 사실), "회색 구역"(단서는 있으나 불확실), "흑색 구역"(완전히 미지)을 표기한다

4. **반편향 점검**:
   - 보고서에 "긍정 정보는 상세하고 부정 정보는 간략한" 편향이 있는지 점검한다
   - 모든 긍정적 판단에 대응하는 반대 검증이 있는지 확인한다

## 중요 주의 사항

1. **Agent 6개는 반드시 병렬로 가동한다** — 같은 메시지 안에서 Agent 도구를 6번 호출한다
2. **데이터 신뢰도 표기** — 비상장 기업의 데이터 출처는 질이 들쭉날쭉하므로, 모든 핵심 데이터에 출처와 신뢰도를 표기한다
3. **추정은 투명하게** — 모든 추정 과정은 계산 논리를 보여야 하며, 근거 없이 숫자를 내놓아서는 안 된다
4. **교차 검증** — 핵심 데이터는 최소 2개 출처로 교차 검증하고, 출처가 충돌하면 모두 나열한다
5. **신호 일관성 검증** — 종합 단계에서 반드시 차원 간 신호 일관성 점검을 한다
6. **결론은 명확하게** — 투자/관망/회피 권고를 피하지 않되, 결론의 신뢰도도 함께 밝힌다
7. **인내심 있게 기다린다** — Agent 6개의 리서치에는 몇 분이 걸리므로, 사용자에게 진행 상황을 실시간으로 알린다
8. **중국어·영어 검색** — 비상장 기업 정보는 중국어·영어 매체에 흩어져 있을 수 있으므로 두 언어로 검색한다
9. **반편향 핵심 원칙** — 자료가 적다≠회사가 나쁘다, AI 분석 분량이 짧다≠투자 확실성이 낮다. 정보가 극도로 희소한 회사는 "제1원리 모드"로 전환해 핵심 질문에 집중하고, 보고서의 형식적 완결성을 좇지 않는다
10. **정직하게 비워 둔다** — 보고서에서 "근거 있는 분석"과 "추측으로 채운 부분"을 명확히 구분하고, "이 차원은 데이터가 부족해 의미 있는 결론을 낼 수 없다"는 서술을 허용한다
11. **대체 데이터는 잡음이 아니다** — 채용, 특허, 소송, App 데이터 같은 대체 데이터가 뉴스 보도보다 실제 경영 상황에 더 가까울 수 있다
12. **진짜 가치 지향** — 최종 목표는 이 사업이 얼마짜리인지 판단하는 것이지, 보기 좋은 보고서를 내는 것이 아니다. 정보가 부족해 신뢰할 만한 밸류에이션 판단을 할 수 없으면 "정보 부족으로 신뢰할 만한 밸류에이션을 제시할 수 없다"고 그대로 말한다
