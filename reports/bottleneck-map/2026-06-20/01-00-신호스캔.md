## 4. FormFactor(FORM) — 진입 목표 미도달, 펀더멘털은 더 강해짐

**2026년 1분기 기록 데이터 요점:**
- 매출: $226.1M(+32% YoY), 사상 최고
- Non-GAAP EPS: $0.56(vs 예상 $0.44, 27% 상회)
- Non-GAAP 매출총이익률: 49%(+510 bps QoQ)
- 2026년 2분기 가이던스: $240M(계속 가속)
- 다음 실적 발표: 2026년 7월 29일

**현재 밸류에이션:**
| 지표 | 데이터 |
|------|------|
| 시가총액 | ~$10.91B |
| 연환산 매출(2분기 가이던스×4) | ~$960M |
| **선행 PS** | **~11.4x** |
| Non-GAAP EPS 연환산 | ~$2.24($0.56×4) |
| **Non-GAAP PE** | **~64x** |
| 52주 ATH | $159.09(4/24/2026) |
| 현재가(추정) | ~$144 |

**10년 25x PE 엑시트 안전마진 검증:**
- 현재 시가총액 $10.91B × 1.1^10 = 엑시트 시가총액 $28.3B
- 필요 순이익: $28.3B / 25 = $1.13B
- 순이익률 20%라면 해당 연매출: $5.65B(오늘 $960M의 5.9배)
- 필요 10년 CAGR: ~19.4%(현재 +32% YoY, 이후 점차 ~15-20% 구간으로 둔화한다면 20년은 어렵지 않으나, 10년 뒤 정점 이후에도 20%를 유지하려면 강한 성장 지속성이 필요)
- 결론: **황색 신호 — 현재 가격은 뚜렷한 안전마진이 없으나, PEG=0.43(낮음)은 성장률이 현 PE를 뒷받침할 수 있음을 시사하며, 성장률이 2-3년 더 30%+를 유지한 뒤 둔화한다면 연환산 수익률 10-12%가 가능하다**

**관찰 명단 상태: ★★★★ 불변.** $120-130 구간(선행 PS ~11x 이하에 해당)으로 조정을 기다리며, 그때 안전마진이 개선된다. 펀더멘털은 과거 어느 때보다 강하지만 가격 역시 더 높다.
