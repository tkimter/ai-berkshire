## 2. 🆕 Lumentum(NASDAQ:LITE) — EML 레이저 S급 병목, 밸류에이션 적신호

**트리거**: 이번 회차 검색에서 Nvidia가 2026년 3월 EML 생산능력을 확보하기 위해 **$4B(Lumentum + Coherent 합계)**를 약정한 사실이 확인됐다. Lumentum은 현재 **전 세계 유일**의 200G/lane EML 양산 공급업체이며, 800G 광모듈 생산은 2026-2027년 40-60% 부족이 예상된다.

**출처**: TechTimes (5/27/2026), TrendForce (12/2025), EE Times Asia, SDxCentral

### 병목 평가(6개 차원)

| 기준 | 평가 | 점수 |
|------|------|------|
| 공급 집중도 | Lumentum = 유일한 200G/lane EML 양산 공급업체; Coherent는 2선 | 🔴 ≤2개사 |
| 증설 주기 | InP 에피택시 + EML 제조 인증: 2-3년 | 🔴 >2년 |
| 대체 난이도 | CW laser + 실리콘 포토닉스가 대체 경로이나 기술 성숙도가 낮고 인증 주기가 길다 | 🟡 부분 대체 가능(3-5년) |
| 가동률 | Nvidia 확보 이후 비Nvidia 고객의 납기는 2027년 이후로 밀렸다 | 🔴 >90% |
| 수요 증가율 | 800G 이상 광모듈 출하량 2025→2026 2.6배 증가(24M→63M개) | 🔴 >50%/년 |
| 고객 검증 주기 | 데이터센터급 EML 검증 주기 >1년 | 🔴 >1년 |

**병목 등급: S급(적신호 5/6)** — EML은 현재 광통신 공급망의 실질적 단일 장애점이다

### 밸류에이션 점검(필수, 생략 불가)

**재무 스냅샷(출처: SEC 10-Q FY2026, Stockanalysis, MacroTrends)**:
- 시가총액: 약 **$70B**($69.66B-$71.7B, 데이터 출처별로 상이해 $70B로 추정)
- Q3 FY2026 분기 매출: $808.4M(확인됨)
- TTM 매출 추정: 약 **$2.5B**(분기 기준 연환산)
- 직전 회계연도(FY2025) 매출: $1.65B
- YoY 증가율: +51%($1.65B → ~$2.5B)
- 수익 상태: 데이터 부족(명확한 GAAP EPS 데이터를 확보하지 못함)

| 지표 | 수치 | 신호등 |
|------|------|------|
| PS(TTM) | $70B / $2.5B = **28x** | 🟡 황색(30x 적신호선에 근접, 증가율 51%<100%) |
| PS(Forward, 연환산 $3.2B 가정) | $70B / $3.2B = **22x** | 🟡 황색 |
| PER | 데이터 부족 | ⚠️ PER 근거 데이터 없음 |
| 시가총액 vs TAM 20% | EML 레이저 TAM 추정 $3-5B, 20% = $600M-$1B << $70B | 🔴 적색(시가총액이 TAM의 약 14-23배) |
| Nvidia $2B 출자 | 전략 주주로서 증설을 뒷받침하나, 미래 수익을 희석하기도 한다 | 🟡 희석 주의 |

**적신호 조건 발동**:
1. ✅ **시가총액 $70B >> EML TAM 20%**($70B vs $600M-$1B, 격차 70-100배)
2. ✅ **PS 28x에 증가율 51%**(<100% 면제선, PS는 30x에 근접하나 넘지 않음, 경계 사례)
3. ⚠️ **PER 데이터 부족**(적자라면 추가 적신호 발동)

**10년 25xPER 엑시트 안전마진 검증**:
- 현재 매수: $70B
- 10년 연 10% 목표: $70B × (1.10)^10 = **$181.5B**
- 25xPER → 필요 순이익: $7.26B
- 순이익률 20%(성숙기 광통신 기업 가정) 적용 시 → 필요 연 매출: **$36.3B**(현재 $2.5B의 **14.5배**)
- 필요 매출 CAGR: (14.5)^(1/10)-1 = **연 30.3%를 10년간 지속**
- **결론: 현재 가격은 안전마진이 없다**(연 30% CAGR을 10년 지속하는 것은 $70B 규모 기업에 극단적인 가정이다)

**강세 논거(존재하나 현재 밸류에이션을 뒷받침하지 못함)**:
1. EML 독점 지위는 실재한다 — 전 세계 유일의 200G/lane 양산 공급업체로, 고객에게 다른 선택지가 없다
2. Nvidia $2B 전략 투자가 협력 관계를 고정해 고객 이탈 리스크를 낮춘다
3. 수요 측: 800G 출하량 2026년 전년 대비 +160%(24M→63M개), 2027년 이후까지 지속
4. InP 생산능력 확장 주기가 길어(2-3년) 신규 진입자가 빠르게 복제할 수 없다

**약세 논거(밸류에이션 판단을 좌우)**:
1. 시가총액 $70B는 EML 레이저 TAM($3-5B) 대비 이미 14-23배를 선반영했으며, 가격에 시장이 자릿수 단위로 확대된다는 전제가 담겨 있다
2. 대체 경로(CW + 실리콘 포토닉스)를 Meta, Google 등 초대형 사용자가 가속 추진하고 있다
3. 현재 밸류에이션을 뒷받침하려면 30% CAGR이 10년간 지속돼야 하는데, 역사적으로 이를 해낸 기업은 극히 드물다
4. Nvidia 투자 조건의 세부 내용이 알려지지 않았으며, 지배권이나 공급 제약 조항이 포함됐을 수 있다

**결론**: 병목은 실재한다(S급). 그러나 밸류에이션이 과도하다(TAM 적신호). **신호 강도: ★★(⚠️ 밸류에이션 적신호)**. 관찰 명단에 올리고, 다음 매수 조건 중 하나를 기다린다:
- 시가총액이 $20-25B로 하락(PS < 10x forward)
- 매출이 $5B+로 가속되고 흑자 유지(TAM 논증의 신뢰도 제고)
- CW 대체 기술의 중대한 돌파(부정 신호, 강등 발동)
