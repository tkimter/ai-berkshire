**밸류에이션 적색 점검**:
1. 시가총액>TAM 20%? WF6 시장~$1B/년(추정), 20%=$200M; Foosung 시가총액 $1.34B > $200M → ⚠️ **적색 발동**(단 WF6는 Foosung 사업의 일부에 불과해 TAM이 과소평가되었을 수 있음)
2. PS>30x이면서 증가율<100%? PS 4.03x → 통과 ✅
3. 시가총액>5년 낙관 매출 예측×10? 매출 예측 필요, 데이터 부족
4. 증자 후 60일 내 2배? 해당 없음 → 통과 ✅

**밸류에이션 황색**: PER 241.6x > 80x → PEG 계산 필요
- PEG = 241.6 / 316 ≈ 0.76 → 316% 증가율이 신뢰할 만하면 PEG<1, 황색 수용 가능
- **단 전제는**: 316% 순이익 증가율이 WF6 가격 +70-90%의 직접 전달에서 나오는 것이며, 2분기 실적 검증이 필요

**10년 25x PER 출구 안전마진 검증**:
- 현재 순이익(추정): 2.04T KRW / 241.6 = ~8.4B KRW ≈ $6M USD
- 현재 $1.34B 시가총액으로 매수, 10년 후 25x PER 출구에 필요한 순이익=$53.6M
- 필요한 연 성장률: ($53.6M/$6M)^(1/10) - 1 = **24.5%/년**
- WF6 가격 +70-90%가 반영되고 계약 비중이 올라가면 24.5%/년 증가율 달성이 **가능**(단 미검증)
- **연 수익률: ~10%**(안전마진 겨우 충족, 초과 여유 없음)

**결론**: WF6 S급 병목은 실재하며 격상되었으나, Foosung은 +196% YTD 이후:
- 안전마진이 얇다(연 10%)
- PER 241.6x는 316% 순이익 증가율 달성에 의존
- ★★★ 유지(12:00 편입); **상향 없음**; 파일명 종목으로 삼지 않음
