## 신호 상세

### 신호 1: ALM $700M 전환사채 초과 청약 오늘 결제 — Phase 2 자금 확보

**핵심 사실**(출처: Globe and Mail, TipRanks, Investing.com, BusinessWire):

| 조건 | 수치 |
|------|------|
| 원금 | US$700,000,000 |
| 금리 | 2.25%, 반기 지급, 2027년 1월 1일부터 |
| 만기 | 2031년 7월 1일 |
| 전환가 | $27.40/주($1,000 원금당 36.495주) |
| 청약 상태 | **초과 청약(oversubscribed)** |
| 결제일 | **2026년 6월 9일**(오늘) |
| 초과배정권 | 추가 $1억, 13일 내 행사 |
| 상한 청약 | Cap Call 상한 $41.36/주(종가 ~$20.68 대비 100% 프리미엄) |
| 용도 | 기존 부채 재융자 + 텅스텐 광산 확장 지원(Phase 2) |

**ALM 현재 재무 상태**(출처: Yahoo Finance, Macrotrends):

| 지표 | 수치 |
|------|------|
| 현재 주가 | ~$16.80(2026-06-07, CB 가격 책정일 ~$20.68 대비 약 19% 하락) |
| 시가총액 | ~$45.7억 |
| 유통 주식 | ~2.837억 주 |
| 잠재 신규 주식(전액 전환)| 700,000 × 36.495 = ~2,555만 주($100M 초과배정 행사 시 +~365만 주) |
| 잠재 희석 비율 | ~9%-10%(전량 전환 시, 단 주가가 $27.40을 넘어야 발동) |

**상태 변화 분석**:

- 이전 상태: Phase 2 자금 조달 미정 + AGM 투표 불확실성
- 현재 상태: **자금 조달 확정, AGM 투표는 절차적 사안**
- $700M = 현재 시가총액의 15.3% → 비교적 큰 비율이나 CB 구조상 즉시 희석되지는 않는다
- 현재 주가 $16.80은 전환가 $27.40보다 훨씬 낮아 CB는 현재 완전히 외가격(OTM 38.7%)이다
- Cap Call 상한 $41.36이 $27.40-$41.36 구간의 잠재 희석을 보호한다

**리스크 변화**:

| 리스크 | 변화 전 | 변화 후 |
|------|--------|--------|
| 자금 조달 리스크 | 높음 | 기본적으로 해소($700M 입금 완료) |
| 실행 리스크 | 존재 | 여전히 존재(증설은 2027년 완공 필요) |
| 희석 리스크 | 보통 | 알려져 있고 계량 가능(최대 ~10%, $27.40 발동 필요) |
| 부채 상환 리스크 | 낮음 | 상승(2031년에 $700M+ 상환 필요, 다만 5년의 시간 창이 있다) |

**결론**: Phase 2 결정은 "할 것인가"에서 "어떻게 할 것인가"로 바뀌었다. 자금 조달 차원의 리스크는 해소되었고 실행 차원에서 시계가 돌기 시작했다. AGM Phase 2 투표 결과(6/10 EST 장 시작 전 공고 예상)는 여전히 기다려야 하나 결과는 결정적 의미를 잃었다.

### 신호 2: TSMC CEO 6월 4일 연례 주주총회 — AI 칩 부족 "수년간 지속"

**핵심 발언**(출처: TechTimes 2026-06-05, TechZine, MoneyCheck):

- **C.C. Wei는 연례 주주총회(2026-06-04)에서 명확히 밝혔다**: AI 칩 부족은 "수년간" 지속되며 메모리 칩처럼 가격이 급격히 출렁이지는 않을 것이다
- **가격**: TSMC는 이미 최선단 공정(3nm 이하) 가격 인상을 시작했으며, 2026년 하반기 3nm 공정은 약 **15%** 인상, 2027년에 5-10% 추가 인상
- **매출 전망**: 2026년 매출 증가율은 여전히 30%+ 예상 유지(수요 강세)

**이미 추적 중인 종목에 미치는 영향**(교차 검증):

| 종목 | 영향 |
|------|------|
| VECO(MOCVD 장비)| ✅ AI 설비투자 지속 → InP 레이저 증설 수요 지속 → 2026년 하반기 주문 반영 논리 유지 |
| 3110.T(T-glass)| ✅ AI 서버 + PCB 수요 지속 → T-glass 부족 지속 검증 |
| 4047.T(WF6)| ✅ 웨이퍼 제조량 지속 상승 → WF6 수요 지속 |
| CHG.L(탄약)| 간접 호재(NATO 국방비는 AI와 무관, 독립 논리) |

**결론**: 이는 6월 9일 기준 가장 권위 있는 AI 공급망 긴장에 대한 1차 확인으로, 모든 AI 인프라 병목 논거를 효과적으로 교차 검증하며 등급은 바꾸지 않으나 논거의 신뢰도를 높인다.

### 신호 3: 고체 로켓 모터 — 새 정부 조치 2건

**새 데이터**(출처: The Defense Post 2026-02-24; StockTitan 2026-05-26; executivegov):

1. **DARPA가 RTX/Raytheon을 선정해 조합형 고체 로켓 모터 개발**(2026-05-26):
   - 목표: 모듈형 SRM 기술을 개발해 공급망 단일 고장점 문제를 해결
   - 의미: 정부 차원에서 SRM 공급망의 구조적 결함을 인정하고 AMPAC 단일 고장점을 "우회"하는 길을 찾기 시작했다
   - CHG.L에 대해: 중립에서 약간 긍정(장기 대체 방안 개발, 단기 공급은 기존 생산능력에 의존)

2. **미 국방부가 $3270만 DPA Title III SRM 투자를 추가**:
   - 목표: 국내 SRM 산업 기반의 핵심 생산능력 병목 확대
   - 2월 Anduril $4370만에 이은 두 번째 DPA 대규모 투입

**CHG.L에 미치는 영향**: 논리가 더 공고해졌다. 단기(1-3년)에는 정부의 증설 투입이 SRM 공급의 심각한 부족을 반영하며 공급 과잉 신호가 아니다. 중기(3-5년)에는 DARPA 모듈형 SRM이 기술 노선 변화를 가져올 수 있다(리스크).
