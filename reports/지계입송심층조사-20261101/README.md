# 《지계입송》(持械入宋) 심층 조사

[수정 보고서 읽기](%EC%A7%80%EA%B3%84%EC%9E%85%EC%86%A1-%EC%97%B0%EA%B5%AC%EB%B3%B4%EA%B3%A0%EC%84%9C-20261101.md) · 자료 기준일 2026년 11월 2일.

제2판은 직접 수집한 자료를 추가하고 실질적으로 다시 썼다:

- 제작 계정의 숏드라마 목록 43개, 앞 10개 시즌 각각의 재생수와 회차 수, 표시 재생수 합계 약 6.96억.
- 시즌 10의 100회 회차별 데이터: 총 길이 2시간 43분 50초, 16회부터 유료 표시, 구매 페이지 "10다이아부터". 제3자의 99회／161분 기준을 정정했다.
- 어미닭 그림(母鸡图)과 회차별 분업에 관한 원 인터뷰, 쉐바오 스튜디오(雪宝工作室)의 실명 Seedance 2.0 적용 기록, OpenClaw 실행 실패 세부 내용. 관련 스튜디오의 경험을 이 드라마의 기술 스택인 것처럼 꾸미지 않았다.
- 같은 계정의 다른 작품 및 후속 시즌 조합, 더우인 직접 유료화와 훙궈(红果) 방영의 상업적 관계.

원고의 가정 원가표, 권장 harness 아키텍처, 기준이 불분명한 제3자 추세 분석은 삭제했다. 구체적 모델, 소프트웨어 harness, 법인, 실제 이익은 여전히 프로젝트 자료로 뒷받침되지 않는다.
