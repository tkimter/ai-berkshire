# 수정판 검증 범위

검증일: 2026년 11월 2일. `python3 reports/지계입송심층조사-20261101/audit/run_audit.py` 를 실행하면 재계산할 수 있다.

이번 점검 범위:

- 공개 목록 43건의 ID 유일성, 회차가 있는 항목 39개와 0회 항목 4개; 《지계입송》(持械入宋) 10개 시즌의 회차 수와 표 전사.
- 시즌 10의 1~100회 연속성, 영상 ID 유일성, 회차별 길이, 유료 표시 경계, 최단／최장 회차, 평균, 중앙값, 길이 합계.
- 약 6.96억의 목록 표시 합계, 첫 시즌 비중 33.1%, 유료 구간 길이 비중 87.1%. 표시값은 반올림되어 있으며, 계산 정밀도가 플랫폼 원시값도 그만큼 정밀하다는 뜻은 아니다.
- 보고서 인용과 로컬 첨부 경로의 존재 여부; 제작진 자술, 모델 단서, 실제 배포 사이의 경계는 수작업으로 재검토했다.

`tools/report_audit.py extract` 를 실행했다. 이 금융 데이터 도구는 ratio가 1이어도 CLI 표본 상한을 30으로 둔다. 보조 스크립트가 별도로 전체 추출 함수를 호출해 추출점 60개 전부를 분류 점검했으며, 그중 55개는 기록／계산과 비교했고, 날짜·시간·모델 버전 성분 5개는 따로 열거했다. 표 추출기는 흔히 셀의 첫 번째 숫자만 인식하므로, 100회 원표와 추가 구절에는 보충 점검을 적용했고 범용 추출기의 출력을 완전한 감사로 취급하지 않았다.

`tools/financial_rigor.py calc` 와 Decimal 재계산을 재생 표시값 합계, 초 합계, 평균, 비중에 사용했다. 원고의 교육용 가정 원가와 제3자 화제성 하락폭 로그는 이번 실측 데이터 계산으로 대체했다.

상태 `LOCAL_CONSISTENCY_PASS` 는 로컬 전사와 산술 점검을 통과했다는 뜻일 뿐이다. 플랫폼 백엔드, 정산 명세서, 제작 프로젝트 파일이 없으므로 실제 트래픽, 실제 기술 스택, 재무상 이익을 인증하지 않으며, 두 번째 독립 재무 출처도 제공하지 않는다. 출처의 진위와 이 드라마의 모델/harness에는 기존 공백이 그대로 남아 있다.

- `audit-summary.json`: 범위, 건수 및 보고서／데이터 SHA-256.
- `numeric-results.json`, `extraction-exclusions.json`: 전체 추출점의 분류 결과.
- `decimal-calculations.json`, `financial-rigor-calculations.txt`: 계산 기록.
- `manual-scope.json`: 수작업 보충 범위와 미해결 문제.
