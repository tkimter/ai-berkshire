# 페이지 직접 수집 데이터

공개 웹페이지 수집 구간: 2026년 11월 1일 밤부터 11월 2일 새벽까지, 베이징 시간. 로그인, 구매, 백엔드 접근은 없었다. 플랫폼 페이지는 계속 갱신될 수 있으며, 아래는 당시 스냅샷이지 실시간 인터페이스가 아니다.

- `creator-catalog.csv`: 라오스이 극장(老十一剧场) "숏드라마" 탭의 목록 항목 43개 전체. 중국어 쉼표는 제목 내용에 속하고 영문 쉼표가 CSV 구분자다. `display_plays` 는 플랫폼의 원래 표시 단위를 유지하며, `paid_badge` 는 카드에 유료 표지가 나타났는지를 기록한다. 컬렉션 URL: `https://www.douyin.com/collection/{collection_id}/1`. 시즌 1의 2.3억은 거친 단위의 표시값이므로 10개 시즌 합계를 정밀한 재생수인 것처럼 내세울 수 없다.
- `season10-episodes.csv`: 시즌 10의 1~100회 연속 기록. 1회의 길이는 플레이어에서 읽었고 나머지는 목록 카드에서 읽었다. `paid_badge=false` 는 당시 목록에 유료 표지가 없었다는 뜻일 뿐이다. 영상 URL: `https://www.douyin.com/video/{video_id}`.

모든 ID는 문자열로 사용하며, 스프레드시트 소프트웨어로 가져올 때는 텍스트로 설정해 긴 정수의 정밀도 손실을 막아야 한다. 시청자 댓글, 개인 프로필, 출처 기사 전문은 저장하지 않았다. 회차가 있는 목록 39개를 원작 IP 39개라고 부르지 않았다.

시즌 10 구매 페이지는 이후 재생 3101.4만을 표시했고 목록은 당시 3092.5만이었다. 각각 따로 보존하며 같은 시계열로 섞을 수 없다. 구매 페이지의 "10다이아부터"는 시즌 전체의 확정 판매가가 아니다.
