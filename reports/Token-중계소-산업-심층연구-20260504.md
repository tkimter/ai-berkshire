# Token 중계소 산업 심층 연구: 비즈니스 모델, 이익률, 그리고 생사의 판

> **보고서 일자**: 2026-05-04
> **연구 대상**: OpenAI, Claude, Gemini, DeepSeek 등 대형 모델 API를 재판매/집계하는 제3자 서비스 사업자
> **연구 차원**: 비즈니스 모델 / 이익률 / 6개월-1년-3년 전망 / 차별화 생존 경로
> **중요 면책**: 중국 내 중계소의 거래액, 이용자 수, 먹튀 금액은 신뢰할 만한 제3자 감사가 거의 없다. 본문에서 "추정"으로 표시한 숫자는 모두 커뮤니티 차원의 규모 추측이다

---

## 1. 핵심 요약

| 핵심 판단 | 결론 |
|---|---|
| **좋은 사업인가?** | 단기 폭리, 장기 굴뚝 — **매출총이익 20-50%지만 실효 순이익률은 10-25%**, 그리고 기회의 창은 3년을 넘지 않는다 |
| **진짜 고객은 누구인가?** | Cursor/Cline 래핑 사용자(35%) + 개인 사용자(30%) + 소기업 PoC(25%) + 회색 산업(10%) |
| **6개월** | 가격 압축 지속, 상위 2-3개사 굳건, 롱테일은 계속 먹튀 |
| **1년** | 중국 내 컴플라이언스 분화, 순수 되팔이형은 절반 이상 사망, LLM Gateway로 전환한 곳은 생존 |
| **3년** | 독립 사업으로서의 중계소는 사실상 소멸, 생존자는 "AI 인프라 계층"으로 승격 |
| **차별화 생존의 핵심** | 컴플라이언스 + 멀티모델 라우팅 지능 + 기업급 SLA + Observability + 자체 추론 구축 |

**한 문장 정리**: **Token 중계소는 전형적인 "기회의 창 사업"이다 — 본질은 "모델 업체가 중국에 들어오지 않음 + 이용자가 비용/속도에 민감함"이라는 이중 불일치를 이용한 차익거래다. 그러나 모델 가격이 매년 5-10배 하락 + 대형 업체의 해외 노드 자체 구축 + 중국산 모델의 부상, 이 세 가지 힘이 이 생태계의 목을 조르고 있다. 3년을 살아남는 것은 더 이상 "중계소"가 아니라 "AI Gateway"다.**

## 2. 산업 지도

### 2.1 세 부류의 플레이어

```
글로벌 컴플라이언스 집계형(백색)
├─ OpenRouter        ← 멀티모델 라우팅 선두(500+ 모델 통합 API)
├─ Helicone          ← Observability + Gateway
├─ Portkey           ← LLM Ops 플랫폼
├─ LiteLLM (BerriAI) ← 오픈소스 + 기업용 클라우드 호스팅
├─ Together AI / Fireworks / Replicate ← 오픈소스 모델 추론 호스팅 위주
└─ Vercel / Cloudflare AI Gateway      ← 클라우드 업체 파생

중국 내 "우회 접속 재판매"형(회색)
├─ laozhang.ai (라오장)
├─ API2D
├─ CloseAI
├─ aiproxy.io
├─ chatanywhere
├─ openai-sb(이미 먹튀)
└─ 롱테일: one-api / new-api 오픈소스 프로젝트로 자체 구축한 소형 사이트가 도처에 있음

기업급 LLM Gateway(B2B)
├─ Kong AI Gateway
├─ TrueFoundry / Lasso / LangDB
└─ 중국 내: APIPark, 바이두 첸판, 알리바바 바이롄
```

### 2.2 Cursor/Cline 래핑의 진짜 배후는 누구인가?

**중국 내 개발자의 주된 사용법**: 중계소 API key를 Cursor, Cline, Continue 등 IDE에 설정한다. 이 부류의 사용자가 **중국 내 중계소 거래액의 약 35%를 기여한다** — 이들은 가격에 민감하지 않고(월 수십~수백 위안) 안정성에 민감하다.

## 3. 비즈니스 모델 해부

### 3.1 다섯 가지 수익 모델

| 모델 | 대표 플레이어 | 매출총이익 원천 | 실제 매출총이익률 |
|---|---|---|---|
| **마진 붙여 재판매** | API2D, CloseAI | 매입 X, 소매 1.0-1.3X | 20-30% |
| **충전 리베이트로 자금 묶기** | laozhang.ai | "100 충전 시 20 증정"으로 선불금을 묶어 두고, 예치 자금으로 이자 수익 + 먹튀 준비금 | 30-50%(자금 점유 포함) |
| **결제 채널 수수료** | OpenRouter | 마진 거의 제로, 5.5% 충전 수수료에 의존 | 5-10% |
| **기업 구독** | Portkey, Kong | $49-999/월 SaaS 요금 + 기업 license | 60-80%(전형적 SaaS) |
| **자체 추론 + 재판매** | Together AI, Fireworks | 오픈소스 모델을 직접 구동, 비용이 업체 정가보다 훨씬 낮음 | 40-60% |

### 3.2 중국 내 회색 사이트의 "예치 자금"이 진짜 이익 원천이다

```
이용자 충전 ¥10,000
├─ 즉시 차감되는 API 매입 원가: ¥0(이용자가 쓰지 않으면 차감되지 않음)
├─ 계좌에 예치: ¥10,000(플랫폼이 이자를 받을 수도, 유용할 수도, "먹튀"할 수도 있음)
└─ 실제 소진 주기: 3-12개월

→ 이 "미소진 잔액"은 업계 추정으로 전체 잔액의 40-60%를 차지
→ 이것이 중국 내 중계소의 진짜 "캐시카우"
→ 먹튀 붐의 근원이기도 하다 — 계좌에 돈이 많을수록 달아나고 싶어진다
```

### 3.3 OpenRouter의 "마진 안 붙이기"이 오히려 가장 안정적인 모델이 됐다

**OpenRouter는 token에 거의 마진을 붙이지 않는다**(일부 오픈소스 모델은 도매가 덕에 오히려 더 싸다). **5.5% 신용카드/Crypto 충전 수수료**로 수익을 낸다.
- 강점: 이용자에게 "마진을 떼인다"는 심리적 부담이 없어 규모를 빠르게 키운다
- 데이터: 2024년 초 월 거래액 $1-2M → 2024 Q4 월 거래액 $10M+ → 2025년 누적 token 1조 돌파
- **시리즈 A $40M(a16z + Menlo Ventures), 기업가치 $500M**(2025-05)
- **본질**: 스스로를 "Visa for AI Models"로 포지셔닝한다 — 결제 채널이지 중간상이 아니다

## 4. 이익률과 비용 구조

### 4.1 중국 내 회색 사이트의 전형적 손익계산서(연 거래액 ¥1,000만 중형 사이트 기준)

| 항목 | 비중 | 비고 |
|---|---|---|
| API 매입 원가 | **60-80%** | 가장 큰 항목 |
| 서버/대역폭/해외 회선 | 5-15% | 우회 접속 회선 비용 |
| 결제 채널(자금세탁 컴플라이언스 포함) | 3-8% | 위챗/알리페이/USDT 수금 리스크 비용 |
| 고객 응대 | 5% | 매우 무겁다, 단체방이 언제든 터진다 |
| **대손/계정 정지 손실** | **5-15%** | OpenAI/Anthropic의 부정 사용 방지 계정 정지 |
| **먹튀 리스크 준비금** | 5-10% | 자체 보유 완충 |
| **실제 순이익률** | **10-25%** | 표면 매출총이익보다 훨씬 낮다 |

### 4.2 세 유형 사이트의 순이익률 비교

| 유형 | 매출총이익 | 순이익 | 비고 |
|---|---|---|---|
| OpenRouter(컴플라이언스) | 5-10% | 3-7% | 규모에 의존 |
| 중국 내 회색 상위 | 30-50% | 15-25% | 예치 자금 점유 수익 포함 |
| 중국 내 회색 롱테일 | 20-30% | -10% ~ 10% | 계정 정지 한 차례면 파산 |
| 기업 Gateway(Portkey) | 70-80% | 20-30% | 전형적 SaaS |
| 자체 추론(Together AI) | 40-60% | 15-25% | 자본 지출이 크다 |

### 4.3 이익 공간이 "세 가지 힘"에 압축되고 있다

```
힘 1: 모델 API 가격이 매년 5-10배 하락
  GPT-4 Turbo $10 → GPT-4o $2.5 → GPT-4o-mini $0.15(67배 하락)
  Claude 3 Opus $15 → Sonnet 4 $3(5배 하락)
  → 마진 공간이 압축된다

힘 2: 중국산 모델 API가 극히 저렴해 중계로 남길 이익이 없다
  DeepSeek V3 $0.27/M token, 야간 반값 $0.135
  Qwen, Kimi 모두 가격 전쟁 중
  → 중국산 모델 중계는 매출총이익이 사실상 없다

힘 3: 모델 업체가 적극적으로 부정 사용 방지 + 계정 정지
  OpenAI는 2024-06부터 중국 IP를 대규모로 정지
  Anthropic은 2025년 중국 지배 실체의 Claude API 사용을 직접 금지
  → 대손 비용과 운영 비용이 늘어난다
```

## 5. 주요 사건과 리스크

### 5.1 먹튀 사례: openai-sb(2024)

**중국 업계에서 가장 유명한 먹튀 사건**:
- 2024년 초 돌연 서비스 중단
- 이용자의 미출금 잔액이 전해지기로 **1,000만 위안 이상**
- 단체방은 곧바로 해산
- 이후 연쇄적 "신뢰 위기"를 촉발, 여러 2·3선 사이트가 잇달아 먹튀

**메커니즘**: 충전 리베이트로 쌓인 "예치 자금"이 계좌에 점점 불어난다 → 사장의 마음이 흔들린다 → 달아난다

### 5.2 대형 업체의 태도 변화

| 업체 | 태도 | 중계소에 미치는 영향 |
|---|---|---|
| **OpenAI** | 중국 불진입을 명확히 하되 중계는 묵인(GTM 레버리지) | 중립~다소 긍정 |
| **Anthropic** | 2025년 중국과 능동적으로 단절 | **수혜**(회색 시장 수요 확대) |
| **Google Gemini** | 중국에 미개방, 태도 모호 | 중립 |
| **DeepSeek/Qwen/Kimi** | 자체 API가 극히 저렴 + 해외 노드 자체 구축 | **중계를 우회** |

### 5.3 규제 리스크

- 중국 내에서 "미등록 해외 대형 모델 호출"은 회색 지대이나 **집행은 엄격하지 않다**
- 국가인터넷정보판공실(网信办)은 중국산 모델에 "생성형 AI 서비스 등록" 절차를 적용하며, **해외 모델 중계는 명확히 단속 범위에 넣지 않았다**
- **예측**: 12-24개월 안에 명확한 집행이 나타나고 롱테일 사이트는 정리된다

## 7. 차별화 생존 경로(5가지)

### 7.1 경로 A: 컴플라이언스화 + 기업급(가장 어렵지만 가장 값지다)

**방법**:
- 정식 인허가 취득(중국에서는 "신통원(信通院)" + "부가통신" + "인터넷문화경영허가증")
- 기업용 세금계산서 제공
- 프라이빗 배포, SLA, SOC2 감사
- 해외 법인 + 중국 내 대리의 이중 구조

**목표 고객**: A주 상장사, 중앙·지방 국유기업, 금융기관
**매출총이익 공간**: 50-70%
**대표 비교 대상**: APIPark, Kong AI Gateway

### 7.2 경로 B: 지능형 라우팅(OpenRouter 모델)

**방법**:
- 100+ 모델을 집계하고, 작업에 따라 가장 저렴하면서 성능이 맞는 모델로 자동 라우팅
- fallback, 로드 밸런싱, 캐시 제공
- token에 마진을 붙이지 않고 수수료 + 부가 서비스에 의존

**목표 고객**: 전 세계 개발자, AI Agent 개발자
**매출총이익 공간**: 5-10%(얇지만 규모가 크다)
**대표 비교 대상**: OpenRouter

### 7.3 경로 C: 버티컬 산업 패키징

**방법**:
- 교육/법률/의료/고객 응대 중 한 버티컬을 겨냥해 prompt + RAG + 도구를 패키징
- 고객이 사는 것은 token이 아니라 "솔루션"이다

**목표 고객**: 버티컬 산업 SaaS, 콘텐츠 생성 회사
**매출총이익 공간**: 60-80%
**대표 비교 대상**: Cursor(프로그래밍 분야), Bizon AI(고객 응대 분야)

### 7.4 경로 D: Observability + LLMOps

**방법**:
- 고객 대신 token을 사지 않는다(고객이 모델 업체에 직접 충전)
- cost monitoring, prompt 버전 관리, PII 비식별화, 성능 모니터링 제공
- SaaS 구독 $99-999/월

**목표 고객**: 북미 중형 SaaS 회사, 기업 AI 팀
**매출총이익 공간**: 70-80%
**대표 비교 대상**: Helicone, Portkey, LangSmith

### 7.5 경로 E: 자체 추론 구축(자본이 가장 무겁다)

**방법**:
- GPU를 사서 추론 클러스터를 자체 구축
- Llama / Qwen / DeepSeek 등 오픈소스 모델 구동
- 가격을 모델 업체의 50%까지 낮춘다

**목표 고객**: 오픈소스 모델 사용자, 배치 추론
**매출총이익 공간**: 40-60%(단 capex가 막대하다)
**대표 비교 대상**: Together AI, Fireworks AI, Replicate

## 8. 지금 이 사업을 할 가치가 있는가?

### 8.1 진입 판단 매트릭스

| 당신의 상황 | 제안 | 이유 |
|---|---|---|
| **개인이 작은 부업으로 하려는 경우** | ❌ 하지 말 것 | 기회의 창이 너무 짧고, 먹튀 리스크가 높고, 기술 장벽이 낮아 과당경쟁에 죽는다 |
| **창업팀** | ⚠️ 처음부터 업그레이드 경로를 계획해야 한다 | 순수 중계 = 제 무덤 파기 |
| **이미 이용자/트래픽을 가진 팀** | ✓ 해도 되지만 빠르게 SaaS로 전환해야 한다 | token 중계로 유입시키고 최종적으로 구독을 판다 |
| **기업 내부** | ✓ LLM Gateway 자체 구축이 추세다 | Cost 거버넌스에 필요 |
| **투자하려는 경우** | OpenRouter 유형이 합리적 대상 | 다만 밸류에이션이 이미 높다($500M), 성장 여력은 관찰 필요 |

### 8.2 진짜로 "크게 키우기" 위한 4가지 필요조건

1. **컴플라이언스를 갖췄거나, 컴플라이언스에 아주 가깝거나** — 순수 회색 플레이어의 천장은 연 거래액 ¥5,000만이다
2. **채널/브랜드 우위가 있거나** — OpenRouter에는 a16z의 뒷받침 + 개발자 브랜드가 있다
3. **기술 차별화가 있거나** — 지능형 라우팅, 캐시, Observability 등
4. **버티컬 산업 lock-in이 있거나** — token을 파는 것이 아니라 솔루션을 판다

**"마진 붙여 재판매"만으로 크게 키우는 것은 불가능하다 — 이 사업의 가치는 모델 가격의 지수적 하락에 빠르게 희석되고 있다**.

## 9. 가치투자 관점

### 9.1 이것은 좋은 사업인가?

**7가지 기준으로 평가**(돤융핑/버핏의 "좋은 사업" checklist 참고):

| 차원 | 평점 | 비고 |
|---|---|---|
| 브랜드/IP | ❌ | 중계소 자체에는 브랜드가 없다 |
| 네트워크 효과 | ⚠️ | OpenRouter에는 약간 있다(모델 증가→이용자 증가→협상력 강화) |
| 전환 비용 | ❌ | 이용자는 언제든 갈아탈 수 있다 |
| 규모의 경제 | ⚠️ | 있으나 강하지 않다 |
| 장기 수요 | ❌ | **기회의 창 사업**, 3년 뒤 사실상 소멸 |
| 현금흐름 | ✓ | 단기 현금흐름은 괜찮다(예치 자금) |
| 자본 배분 | ❌ | 대부분의 플레이어는 돈을 들고 달아난다 |

**총평: 2-3 / 7, 좋은 사업이 아니다 — 전형적인 "단기 폭리, 장기 소멸" 모델**

### 9.2 어떤 역할이 투자할 가치가 있는가?

```
✓ 투자 대상:
  - OpenRouter 유형 컴플라이언스 집계(이미 a16z가 투자)
  - Portkey / Helicone / Langfuse 등 LLMOps SaaS
  - Together AI / Fireworks 등 자체 추론(중자본)

✗ 투자 가치 없음:
  - 중국 내 회색 중계
  - 개인 공동구매
  - 롱테일 되팔이
```

### 9.3 대형 업체가 직접 뛰어들 것인가?

| 업체 | 직접 중국에 들어와 token을 파는가? | 확률 |
|---|---|---|
| OpenAI | 진입 안 함 | <5% |
| Anthropic | 진입 안 함(이미 단절) | <5% |
| Google | 진입 안 함 | <10% |
| DeepSeek/Qwen | 해외 노드 자체 구축 | **>50%** |
| AWS Bedrock / Azure | 중국 내 클라우드 협업 | 중간 |

**결론**: 해외 업체는 **단기적으로 직접 중국을 서비스하지 않는다**. 중계소의 기회의 창은 최소 2-3년 더 남았다. 그러나 중국산 모델의 해외 노드 자체 구축이 시장을 대거 잠식한다.

## 10. 최종 판단

### 한 문장 요약

> **Token 중계소는 "기회의 창 동안 폭리, 3년 뒤 필사"의 사업이다 — 본질은 "모델 업체가 중국에 들어오지 않음 + 이용자가 비용/속도에 민감함"이라는 이중 불일치를 이용한 차익거래다. 단기 순이익은 상당하나(10-25%), 모델 가격의 지수적 하락, 대형 업체의 노드 자체 구축, 규제 강화라는 세 가지 힘이 이 생태계의 목을 조르고 있다. 3년을 살아남는 것은 더 이상 "중계소"가 아니라 "AI Gateway"다 — 이는 질적 변화이지 단순한 업그레이드가 아니다.**

### 세 가지 구체적 제안

1. **이용자라면**: 잔액을 너무 많이 쌓아 두지 말 것(먹튀 리스크), 월 단위로 충전한다
2. **창업자라면**: 진입 장벽이 낮다 → 반드시 죽는다. 첫날부터 "지능형 라우팅 + 기업급 + 버티컬 SaaS"의 업그레이드 경로를 계획해야 한다
3. **투자자라면**: 중계 단계를 건너뛰고 OpenRouter / Portkey / Together AI처럼 이미 "다음 정거장"에 있는 플레이어를 바로 본다
