## 결론부터

모델을 고르려면 세 가지 질문에 동시에 답해야 한다. 과제를 완수할 수 있는가, 한 번 완수하는 데 얼마가 드는가, 합법적으로 자체 배포할 수 있는가. 파라미터 수는 그중 일부에만 답한다.

이번 검색 시점 기준으로 글로벌 프런티어 제품에는 이미 GPT-6 Astra, Claude Fable 5.1 / Opus 5, Gemini 3.8 Flash / 3.1 Pro Preview, Grok 4.6, Muse Spark 1.3이 포함된다. 중국의 핵심 후보는 DeepSeek-V4, Qwen3.8, Kimi K3, GLM-5.3, MiniMax M3이다. 이들의 "플래그십"은 뜻이 서로 다르다. 어떤 것은 능력 상한이고, 어떤 것은 벤더가 주력으로 미는 프로덕션 모델이며, 어떤 것은 가중치를 내려받을 수 있는 가장 강한 제품이다. 본 보고서는 이 몇 가지 포지션을 각각 명시하고, 모델명의 숫자 크기로 순위를 매기지 않는다. [OpenAI 모델 페이지](https://developers.openai.com/api/docs/models/gpt-6-astra), [Claude 제품 매트릭스](https://platform.claude.com/docs/en/models/overview), [Google 모델 카탈로그](https://ai.google.dev/gemini-api/docs/models), [Grok 모델 카탈로그](https://docs.x.ai/developers/models), [Meta 제품 페이지](https://ai.meta.com/llama/). 중국 모델의 항목별 출처는 아래 표를 참조한다.

가장 먼저 바로잡아야 할 인식은 이것이다. **가중치를 내려받을 수 있다고 해서 추가 조건의 제약 없이 상업적으로 쓸 수 있는 것은 아니다.** Kimi K3, Qwen3.8-2.4T, GLM-5.3, MiniMax M3은 모두 자체 라이선스를 갖고 있고, GLM-5.3-Flash는 MIT다. 같은 회사라도 세대와 등급에 따라 전혀 다른 라이선스를 채택할 수 있다. [Kimi K3 라이선스](https://huggingface.co/moonshotai/Kimi-K3/blob/main/LICENSE), [Qwen3.8 라이선스](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B/blob/main/LICENSE), [GLM-5.3 라이선스](https://huggingface.co/zai-org/GLM-5.3/blob/main/LICENSE), [MiniMax M3 라이선스](https://huggingface.co/MiniMaxAI/MiniMax-M3/blob/main/LICENSE), [GLM-5.3-Flash 라이선스](https://huggingface.co/zai-org/GLM-5.3-Flash/blob/main/LICENSE).

## 범위와 판단 방법

"모든 플래그십"에는 권위 있고 고정된 전체 집합이 없다. 본문은 23개 주요 벤더 또는 연구 조직의 플래그십과 필요한 오픈 모델 대조군을 다룬다. 같은 가중치의 양자화판, 파인튜닝판, 서로 다른 API 날짜 스냅샷은 대체로 합쳐서 본다. 모든 지역 벤더, 산업 특화 모델, 연구소 내부 모델을 다루지는 않았다. 이미지 생성, 영상 생성, 음성 합성, 로봇 모델은 과제와 과금 단위가 다르므로 같은 순위표에 넣지 않는다.

표의 "우선 평가 용도"는 모델 설계, 인터페이스 기능, 공개 평가를 근거로 내린 선정 판단이며, 본 보고서가 실제로 돌린 점수가 아니다. 기반 모델, 채팅 제품, 도구를 실행하는 소프트웨어 환경은 각각 따로 본다. 모델이 도구를 호출할 수 있다고 해서 가중치를 내려받으면 브라우저, 웹 검색, 파일 관리, 컴퓨터 제어 기능이 자동으로 갖춰지는 것은 아니다.

개방 정도는 다음의 명확한 기준을 쓴다.

| 표기 | 본문에서의 의미 | 자체 배포 가능 여부 | 상업적 사용 판단 |
|---|---|---|---|
| 비공개 | 공개된 모델 가중치를 확인하지 못했고, 주로 제품/API로 제공 | 통상 가중치를 직접 얻을 수 없음, 기업 특약은 별개 | 서비스 계약에 따름 |
| 관대한 라이선스의 오픈 가중치 | 가중치가 MIT, Apache 2.0 등의 라이선스를 채택 | 가능, 단 연산 자원과 프레임워크 지원이 전제 | 통상 허용, 그래도 라이선스 의무는 이행해야 함 |
| 조건부 오픈 가중치 | 자체, 커뮤니티 또는 연구 라이선스 | 통상 다운로드 가능, 신청을 요구할 수 있음 | 상업 기준선, 용도, 재배포 조항을 조목조목 봐야 함 |
| 제한적 프리뷰 | 발표 또는 시연되었으나 접근 대상이 제한됨 | 이를 근거로 가중치가 개방되었다고 볼 수 없음 | 접근 허가 및 계약에 따름 |

이것은 **가중치와 라이선스 검증**이지, 각 모델이 완전한 "오픈소스 AI 정의"를 충족하는지에 대한 인증이 아니다. 완전한 개방에는 학습 코드, 데이터 설명, 수정과 재현에 필요한 자료도 포함된다. MIT/Apache 가중치 자체로는 학습 과정 전체가 재현 가능하다는 것을 증명하지 못한다. [OSI 오픈소스 AI 정의](https://opensource.org/ai/open-source-ai-definition).

## 결국 누가 더 강한가: 비교 가능 조건을 남겨야 점수를 읽을 수 있다

이번에는 유료 API를 실제로 돌려 측정하지 않았다. 아래는 평가 기관 자체의 원본 분석과 벤더가 공개한 원본 평가를 인용한 것이며, 두 종류의 증거를 명확히 구분한다.

### 독립 평가 스냅샷: 2026년 9월 3일

Artificial Analysis의 당일 Astra 특집은 아래 결과를 제시했다. Intelligence Index와 Coding Agent Index는 서로 다른 두 지표 체계이며, **두 열 사이에서는 크기를 비교할 수 없다**. 코드 열이 평가하는 것은 모델이 특정 도구 환경과 결합한 시스템 능력이다.

| 모델 및 평가 설정 | Intelligence Index | Coding Agent Index | 무엇을 말해 주는가 |
|---|---|---|---|
| Claude Fable 5.1, 최고 추론 등급, fallback 조건 포함 | 66 | 70, Claude Code | 이 스냅샷에서 선두. fallback 조건을 남겨야 함 |
| GPT-6 Astra, max | 61 | 67, Codex | 코드 실행 시스템에서 경쟁력이 강함. 범용 지수는 전 세대와 뚜렷하게 벌어지지 않음 |
| GPT-5.6 Sol, max | 61 | 65, Codex | 비용과 효과를 비교하는 중요한 기준점 |
| Claude Opus 5, Fable 5, Muse Spark 1.3 | 본 표는 글에서 추정하지 않음 | 본문은 약 67의 같은 수준으로 서술, 실행 환경은 제각각 | 같은 능력 구간이라는 점만 뒷받침할 수 있고, 이를 근거로 1위부터 4위까지 억지로 가를 수 없음 |

데이터는 같은 [Artificial Analysis 원본 평가 글](https://artificialanalysis.ai/articles/benchmarking-gpt-6-astra)에서 가져왔다. 마지막 행에는 정밀한 소수를 지어내지 않았다. 9월 6일의 동적 순위표는 테스트가 추가되거나 지수가 조정되었을 수 있으므로, 이 9월 3일 스냅샷과 직접 이어 붙일 수 없다.

여기서 내린 판단: **복잡한 과제의 상한을 추구한다면 Fable 5.1과 Astra를 1차 실측에 올릴 수 있다. 가격을 고려하면 Opus 5, Sol 및 다른 후보도 여전히 의미가 있다.** "더 최신", "입력 가격이 더 높다"는 것만으로는 모든 과제에서 더 유리하다는 것을 증명하지 못한다.

### 중국 오픈 모델: 과제 단위로 비교한다

Z.ai가 공개한 GLM-5.3 평가표에서 Terminal-Bench 2.1 점수는 GLM-5.3 88.2, Kimi K3 88.3, DeepSeek-V4-Pro-0813 87.9, Qwen3.8-Max 86.6이고, DeepSWE v1.1은 각각 66.9, 67.5, 62.7, 56.6이다. 이는 이 몇 개 모델이 모두 장기 과제 코드 후보풀에 들어갈 만하며, 과제에 따라 격차가 다르다는 것을 보여 준다. [Z.ai 원본 모델 카드 및 평가 각주](https://huggingface.co/zai-org/GLM-5.3).

**이것은 벤더가 공개한 데이터이며, 네 모델을 로컬의 통일된 환경에서 재측정한 결과가 아니다.** 모델 카드는 각 벤치마크에 서로 다른 도구 프레임워크, 시간 예산, 일부 자체 보정을 사용했고, 경쟁 모델의 숫자도 각자의 최고 결과를 재인용한 것일 수 있다. 0.1점 차이로 안정적 우위를 주장할 수 없고, 발표 당시 구 모델의 성적으로 오늘의 최신 플래그십을 대표할 수 없다.

엔지니어링 용도에서 보면 Kimi K3의 네이티브 시각과 장기 과제 능력, GLM-5.3의 코드 방향, DeepSeek-V4의 긴 컨텍스트 설계, Qwen의 다등급 생태계가 각각 후보로 올릴 이유가 된다. 최종 순서는 사용자의 중국어 자료, 코드 저장소, 출력 요구 사항이 결정해야 한다.

## API 비용: 단위를 먼저 통일한 뒤 가성비를 논한다

아래는 확인된 공식 표준 텍스트 가격이며, 단위는 **달러 / 100만 tokens**, 입력은 캐시 미적중 기준이다. 채팅 구독 가격이 아니다. 긴 컨텍스트, 캐시 쓰기, 도구, 우선 서비스는 별도 과금될 수 있다.

| 모델 | 입력 | 출력 | 청구액에 크게 영향을 주는 조건 |
|---|---:|---:|---|
| GPT-6 Astra | 10 | 50 | 입력이 272K를 넘으면 요청 전체의 입력/캐시 요율과 출력 요율이 오른다. Fast/Batch/Flex는 별도 요율이 있다. [공식 가격](https://developers.openai.com/api/docs/models/gpt-6-astra) |
| Claude Fable 5.1 | 10 | 50 | 추론 tokens, 캐시, 구체적 서비스 조건은 전체 과금 내용을 따로 볼 것. [공식 가격](https://platform.claude.com/docs/en/models/overview) |
| Claude Opus 5 | 5 | 25 | 위와 같음. [공식 가격](https://platform.claude.com/docs/en/models/overview) |
| Claude Sonnet 5 | 2 | 10 | 위와 같음. [공식 가격](https://platform.claude.com/docs/en/models/overview) |
| Grok 4.6 | 2 | 6 | 검색 등 도구는 별도 과금. [공식 가격](https://docs.x.ai/developers/models) |
| GLM-5.3 | 1.4 | 4.4 | 캐시 입력 0.26, 도구 비용은 별도 과금. [공식 가격](https://docs.z.ai/guides/overview/pricing) |
| GLM-5.3-Flash | 0.075 | 0.25 | 2026-09-09 24:00, UTC+8까지 한시 할인. 정가는 0.15 / 0.50. [공식 가격](https://docs.z.ai/guides/overview/pricing) |

나머지 벤더의 일부 가격 페이지는 지역, 스냅샷, 프로모션 또는 수집 실패 문제가 있어, 본 표는 제3자 호스팅 가격으로 공식 가격을 대체하지 않았다. 현재 과금은 [Google](https://ai.google.dev/gemini-api/docs/pricing), [DeepSeek](https://api-docs.deepseek.com/), [Kimi](https://platform.kimi.com/), [MiniMax](https://platform.minimax.io/docs/api-reference/api-overview), [Qwen](https://www.alibabacloud.com/help/en/model-studio/)에서 각각 확인할 수 있다. 이 가격표는 전체 시장의 최저가 순위가 아니다.

고정 token 사용량의 청구 예시: 요청 한 번에 입력 100,000 tokens, 과금 출력 합계 10,000 tokens, 캐시와 추가 도구를 쓰지 않을 때 Astra는 1.50달러, Opus 5는 0.75달러, Grok 4.6은 0.26달러, GLM-5.3은 0.184달러다. 계산식은 `입력 수량 / 1,000,000 × 입력 가격 + 출력 수량 / 1,000,000 × 출력 가격`이며, 프로젝트의 정밀 산술 도구로 재검증했다. 이는 동일 사용량에서의 비교일 뿐이다. 같은 과제를 완수하는 데 드는 추론 길이, 재시도 횟수, 성공률은 같지 않다.
