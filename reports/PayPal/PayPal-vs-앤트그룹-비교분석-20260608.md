# PayPal vs 앤트그룹: 두 결제 거인의 같은 점과 다른 점

> 분석일: 2026년 6월 8일
> 이 글은 어떠한 투자 권유도 아니다.

---

## 공통점

| 차원 | 공통 특징 |
|------|---------|
| 기원 | 둘 다 제3자 결제에서 출발했다(PayPal→eBay 생태계, 알리페이→타오바오 생태계) |
| 핵심 기능 | 둘 다 "구매자가 판매자를 믿지 못한다"는 신뢰 문제를 풀었다——중간에서 자금을 맡아 둔다 |
| 규모 | 둘 다 각자 시장의 결제 패자다(PayPal 글로벌 온라인 43%, 알리페이 중국 36%) |
| 슈퍼앱 야심 | 둘 다 결제에서 금융(대출, 자산관리, 보험) + 생활 서비스로 확장하려 했다 |
| 규제 압력 | 둘 다 강한 규제 타격을 겪었다(앤트 IPO 중단, PayPal은 영국 FCA 반독점 조사) |
| 밸류에이션 압축 | 둘 다 정점에서 크게 쪼그라들었다(앤트는 밸류에이션 2조에서 6000억으로, PayPal은 시가총액 3000억에서 364억으로) |

## 핵심 차이

| 차원 | PayPal | 앤트그룹 |
|------|--------|---------|
| **시장** | 글로벌(200+개국), 핵심은 미국/유럽 | 중국 중심, 국제화는 막 시작 |
| **기반 구조** | Visa/Mastercard 카드 네트워크 위에 지었다——**"전대인"** | 은행 계좌에 직접 연결, 카드 네트워크를 우회——**"집주인"** |
| **수수료 구조** | 3.49%를 받지만 절반을 카드 네트워크와 발급사에 나눠 주고 약 1.5%를 남긴다 | 요율이 더 낮지만(약 0.6%) 은행 직결이라 카드 네트워크에 나눠 줄 필요가 없다 |
| **이용자 고착의 원천** | 브랜드 신뢰 + 구매자 보호(기능 차원) | 소셜 관계 + 생활 장면 + 미니프로그램 생태계(생태계 차원) |
| **최대 위협** | 애플페이(운영체제 수준의 대체) | 위챗페이(소셜 장면 잠식, 점유율은 이미 60%로 역전) |
| **금융 사업** | 가볍게 진입(선구매 후결제, 대출), 스스로 축소 | 깊이 진입(화베이(花呗), 제베이(借呗), 위어바오(余额宝), 보험), 규제로 강제 축소 |
| **수익성** | 순이익률 약 16%, 잉여현금흐름 56억 달러 | 2025년 순이익 153억 위안(전년 대비 -60%), 연구개발 투입 290억으로 사상 최고 |
| **상장 상태** | 나스닥 상장, 시가총액 364억 달러 | 비상장, IPO는 지금까지 좌초 상태 |
| **AI 전략** | 리스크 관리 + 광고 + Fastlane 결제(응용 계층) | 앤트 아푸(蚂蚁阿福) + 바이링(百灵) 대형 모델(인프라 계층) |

## 매출 퍼널 비교

### PayPal

```
총결제액 1.79조 달러
    │ × 수수료율 1.73%
매출 332억 달러
    │ - 카드 네트워크/발급사/사기 비용 177억
거래이익 155억 달러
    │ - 운영비용 94억
영업이익 61억 달러
    │ - 세금
순이익 52억 달러 → 잉여현금흐름 56억 달러
```

전환율: 잉여현금흐름/총결제액 = **0.31%**

### 앤트그룹(추산, 데이터 제한적)

```
총결제액 약 118조 위안(2023년 알리페이 데이터로 추산)
    │ × 수수료율 약 0.06%(PayPal보다 훨씬 낮다)
매출 약 1,900억 위안(2023년 추정)
    │ - 운영비용
순이익 153억 위안(2025년, 시정 조치와 AI 투입 영향으로 급감)
```

전환율: 순이익/총결제액 = **약 0.001%**

### 핵심 차이

**PayPal의 수수료율(1.73%)은 앤트의 약 30배다**——PayPal이 돈을 더 잘 벌어서가 아니라 두 회사의 기반 구조가 완전히 다르기 때문이다:

- PayPal은 Visa/Mastercard 위에 지어졌고, 카드 네트워크 요율 자체가 높다(미국 신용카드 정산수수료 약 2%). PayPal은 그 위에 한 겹을 더 얹는다
- 앤트는 은행 계좌에 직접 연결하며 카드 네트워크라는 중간상이 없어 결제 사슬 전체의 비용이 더 낮다
- 중국 결제 시장은 위챗과 알리페이가 「거의 무료」라는 사용 습관을 길러 놓아 수수료 여지가 극히 제한적이다

## 가장 본질적인 차이

**PayPal은 카드 네트워크 생태계의 "부가가치 계층"이고, 앤트는 은행 체계의 "대체 계층"이다.**

PayPal의 모든 거래는 Visa/Mastercard의 철로를 지나며 "통행료"를 낸다. PayPal이 버는 것은 카드 네트워크 위에서 제공하는 "신뢰 + 편의" 프리미엄이다. 문제는 애플페이가 운영체제 고유의 능력으로 같은 수준의 신뢰와 더 나은 편의를 제공하면 이 프리미엄이 눌린다는 점이다.

앤트(알리페이)는 이용자의 은행 계좌에 직접 연결하며 카드 네트워크에 의존하지 않는다——중국에는 Visa/Mastercard라는 중간상 계층이 없다. 그 비즈니스 모델은 "철로 위의 서비스 사업자"보다 "철로를 직접 깐 쪽"에 가깝다. 다만 이는 은행과 규제 당국의 핵심 이익을 직접 건드렸다는 뜻이기도 해서 시정 조치도 더 가혹했다.

**PayPal의 천장은 카드 네트워크가 얼마를 벌게 해 주느냐이고, 앤트의 천장은 규제가 얼마를 하게 해 주느냐다.**

## 투자 시사점

| 차원 | PayPal | 앤트 |
|------|--------|------|
| 투자 가능성 | 매수 가능(나스닥 상장, PER 8.7배) | 당분간 투자 불가(비상장, 회수 경로 불명) |
| 밸류에이션 | 역사적 저점, 극단적 저평가일 가능성 | 밸류에이션이 2조에서 6000억으로 내렸으나 공개 거래 가격이 없다 |
| 핵심 베팅 | 브랜드 결제가 하락을 멈출 수 있는가 | 규제가 언제 풀리는가 + IPO가 언제 성사되는가 |
| 맞는 투자자 | 결제 산업이 범용화되지 않는다는 데 걸 의향이 있는 가치투자자 | 장기 락업 + 정책 불확실성을 감수할 수 있는 1차 시장 투자자 |
