# Adobe 재무 및 밸류에이션 분석

> 분석 차원: 이익의 질, 자본 배분, 내재가치, 안전마진
> 데이터 기준: 2026년 5월 | FY2025 연차보고서 + Q1 FY2026 실적 기준

---

## 1. 재무 개요: 돈 찍는 기계

| 지표 | FY2023 | FY2024 | FY2025 | Q1 FY2026 |
|------|--------|--------|--------|-----------|
| 총매출 | 194.1억 | 214.0억 | 237.7억 | 64.0억 |
| 매출 증가율 | 10% | 10% | 11% | 12% |
| GAAP 영업이익 | - | - | 87.1억 | - |
| Non-GAAP 영업이익 | - | - | 109.9억 | - |
| GAAP 순이익 | - | - | 71.3억 | - |
| GAAP 순이익률 | ~28% | ~29% | 29.5% | - |
| Non-GAAP EPS | - | - | $20.94 | $6.06 |
| 영업현금흐름 | - | - | 100.3억 | 29.6억 |
| 잉여현금흐름(TTM) | - | - | ~103억 | - |
| ARR(기말 값) | - | - | 252억 | - |
| ROIC | ~24% | ~26% | 33-41%* | - |

*주: ROIC 데이터는 산출 기준에 따라 차이가 있다. GuruFocus는 26%, ValuSense는 33%, 일부 출처는 41%로 제시한다.

**핵심 관찰:**

1. **매출 증가율이 가속하고 있다**: FY2023-2024의 10%에서 FY2025의 11%로 가속했고, Q1 FY2026에는 12%로 더 가속했다. 매출 규모 240억 달러의 회사로서는 드문 일이다.
2. **이익률이 매우 높고 안정적이다**: GAAP 순이익률 29.5%, 잉여현금흐름률 42%는 최상위 소프트웨어 회사의 재무적 특징이다.
3. **현금흐름의 질이 매우 좋다**: FY2025 영업현금흐름은 100.3억 달러, 잉여현금흐름은 약 103억 달러로, 순이익 대비 현금흐름 전환율이 100%를 넘는다. 이익이 "진짜 현금"이라는 뜻이다.

## 2. AI가 ARR을 끌어올리는 경로

Adobe의 AI 수익화 경로는 초기 윤곽이 드러났다:

**현재 기여:**
- Firefly 직접 매출 약 4억 달러(2024-2025 누적). 240억의 전체 규모에 비하면 아직 매우 작다.
- AI 관련 ARR은 전년 대비 3배 이상 증가했으나, 절대값은 아직 별도로 공시되지 않았다.
- 생성형 크레딧 소비량은 전분기 대비 45%+ 증가했다.

**세 가지 수익화 경로:**
1. **가격 인상에 내장**: AI 기능을 더 비싼 Pro 요금제(월 69.99 vs 54.99달러)에 묶어, 요금제 업그레이드로 수익화한다.
2. **소비형 매출**: 생성형 크레딧 팩(19.99달러/4000 크레딧). 구독 위에 얹는 증분 매출이다.
3. **기업용 서비스**: Firefly Foundry는 브랜드 맞춤형 AI 모델 학습을 제공하는, 대기업 대상 고부가가치 서비스다.

**추정(관점)**: AI 관련 매출이 향후 3년 내 총매출의 10-15%(즉 30-45억 달러)에 도달하면 Adobe의 성장 중심축이 뚜렷이 올라간다. 크레딧 소비량의 빠른 증가와 기업 고객의 도입률을 감안하면 이 목표는 실현 가능성이 있다.

## 3. 자본 배분: 경영진이 "자기 개밥을 먹는다"

**250억 달러 자사주 매입 계획(2026년 4월 발표):**
- Adobe 역사상 최대 규모의 자사주 매입 승인이며, 2030년 4월까지 이어진다.
- 250억 달러는 현재 시가총액(~990억)의 약 25%다. 경영진이 실제 돈으로 회사 가치에 대한 신뢰를 표현한 것이다.
- 현재 약 103억 달러의 연간 잉여현금흐름으로 계산하면, Adobe는 차입 없이 이 자사주 매입을 완료할 능력이 충분하다.

**자사주 매입의 EPS 증대 효과:**
Adobe가 4년 내 250억 달러어치 주식을 매입하면(평균 매입가 280달러 가정) 약 8900만 주가 줄어들며, 이는 현재 유통주식의 약 20%다. 매출 증가율이 10%에 머물더라도 EPS 증가율은 12-15%에 이른다.

**무배당 정책:**
Adobe는 배당을 지급하지 않으며, 자본 환원은 전부 자사주 매입으로 이루어진다. ROIC가 높은 성장형 회사로서는 합리적인 자본 배분 전략이다.

## 4. 밸류에이션 분석: 역사적 저평가 구간

**현재 밸류에이션 스냅숏(2026년 5월):**
| 지표 | 수치 |
|------|------|
| 시가총액 | ~989억 달러 |
| 주가 | ~$247(2026년 초 이후 약 30% 하락) |
| PER(GAAP) | ~19x(FY2025 순이익 71.3억 기준) |
| PER(Non-GAAP) | ~11x(Non-GAAP 순이익 89.4억 기준) |
| 주가/잉여현금흐름 | ~9.6x(TTM FCF 103억 기준) |
| 잉여현금흐름 수익률 | ~10.4% |
| EV/EBITDA | ~9-10x(추정) |

**역사적 비교:**
Adobe의 지난 5년 평균 선행 PE는 30-40x 사이였다. 현재의 19x GAAP PE(11x Non-GAAP PE)는 최근 10년 내 최저 수준이다. 시장 가격에 내재된 가정은 Adobe의 성장이 크게 둔화하거나 AI가 그 비즈니스 모델을 파괴한다는 것이다.

**내재가치 추정(보수적 DCF):**
- 향후 5년 매출 CAGR 10% 가정(과거와 일치)
- 잉여현금흐름률 42% 유지
- 영구 성장률 3%, 할인율 10%
- 도출된 내재가치는 약 **주당 350-400달러**
- 현재 가격 247달러, 안전마진 약 **30-40%**

**더 낙관적인 시나리오**: AI 수익화가 매출 증가율을 12-13%로 가속시키면 내재가치는 주당 400-450달러에 이를 수 있다.

## 5. 버핏 관점 요약

> "훌륭한 회사를 적정한 가격에 사는 것이 평범한 회사를 싼 가격에 사는 것보다 훨씬 낫다."

Adobe의 현재 상황은 한 걸음 더 나아간다: **훌륭한 회사를 싼 가격에 사는 것이다.**

- 10%의 잉여현금흐름 수익률은 ROIC 26%+, 성장률 10-12%의 소프트웨어 독점 기업으로서는 매우 매력적이다.
- 250억 달러 자사주 매입은 향후 수년간 EPS를 지속적으로 끌어올린다.
- 주요 리스크는 CEO 교체와 AI 경쟁의 불확실성이지만, 재무 펀더멘털은 매우 견고하다.

**밸류에이션 평가: 현재 가격대는 비교적 높은 안전마진을 갖추고 있으며, "좋은 회사를 좋은 가격에 사는" 기회에 해당한다.**
