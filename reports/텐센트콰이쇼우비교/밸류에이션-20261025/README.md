## 재계산

주 모델은 Python 표준 라이브러리만 있으면 되고, 금융 데이터 패키지를 설치할 필요가 없다. 아래 명령은 이 디렉터리에서 실행한다:

```sh
python3 model.py
python3 stress.py
python3 independent_check.py
```

`engine_crosscheck.py`와 `audit_report.py`는 연구 당시 로컬 저장소의 공유 도구를 추가로 호출한다. 이 공유 도구들은 이번 발행 범위에 속하지 않는다. 이번 입력, 결과, 감사 기록은 `audit/`에 저장되어 있으며, 위 세 개의 독립 스크립트로 본 보고서를 재계산하는 데 영향을 주지 않는다.

금액 모델 단위는 십억 위안, 주식 단위는 십억 주다. 보고서에서는 억 위안, 억 주로 바꿔 표시한다. 첫 해는 밸류에이션 기준일 이후의 온전한 12개월이며, 경제적 주식 수는 고정한다. 클링(可灵)의 음(-)의 현금 부담 비율과 양(+)의 수익 귀속 비율은 서로 다르다. 순 자사주 매입 0, 양(+)의 주주 현금의 35% 배당, 나머지 유보는 통일된 비교 가정이며 회사의 약속이 아니다.

이번에는 이 디렉터리의 연구만 발행하며, 기존 텐센트·콰이쇼우 보고서나 다른 작업 파일을 덮어쓰지 않는다.
