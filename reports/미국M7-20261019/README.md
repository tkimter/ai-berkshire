# 미국 주식 매그니피센트 7: 일곱 편의 독립 투자 연구

연구 일자: 2026년 10월 19일(베이징 시간). 시세는 2026년 10월 16일 미국 주식 정규장 종가로 통일했다. 재무 자료는 각 회사가 연구일까지 공시한 최신 보고서를 사용했으며, 구체적인 기간은 각 편의 첫 페이지를 참조한다.

저장소의 `skills/investment-research.md`에 따라 7개 병렬 경로로 일곱 회사를 각각 연구한 뒤 교차 검토했다. 회사마다 사업 판단, 재무 기준, 밸류에이션 가정을 독립적으로 세웠고, 보고서는 재계산, 데이터 출처, 감사 첨부물과 함께 보관했다. 본 디렉터리는 한 차례의 연구 스냅샷이며 시세에 따라 자동으로 갱신되지 않는다.

## 방법과 감사의 경계

- 각 보고서는 비즈니스 모델, 과거 및 최신 분기 재무, 해자, 경영진, 위험, 문명 기여, 밸류에이션, 종합 판단을 다루며, AI 연구에 있을 수 있는 편향을 명시한다.
- 수치는 저장소의 재무 도구와 로컬 Python으로 재계산했다. 10년 잔존가치는 영구 성장과 재투자 제약을 적용했고 할인율 민감도를 점검했다. 3년 밸류에이션과 10년 스트레스 시나리오의 관계는 보고서에서 설명하며, 10년 모델을 기계적인 일괄 부결 규칙으로 쓰지 않는다.
- 보고서 수치는 고정 난수 시드로 약 15%를 표본 추출했고, 추출, 판정, 이상 설명, 모델 설정을 보존했다. 도구 판정 통과가 보고서 전체의 모든 사실이 두 개의 독립된 외부 출처로 확인되었음을 뜻하지는 않는다.
- 감사는 외부 이중 출처, 단일 출처 또는 도출, 모델 재계산, 파서 오인식을 구분한다. 모델 가정의 산술적 일관성은 미래 결과에 대한 사실 검증과 같지 않다. 이중 출처 요건을 충족하지 못한 항목은 공백으로 남겨 두었고, 제3자 기준이 충돌하는 경우 원래의 차이와 채택 이유를 남겼다.
- 이번 교차 검토에서 마이크로소프트의 현재 배당, 테슬라의 지분 및 의결권 서술, 구글 보조 역DCF에서 금융자산을 중복 산입한 기준을 수정했다. 엔비디아 현금흐름 근사에서 SBC의 경제적 희석 비용을 차감하지 않았다는 한계를 보완 기재했다.

## 재계산 입구

저장소 루트 디렉터리에서 Python 3로 해당 스크립트를 실행한다. 재계산은 보관된 입력을 사용하며 시장 시세를 자동으로 수집하거나 갱신하지 않는다. 실행하면 같은 디렉터리의 결과와 일부 로그를 다시 쓴다. 보고서 본문에는 사람의 연구 판단도 포함되어 있으므로, 모델 스크립트만 실행하는 것이 연구를 다시 완료했음을 뜻하지는 않는다.
