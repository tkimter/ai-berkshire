## 항저우 중점 회사(7개사 상세 분석)

### 1. 유니트리 ★★★★✦(4.5성)

| 항목 | 데이터 |
|------|------|
| 설립 | 2016년, 창업자 왕싱싱(王兴兴, 90년대생, 전 DJI) |
| 제품 | 4족 로봇 Go/B 시리즈 + 휴머노이드 로봇 H1/G1 |
| 자금 조달 | 10회, IPO 밸류에이션 420억, 커촹반(科创板)에서 42억 조달 계획 |
| 재무 | **2025년 매출 17억(+335%), 순이익 6억(+674%), 매출총이익률 60.3%** |
| 경쟁 | vs 애지봇(국내), 테슬라 Optimus(글로벌) |

**투자 판단**: 중국 로봇 트랙에서 확실성이 가장 높은 종목이다. 흑자 + 고성장 + 높은 매출총이익률의 조합은 글로벌 로봇 업계에서 극히 드물다. 420억 밸류에이션은 약 70x PE에 해당해 비싼 편이지만 높은 성장률로 소화할 수 있다. 핵심 리스크: 휴머노이드 로봇의 대규모 응용 장면이 아직 열리지 않았다.

### 2. DeepSeek ★★★★(4성)

| 항목 | 데이터 |
|------|------|
| 설립 | 2023년 7월, 창업자 량원펑(梁文锋, 환팡퀀트(幻方量化) 수장) |
| 제품 | DeepSeek 시리즈 대형 모델(V2/V3/R1/V4), 오픈소스 |
| 자금 조달 | 첫 외부 자금 조달 500억 위안, 밸류에이션 3500억, 국가대기금이 리드 투자 협의 중 |
| 팀 | **단 139명**, 인재 밀도 세계 정상급 |
| 경쟁 | 글로벌 비교 대상은 OpenAI/Google DeepMind/Anthropic |

**투자 판단**: 국운급 종목이다. 극히 작은 팀과 극히 낮은 비용으로 세계 정상급 모델을 만들었고, 기술력은 이미 국제적으로 검증됐다. 핵심 리스크: 139명 팀의 취약성(이미 핵심 인력 5명이 스카우트됐다), 불분명한 상업화 경로(오픈소스를 어떻게 수익화할 것인가), 량원펑 개인 의지의 절대적 통제. 고배당률·고위험으로, 재무적 투자보다 전략 자본에 적합하다.

### 3. 크리스탈파이 ★★★★(4성)

| 항목 | 데이터 |
|------|------|
| 설립 | 2015년, MIT 양자물리학자 3인조 |
| 제품 | AI 기반 신약 발굴 플랫폼, 글로벌 Top20 제약사 중 17곳에 서비스 |
| 시가총액 | 홍콩 상장(2228.HK) |
| 재무 | **2025년 매출 8억(+201%), 순이익 2.58억(첫 흑자)** |
| 강점 | 일라이 릴리 3.45억 달러 대형 계약 갱신, 현금 70.7억 |

**투자 판단**: AI 신약 트랙에서 가장 안전한 종목이다. 흑자 + 대형 제약사 수주 + 넉넉한 현금. 홍콩 주식의 유동성 부족이 주된 리스크다.

### 4. 애지봇 ★★★✦(3.5성)

| 항목 | 데이터 |
|------|------|
| 설립 | 2023년, CTO "즈후이쥔(稚晖君)" 펑즈후이(彭志辉, 전 화웨이 천재소년), CEO 덩타이화(邓泰华, 전 화웨이 부총재) |
| 제품 | 위안정(远征)/징링(精灵)/링시(灵犀) 휴머노이드 로봇, GO-1 체화 기반 대형 모델 |
| 자금 조달 | 2년간 10+회, 밸류에이션 150억, 2026년 Q3 홍콩 IPO 계획 |
| 재무 | **2025년 매출 10.5억, 출하 5168대(글로벌의 약 40%)** |

**투자 판단**: 성장 속도는 놀랍지만 현금 소진이 거세다(자금을 조달하면서 동시에 스타트업 15곳에 투자). 150억 밸류에이션은 15x PS에 해당하며 적자 상태에서는 비싼 편이다. "즈후이쥔" 개인 IP에 지나치게 묶여 있는 점이 잠재 위험이다.

### 5. 성수 테크놀로지(Vidu) ★★★✦(3.5성)

| 항목 | 데이터 |
|------|------|
| 설립 | 2023년, 칭화계 + 앤트 + 바이두 BV 인큐베이팅 |
| 제품 | Vidu AI 영상 생성 대형 모델, 글로벌 순위 중국 1위·세계 2위 |
| 자금 조달 | B라운드 약 20억 위안, 밸류에이션 20억 달러 초과(150억 위안) |
| 재무 | ARR 2000만 달러 돌파, 사용자/수익 10배 초과 성장 |

**투자 판단**: 기술은 글로벌 2위권이지만 20억 달러 밸류에이션에 ARR은 2억 위안에 못 미친다(PS 극히 높음). 70명 팀은 빅테크 앞에서 규모 열세가 뚜렷하다. 탄력도 높고 변동성도 큰 종목이다.

### 6. 딥로보틱스(云深处科技) ★★★(3성)

| 항목 | 데이터 |
|------|------|
| 설립 | 2017년, 창업자 주추궈(朱秋国, 저장대 부교수) |
| 제품 | "줴잉(绝影)" 4족 로봇, 산업용 시장 점유율 80%+ |
| 자금 조달 | Pre-IPO 후 밸류에이션 약 90-100억 |
| 재무 | 2024년 매출 전년 대비 100% 증가, 3-5억 규모로 추정 |

**투자 판단**: 4족 로봇의 숨은 챔피언으로 산업용 시장 점유율이 매우 높다. 다만 4족 시장은 천장이 제한적이고 휴머노이드 제품 라인은 이제 막 시작했다.

| 항목 | 데이터 |

**투자 판단**: 대형 모델 전환이 초기 성과를 냈지만 해자는 의문이다. 범용 대형 모델이 강해질수록 버티컬 음성 회사의 가치는 낮아진다. 홍콩 주식 유동성이 나쁘고 주가 변동이 극심하다.

## 상하이 중점 회사(8개사 상세 분석)

### 8. MiniMax ★★★★(4성)

| 항목 | 데이터 |
|------|------|
| 설립 | 2021년, 창업자 옌쥔제(闫俊杰, 전 센스타임 부총재) |

### 9. 푸리에 인텔리전스 ★★★★(4성)

| 항목 | 데이터 |
|------|------|
| 설립 | 2015년, 창업자 구제(顾捷) |
