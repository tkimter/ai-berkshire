## 1. CUDA 해자는 구체적으로 무엇인가

**본질: 5개 층이 겹친 생태계, 19년(2006-2026)의 체계적 투자, 공격자는 5개 층을 동시에 뚫어야 한다**

| 층 | 내용 | 핵심 라이브러리 | AMD 대응 격차 |
|---|---|---|---|
| 1 | **하드웨어 추상화 계층** | CUDA Driver / Runtime(NVIDIA 칩과 같은 뿌리에서 개발) | ROCm/HIP 30%+ 뒤처짐 |
| 2 | **핵심 수학 라이브러리** | cuDNN(10만 줄) / cuBLAS / NCCL / TensorRT | MIOpen 30-50% 열세, RCCL 대형 클러스터에서 30%+ 열세 |
| 3 | **도메인 라이브러리** | cuDF / cuML / cuQuantum / RAPIDS / Modulus / Isaac | AMD는 거의 커버리지 없음 |
| 4 | **프레임워크 계층** | PyTorch / TF / JAX / vLLM CUDA 1st-class | ROCm은 2nd-class, 6-12개월 뒤처짐 |
| 5 | **애플리케이션 계층** | HuggingFace / TensorRT-LLM / SD / ComfyUI | 주류 모델의 80%를 부분 지원 |

**해자 = 5개 층의 곱 × 18년의 시간 × 엔지니어 4000명 × 개발자 500만 명**. Windows / Office / iOS에 견줄 수 있다.

**가장 깊은 구체적 해자 3가지**:
1. **TensorRT-LLM**: 추론 성능이 순수 PyTorch보다 3-10x 빠르다. AMD에는 대응 제품이 없다
2. **NCCL**: 1만 장 규모 all-reduce가 RCCL보다 30%+ 빠르다. GPT-5/Claude 4급 학습이 NVIDIA를 택하는 근본 이유다
3. **cuDNN**: GPU 세대마다 별도로 수작업 최적화해 하드웨어 한계의 90%+까지 끌어올린다. FlashAttention v2/v3 통합은 NVIDIA가 6-12개월 앞선다

## 2. AI 코딩 이후 해자는 어떻게 변하는가

**얕아지지만 무너지지는 않는다 — "절대적 락인"이 "비용 곡선"으로 눌린다**

### AI 코딩 능력의 진전(2024 → 2026)

| 시기 | 모델 | 성능 vs 수작업 | KernelBench correctness |
|---|---|---|---|
| 2024 | GPT-4 / Claude 3.5 | 30-50% 열세 | <50% |
| 2025 | Claude 4 / GPT-4.5 | 15-25% 열세 | ~70% |
| 2026 | Claude 4.7 / GPT-5 | **5-15% 열세** | 20% 사례에서 PyTorch와 동등 |

**상징적 사건**: 2026-01 Claude Code가 **30분 만에 CUDA 백엔드를 ROCm으로 이식**(HIPIFY 불필요).

### 변환 후 성능 보존율

| 경로 | 성능 보존 |
|---|---|
| 수작업 CUDA → 수작업 ROCm(최상급 엔지니어) | 95-100% |
| HIPIFY 자동 | 60-80% |
| **AI agent 변환(Claude/GPT-5)** | **70-85%** |
| Triton 크로스플랫폼 컴파일 | 85-95% |
| ZLUDA 바이너리 계층 | 80-95% |

### 무엇이 약해졌고 무엇이 여전히 견고한가

**약해진 것(개인/입문 층)**:
- ❌ 기초 CUDA C 작성법 → AI가 이미 변환할 수 있다
- ❌ 기초 행렬 연산 → torch.compile이 격차를 30%에서 15%로 줄였다
- ❌ 단순 추론 시나리오 → AMD MI355X의 TCO가 이미 역전했다

**여전히 견고한 것(산업/극한 층)**:
- ✅ TensorRT-LLM 극한 최적화(FP8/FP4/Speculative/Paged KV)
- ✅ NCCL 1만 장 규모 통신
- ✅ cuDNN 신규 알고리즘 최초 탑재
- ✅ **AI 코딩의 역방향 플라이휠**: 인터넷상 GPU 코드의 99%가 CUDA이고 LLM 학습 데이터도 CUDA에 치우쳐 있어, AI가 CUDA를 쓰는 편이 오히려 더 쉽다

### 5-10년의 변화

- **2026-2028**: ROCm/Triton 격차가 10-15%로 축소, NVIDIA 추론 점유율 75% → 60-65%
- **2028-2030**: 자동 최적화가 최상급 수작업의 90% 수준 도달, 추론 점유율 50-55%
- **2030+**: 하드웨어 무관 프로그래밍이 표준화되고, 해자는 하드웨어 + 네트워크 + 풀스택 AI 팩토리로 완전히 이동

## 3. 엔비디아의 해자에는 무엇이 있는가(종합 목록)

강도에 따라 5개 유형으로 나눈다:

### 1. 소프트웨어 생태계(가장 깊음, 5-10년)
- CUDA 5개 층의 곱
- TensorRT-LLM 추론 최적화(3-10x)
- NCCL 1만 장 규모 클러스터 통신
- cuDNN 딥러닝 프리미티브
- NIM 컨테이너화(동일 하드웨어에서 2.6x 향상)

### 2. 하드웨어 성능 우위(중-강, 1-2년)
- B200 vs MI300X: FP8 9 vs 5.2 PFLOPS(1.7x)
- GB200 NVL72: GPU 72개 NVLink 완전 상호연결, 1조 파라미터 추론 30x H100
- Rubin Ultra NVL576(2027 H2): 15 EFLOPS FP4, 경쟁 제품은 3년 내 대응 불가
- 연간 세대 교체: Hopper → Blackwell → Rubin → Feynman

### 3. 고객 관성 + 설치 기반(강)
- Hopper 5M+, Blackwell 1M+ GPU 배치 완료
- 전환 비용: 이전에 6-12개월, 성능 손실 10-30%
- CUDA 개발자 500만 명
- HuggingFace는 기본적으로 CUDA에서 검증

### 4. 시스템 단위 판매(고유, 2-3년 해자)
- DGX SuperPOD + NVL72/576 + Spectrum-X 네트워크 + BlueField DPU
- chips가 아니라 racks를 판다(GB200 NVL72 랙 한 대 $3-3.5M)
- DGX Cloud는 MS/Google/AWS/Oracle에 걸쳐 있다
- Run:ai 인수(GPU 스케줄링)

### 5. 공급망 + 방어적 인수(중)
- TSMC 4N/3nm 우선 생산능력
- HBM3E/HBM4 SK Hynix + Samsung 이원 공급
- CoWoS 전 세계 생산능력의 70%+ 점유
- **2025-12 $20B에 Groq 인수**(최대의 저지연 추론 위협 제거)
