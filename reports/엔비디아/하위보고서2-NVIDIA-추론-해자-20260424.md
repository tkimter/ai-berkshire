## 1. 핵심 판단

**해자 강도: 높음(데이터센터 추론)/ 중간(엣지)/ 낮음-중간(중국)**. NVIDIA 는 AI 추론 시장에서 여전히 **60-75% 점유율**을 차지하지만(FY2026 데이터센터 매출 $194B, 전체 시장 점유율 약 86%), 학습(>90%)과 비교하면 이미 분화가 시작됐다. **가장 깊은 해자는 CUDA + TensorRT-LLM + NIM 의 18 년 소프트웨어 스택 축적에서 나온다**——같은 하드웨어에서 소프트웨어 스택이 2.6-10x 의 성능 격차를 만든다. 향후 3 년간 삼중 협공에 직면한다: AMD MI355X 의 TCO 역전, 초대형 고객 ASIC(Maia/TPU/Trainium/MTIA)의 44.6% 증가율 물량 확대, 화웨이 Ascend 의 중국 내 35% 에서 50%+ 로의 상승. **NVIDIA 의 2030 년 추론 점유율은 50-55% 로 내려갈 것으로 예상되지만 매출 절대액은 여전히 2 배가 된다**. $20B 의 Groq 인수(2025-12)는 ASIC 위협을 방어하는 핵심 한 수다.

## 3. NVIDIA 추론 소프트웨어 스택(가장 깊은 해자)

### TensorRT(2017)
범용 GPU 추론 옵티마이저, FP8/FP4 양자화, Kernel fusion, 동적 형상. 성능은 PyTorch 네이티브 대비 5-10x.

### TensorRT-LLM(2023-09)
LLM 전용 설계: In-flight batching, Paged KV cache, Speculative decoding, 멀티 GPU tensor/pipeline 병렬. 100+ 주류 모델 지원.

### Triton Inference Server
다중 모델·다중 프레임워크(PyTorch/TF/ONNX/TRT-LLM/vLLM) 통합 서빙.

### NIM(NVIDIA Inference Microservices, 2024-03)
**최근 가장 중요한 제품**: 컨테이너화, 명령어 한 줄로 배치, TensorRT/TensorRT-LLM/vLLM/SGLang 다중 백엔드 내장.
- **2025-12 데이터: NIM 은 H100 에서 Llama 3.1 8B 를 1,201 tokens/s 로 돌린다. 최적화 없이 돌리면 613 tokens/s(2.6x 향상)**
- AWS / Google Cloud / Azure 전부 등재
- 기업 고객: Lowe's, Siemens, Box, Cohesity, Dropbox, NetApp, Hippocratic AI, Glean

**해자 논리**: CUDA → TensorRT → TensorRT-LLM → NIM 이 층층이 위로 올라가는 "성능 + 사용 편의성" 플라이휠을 이룬다. **같은 H100 하드웨어에서 NVIDIA 소프트웨어 스택은 유효 연산력을 경쟁 제품보다 2-3 배 높인다**.

## 4. NVIDIA 추론 해자의 5 대 차원

### 4.1 하드웨어 성능 우위(중간 해자)
- B200 vs MI300X: FP8 에서 9 PFLOPS vs 5.2 PFLOPS(1.7x)
- GB200 NVL72 vs 모든 경쟁 제품: 72 GPU NVLink 전체 상호연결, 조 단위 파라미터 추론 30x H100
- 그러나 AMD MI355X 는 FP8/FP4 에서 이미 B200 과 대등하다

### 4.2 소프트웨어 스택 성숙도(가장 깊은 해자)
- TensorRT 18 년 반복 개선, TensorRT-LLM 은 13 개월 동안 30+ 버전을 반복 출시
- vLLM CI 데이터: AMD ROCm 의 vLLM 테스트 통과율은 2025-11 에 37%, 2026-01 에 93% 로 상승
- Batch size 1-4(저지연)에서 H100 + TRT-LLM 이 MI300X + vLLM 보다 처리량이 20-30% 높다

### 4.3 모델 생태계(높은 해자)
HuggingFace 는 NVIDIA 가 기본값이고, 모든 선두 오픈소스 모델의 최초 최적화는 NVIDIA 에서 이뤄진다.

### 4.4 고객 관성 + 설치 기반(높은 해자)
전 세계에 5M+ Hopper, 1M+ Blackwell GPU 가 배치돼 있다. **전환 비용: 연 백만 달러 규모의 추론 부하를 ROCm 으로 옮기는 데 통상 6-12 개월, 성능 손실 10-30%**.

### 4.5 공급망 우위(중간 해자)
TSMC 4N/3nm 우선 생산능력, HBM3E/HBM4 는 SK Hynix 와 Samsung 이중 공급, CoWoS 는 전 세계 생산능력의 70%+ 를 점유.

## 11. 투자 함의(버핏 관점)

**해자 깊이 순위**: 소프트웨어 생태계 > 고객 관성 > 모델 생태계 > 하드웨어 성능 > 공급망. **소프트웨어 스택이 NVIDIA 밸류에이션의 진짜 주춧돌이다**——하드웨어 성능은 1-2 년 앞서고, 소프트웨어 성능은 3-5 년 앞선다.

**리스크 포인트**:
1. 초대형 고객 ASIC 이 2027-2028 년에 집중적으로 물량 확대
2. AMD MI400 시리즈가 ROCm/vLLM 을 TRT-LLM 과 100% 동등한 수준까지 끌어올리는 경우
3. 중국 시장은 사실상 영구 상실
4. 가격 탄력성이 이미 드러났다: B200 할인이 클라우드 고객 계약에 들어갔다

**결론**: NVIDIA 의 "AI 추론 인프라 선두" 지위는 적어도 2028-2029 년까지 유지된다. **Vera Rubin / Rubin Ultra 가 핵심 관찰 포인트다**——2027 H2 에 Rubin Ultra 가 제때 출시되고 성능이 예상에 부합하면 해자는 3 년 더 연장될 수 있다.
