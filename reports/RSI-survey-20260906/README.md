# RSI 중·영문 서베이 작업 원고

문헌 마감: **2026-09-06**. 여기서 RSI는 Recursive Self-Improvement(재귀적 자기개선)를 가리킨다.

약 6,500 영어 단어 분량의 비판적 서술형 서베이 한 편과, 약 11,300 한자 분량의 대응 중국어판을 완성했다. 두 판은 동일한 참고문헌 53건, 같은 핵심 사실 묶음, 같은 핵심 수식을 쓴다. 중국어판 끝에는 용어 대조표를 따로 붙였다. 확인되지 않은 저자, 소속, 이메일은 추가하지 않았고 arXiv에 제출하지 않았다.

## 논문의 위치

영문 제목: **Recursive Self-Improvement in AI: A Critical Survey of Mechanisms, Evidence, and Evaluation**

중국어 제목(번역): **인공지능의 재귀적 자기개선: 메커니즘, 증거, 평가에 관한 비판적 서베이**

논문의 주된 줄기는 답 하나를 고치는 것, 시스템을 지속적으로 바꾸는 것, 다음 차례 개선의 방법을 개선하는 것을 구분하는 일이다. 자기수정 코딩 에이전트, 모델 자기 편집, 자기 훈련, 자동화 연구에 대해 수정 대상, 피드백, 계승 관계, 실험 경계를 각각 살핀다.

기존 서베이는 "무엇이 진화하고, 언제 진화하며, 어떻게 진화하는가"와 개선 메커니즘의 수정 가능성 등의 주제를 이미 다뤘다. HGM도 현재 성능과 후손 산출 능력의 구분을 이미 제시했다. 본 논문은 이 연구들을 명시적으로 인용하며, RSI 분류, 수정 가능한 개선 메커니즘, metaproductivity를 처음 제시했다고 주장하지 않는다. 비교적 집중된 집필 각도는 이 문제들을 2026년에 등장한 새 평가 벤치마크, 개선자를 맞춘 대조, 자원 회계와 연결하는 것이다.

제시한 연산자 산출 지표와 평가 프로토콜은 종합적 방법 제안이며, 아직 실험으로 검증하지 않았다. 원고는 서술형 서베이로서 망라적인 체계적 문헌고찰이 아니며, 허구의 선별 총수, 통계적 메타분석, 재현 실험을 보고하지 않는다.

## 유지할 가치가 있는 핵심 한정

1. 현재 선별한 문헌은 경계가 있는 여러 형태의 자기개선을 뒷받침하며, 이를 근거로 범용적이고 지속적이며 비용 보정을 거친 재귀적 가속이 실현됐다고 선언할 수 없다.
2. 가중치 변화는 RSI의 필요조건도 충분조건도 아니다. 복합 시스템의 경계를 설명해야 한다.
3. "제로 데이터"는 특정한 사후 훈련 입력 조건을 기술하는 말이며, 사전 훈련, 환경, 사람이 설계한 감독 구조를 지우지 않는다.
4. DGM의 20%→50%는 논문 고유의 SWE-bench 부분집합 결과이며, 전체 공식 성적으로 바꿔 쓸 수 없다.
5. 자기개선의 역대 최고 곡선은 정의상 내려가지 않는다. 현재 시스템, 정당한 검증 선별 결과, 사후 감사 최적값을 점검해야 한다.
6. 2026년의 새 프리프린트는 저자 보고에 따라 처리한다. 서지 정보 대조는 독립 재현과 같지 않다.

## 컴파일

이 디렉터리에서 실행한다:

```bash
python3 research/build_bibliography.py
python3 build.py
```

Pandoc, pdfLaTeX, XeLaTeX, BibTeX가 필요하다. 영문 원고는 표준 TeX 글꼴을 쓴다. 중국어 원고의 `arxiv/preamble-zh.tex`는 현재 이 컴퓨터의 macOS 쑹티(宋体) 글꼴 경로를 쓰며, 컴퓨터를 바꿀 때는 설치된 중국어 글꼴로 바꾸면 된다. 영문 arXiv 패키지는 이 중국어 글꼴에 의존하지 않고, 중국어 원고나 그 글꼴 경로도 포함하지 않는다.

영문 제출 패키지만 컴파일할 때는 `arxiv/`에서 실행한다:

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

압축 파일에는 `main.tex`, `main.bbl`, `references.bib`, `figure-loop.tex`만 있으며 참고 논문 캐시나 임시 컴파일 파일은 포함하지 않는다. 본문의 서지 키는 Pandoc을 통해 정식 인용으로 변환된다.

## arXiv 제출 전 확정 단계

1. 실제 영문 저자명, 소속, 이메일을 보충한다. 저자마다 저자 표기에 동의하고 전문을 검토했음을 분명히 한다. 현재 어떤 개인 신원도 대신 채워 넣지 않았다.
2. 증거 대장에서 논점과 가장 관련 깊은 원문 단락을 사람이 재확인한다. 특히 새 프리프린트의 평가 설정과 한계를 확인한다. 개인 판단을 결합해 핵심 논증을 다시 쓴다. 더 강한 독창적 기여를 원한다면 6절의 연산자를 맞춘 실험을 수행한 뒤 결과를 원고에 넣을 수 있다. 서베이 원고 자체는 이 실험을 완료된 것으로 쓰지 않았다.
3. Markdown을 편집한 뒤 `build.py`를 실행한다. `arxiv/main.tex`를 직접 편집했다면 이를 덮어쓰는 생성 단계를 다시 실행하지 않는다. 저자 수정과 문장 수정은 같은 소스 파일 흐름에 보존해야 한다.
4. 영문 소스 패키지로 투고를 만들고, 내용에 맞는 분류를 고른다(우선 cs.AI를 고려할 수 있고, cs.LG/cs.CL로의 교차 등록 여부는 최종 원고의 중점에 달려 있다). 제목과 초록을 기입하고, 계정 상태에 따라 필요한 단계를 마친 뒤 플랫폼이 다시 컴파일한 PDF를 점검한다.
5. 작업 원고에는 실제 AI 보조 고지가 붙어 있다. 최종 저자는 실제 작업 흐름에 따라 그 표현을 확인하고 원고 내용에 책임을 져야 한다.

arXiv는 공식적으로 본문에 대응하는 소스 파일과 필요한 참고문헌 파일을 제출하도록 요구하고, 투고자가 다시 컴파일된 PDF를 점검하도록 요구한다. 자세한 내용은 [TeX 투고 안내](https://info.arxiv.org/help/submit_tex.html)와 [투고 개요](https://info.arxiv.org/help/submit/index.html)를 참조한다. 중국어판도 함께 제출할 계획이라면 먼저 [번역본 안내](https://info.arxiv.org/help/translations.html)를 확인하고 동일 저작물의 번역본으로 처리해야 한다. 본 산출물은 두 언어에 대해 중복 투고를 만들지 않았으며, 플랫폼 등재나 학술 동료 심사 결과를 보증하지도 않는다.
