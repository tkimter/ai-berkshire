# ai-berkshire 로드맵

> 원본 저장소(`xbtlin/ai-berkshire`)의 로드맵을 옮긴 것이다.

## P0: 단기 (1-2개월)

### 중국 A주 데이터 소스 연동
- akshare, 东方财富(Eastmoney) 등 무료 데이터 소스 연동
- A주 재무 데이터, 시세, 거래 상위 종목 공시 포괄
- 기존 Skill은 바꿀 필요 없이 데이터 계층만 확장한다

## P1: 중기 (3-6개월)

### HTML 보고서 출력
- Markdown에 더해 HTML 보고서 형식 추가
- 다크 모드, 내비게이션 바, 차트 시각화 지원
- 보고서의 전파력과 읽기 경험 개선

### 다단계 깊이 모드
- `lite`: 5분 속결. 밸류에이션 구간과 핵심 결론을 빠르게 낸다
- `standard`: 현재 기본 모드. 완전한 멀티 Agent 연구
- `deep`: 교차검증과 역사적 유추를 더한 기관급 깊이

### 여러 종목 가로 비교
- 종목 2-4개를 같은 차원에서 가로로 맞대결
- 같은 산업 기업의 밸류에이션 비교
- 비교 매트릭스와 우선순위 제안 출력

## P2: 장기 (6개월 이상)

### 테스트 커버리지
- 핵심 도구(financial_rigor.py 등)에 단위 테스트 추가
- Skill 출력에 회귀 테스트 추가
- 반복 개선이 기존 기능을 깨지 않도록 보장

### 포트폴리오 단위 분석
- 보유 포트폴리오 건전성 평가
- 산업/지역 집중도 분석
- 상관관계 리스크 탐지
