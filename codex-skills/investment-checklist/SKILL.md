## 실행 절차

### 1단계: 입력을 해석해 분석 대상 회사를 모두 식별한다

$ARGUMENTS 에서 모든 회사명/코드를 해석한다. 회사마다 다음을 확정한다:
- 회사 정식 명칭, 종목 코드, 상장 거래소
- 비상장 회사라면 "비상장"으로 표시하고 간단히 설명한 뒤(간접 투자 경로가 있는지) 전체 Checklist는 건너뛴다

### 1.5단계: AI 리서치 편향 사전 경고

회사마다 "정보 풍부도"를 빠르게 등급화(A/B/C)하고 보고서에 표기한다:

| 등급 | 판단 기준 | Checklist에 미치는 영향 |
|------|---------|-----------------|
| A급 | 상장한 지 오래되고 데이터가 충분 | 정상 수행하되 "컨센서스 함정"을 경계한다 — 모든 지표가 또렷해 보인다고 정말 확실한 것은 아니다 |
| B급 | 데이터가 제한적이라 추산 필요 | 추산한 지표마다 신뢰도를 표기하고, "좋은 사업" 판단에 데이터 신뢰성을 가중 반영한다 |
| C급 | 정보가 극도로 희소 | 여섯 관문 표를 억지로 채우지 않는다. "데이터 부족으로 판단 불가"라고 정직하게 표기하고, 검증 가능한 핵심 질문에 집중한다 |

**핵심 원칙**: Checklist의 목표는 **나쁜 선택을 배제하는 것**이다. C급 회사에서 "데이터 부족"은 "불통과"도 아니고 "통과"도 아니다 — AI가 표를 채우지 못한다는 이유로 부결하지 말고, "회색지대, 1차 정보 보완 필요"라고 정직하게 표기한다.

돤융핑은 이렇게 말했다: "이해하지 못한다"에는 두 종류가 있다 — 하나는 사업이 너무 복잡해서 정말 이해하지 못하는 것이고, 다른 하나는 아직 시간을 들여 들여다보지 않은 것이다. AI 리서치의 한계는 "자료가 적다"와 "이해하지 못한다"를 혼동하기 쉽다는 점이다.

### 2단계: 병렬 데이터 수집

Task 도구로 **회사마다** 독립된 백그라운드 Agent를 띄워 데이터를 수집한다(모든 회사를 동시에 병렬로 시작). 각 Agent가 수집할 항목:

1. **수익성**: ROE(5~10년 추세), 매출총이익률, 순이익률, 잉여현금흐름
2. **밸류에이션 데이터**: 현재 주가, 시가총액, PE(TTM), 선행 PE, PB, 배당수익률
3. **성장 추세**: 최근 3년 매출/이익 증가율
4. **재무 건전성**: 부채 수준, 자본적 지출 수요, 현금 보유액, 순현금/순부채
5. **경쟁 구도**: 시장 점유율, 주요 경쟁사, 점유율 변화 추세
6. **해자 증거**: 브랜드/전환 비용/네트워크 효과/규모 효과/기술 장벽의 구체적 증거
7. **경영진 기록**: CEO 이력, 핵심 의사결정, 지분 보유, 자본 배분 기록
8. **최신 동향**: 최근 6개월 중대 사건(실적, 인수합병, 규제, 경영진 변동 등)

#### 제1관문: 나는 이 사업을 이해할 수 있는가(능력범위)

반드시 답할 것:
- [ ] 이 회사가 무엇으로 돈을 버는지 한 문장으로 설명할 수 있는가?
- [ ] 10년 뒤에도 높은 확률로 어떤 사업을 하고 있을 것인가?
- [ ] 어떤 핵심 변수가 성패를 가르는가?
- [ ] 이 산업에 대한 인식은 깊이 있는 연구에서 나온 것인가, 주워들은 이야기에서 나온 것인가?

**평가 기준**(★1-5):
- ★★★★★: 비즈니스 모델이 지극히 단순하고 명확하며 10년 확실성이 높다(예: 마오타이 — 술을 빚어 판다)
- ★★★★☆: 모델은 명확하지만 기술 문턱이 있어 이해하려면 어느 정도 전문 지식이 필요하다
- ★★★☆☆: 모델은 이해할 수 있지만 10년 확실성이 높지 않고 산업 변화가 빠르다
- ★★☆☆☆: 사업 라인이 복잡하거나 산업이 격변 중이라 미래를 예단하기 어렵다
- ★☆☆☆☆: 능력범위를 완전히 벗어난다

**절대 부결**: 돈 버는 방식조차 설명하지 못하면 곧바로 "능력범위 밖, 분석하지 않음"으로 표시한다.

#### 제2관문: 이것은 좋은 사업인가(경제적 특성)


| 지표 | 해당 회사 수치 | 참고 기준 | 판단 |
|------|-----------|---------|------|
| ROE(5년 평균) | | >15% 우수, >20% 탁월 | |
| 매출총이익률 | | >40%는 가격 결정력을 시사 | |
| 잉여현금흐름 | | 지속적으로 플러스, ≈순이익 | |
| 자본적 지출 강도 | | 경자산이 중자산보다 낫다 | |
| 부채 수준 | | 이자부 부채/순이익 < 3년 | |

**평가 기준**(★1-5):
- ★★★★★: ROE>25%, 높은 매출총이익률, 강한 FCF, 경자산, 낮은 부채(전부 충족)
- ★★★★☆: 4개 항목 충족
- ★★★☆☆: 3개 항목 충족
- ★★☆☆☆: 2개 항목 충족 또는 추세 악화
- ★☆☆☆☆: 대부분 미충족 또는 FCF가 지속적으로 마이너스

### 4단계: 거울 테스트

회사마다 거울 테스트 문장을 작성한다:

> "나는 ___원에 ___회사를 매수한다. 이유는 다음과 같다:
> 1. 이 사업의 본질은 ___이고, 나는 그것을 이해한다;
> 2. 이 회사의 해자는 ___이며, 넓어지고 있다/좁아지고 있다;
> 3. 경영진은 ___하며, 신뢰할 만하다/신뢰할 만하지 않다;
> 4. 현재 가격은 내재가치의 ___% 수준으로, 안전마진이 충분하다/충분하지 않다;
> 5. 내가 틀리더라도 하방 위험은 통제 가능하다/통제 불가능하다. 왜냐하면 ___이기 때문이다."

**다섯 문장을 온전히 말하지 못하면 = 사지 않는다.** "통과" 또는 "불통과"를 명확히 표기한다.

---

### 5단계: 빠른 부결 목록

회사마다 항목별로 점검하고, 하나라도 해당하면 곧바로 "부결"로 표기한다:

- [ ] 이 회사가 어떻게 돈을 버는지 설명하지 못한다
- [ ] 3년 연속 잉여현금흐름이 마이너스이고 개선 조짐이 보이지 않는다
- [ ] 경영진에게 정직성 오점이 있다
- [ ] 경쟁 우위가 되돌릴 수 없이 침식되고 있다
- [ ] "다음에 받아 줄 사람이 더 높은 값을 치르는 것"에 기대어 돈을 벌어야 한다(더 큰 바보 게임)
- [ ] 이 투자가 0이 되는 결과를 감당할 수 없다
- [ ] 매수 이유가 주로 "남들이 다 사니까" 또는 "최근 많이 올라서"다
- [ ] 매수 이유를 200자 이내로 명확히 쓰지 못한다

### 7단계: 최종 결론과 파일 저장

회사마다 명확한 결론을 낸다(회피하지 않는다):
- ✅ **Checklist 통과**(X/6관문) — 심층 연구 단계로 넘어갈 수 있다
- ❌ **Checklist 불통과** — 어떤 레드라인이 발동됐는지 설명한다
- ❓ **회색지대** — 핵심 쟁점이 무엇인지, 투자자가 스스로 판단해야 할 것이 무엇인지 설명한다
- N/A — 비상장/매수 불가

## 출력 형식 요건

1. 회사마다 독립된 장으로 구성하고 다음을 담는다: 여섯 관문 평가표 + 핵심 데이터표 + 핵심 리스크(3~5개) + 거울 테스트 + 명확한 결론
2. 복수 회사일 때는 마지막에 종합 비교표를 붙인다
3. 모든 평가는 ★ 기호(★1-5)를 사용하고 반 개짜리 별은 쓰지 않는다
4. 데이터에는 출처 시점을 표기하고, 추정치에는 반드시 "추정"이라고 밝힌다
5. 글 끝에 맺음말을 붙여 버핏의 명언과 호응시킨다: "투자의 제1원칙은 돈을 잃지 않는 것이다"
6. 문체: 직설적이고 날카롭게, 군더더기 없이. 버핏/멍거/돤융핑의 어록을 곁들여 논평한다

## 핵심 원칙

- **놓칠지언정 잘못 사지는 않는다**: Checklist의 목표는 나쁜 선택을 배제하는 것이지 최고를 찾는 것이 아니다
- **능력범위를 정직하게 마주한다**: 이해하지 못하면 이해하지 못한다고 말하고, 억지로 분석하지 않는다
- **안전마진은 생명선이다**: 좋은 회사도 비싸게 사면 돈을 잃는다
- **거울 테스트는 건너뛸 수 없다**: 이유를 명확히 말하지 못하면 사지 않는다. 예외는 없다
