## 설계 이념

회사 연구는 투자의 절반일 뿐이다. 나머지 절반은 **포트폴리오 차원의 의사결정**이다:
- 얼마나 살 것인가?(비중)
- 어떤 돈으로 살 것인가?(자금 출처——신규 자금인가 종목 교체인가)
- 기존 보유종목과 충돌하지 않는가?(상관성)
- 최적의 포트폴리오는 어떤 모습인가?(기회비용)

버핏은 한 종목을 따로 떼어 놓고 보지 않는다——그는 늘 "이것이 내가 할 수 있는 최선의 일인가?"를 생각한다.

## 실행 절차

### 1단계: 보유종목 파싱

입력에서 현재 보유종목을 파싱해 다음 형식으로 표준화한다:

| 종목 | 코드 | 보유 수량 | 매입 단가 | 현재가 | 평가액 | 비중 | 손익 |
|------|------|--------|-------|------|------|------|------|

입력에 비율만 있고 금액이 없으면 비율 기준으로 분석하면 된다.

동시에 기존 포트폴리오 파일(`reports/portfolio-latest.md`)이 있는지 확인하고, 있으면 읽어서 갱신한다.

### 2단계: 최신 데이터 가져오기

Task 도구로 백그라운드 Agent를 띄우고, WebSearch를 통해 보유종목마다 다음을 병렬로 가져온다:
1. 현재 주가와 밸류에이션 지표(PE, PB, 배당수익률)
2. 최근 한 분기의 핵심 재무 변화
3. 최근의 중대 사건
4. 애널리스트 컨센서스(선행 PE, 목표주가)

보유종목마다 `tools/financial_rigor.py verify-valuation` 으로 밸류에이션 데이터를 검증한다. 보유종목마다 정보 충실도(A/B/C 등급)를 표기하고, C 등급 종목의 분석 결론에는 낮은 신뢰도를 표기한다.

### 3단계: 개별 종목 건강검진

보유종목마다 빠른 건강 점검을 한다:

| 종목 | 현재 PE | 매수 논리 변화 여부 | 논거 건전성 | 비중 제안 |
|------|:------:|:--------------:|:---------:|---------|
| 텐센트 | 18x | 변화 없음 | 8/10 | 적정 |
| 메이퇀 | 25x | 경쟁 심화 | 6/10 | 높은 편, 비중 축소 검토 |

보유종목마다 다음에 답한다:
- [ ] **오늘 이 종목을 갖고 있지 않다면, 현재 가격에 그래도 매수하겠는가?**
- [ ] **내일부터 거래할 수 없다면, 5년 보유해도 마음이 편한가?**
- [ ] **매수 논거는 아직 온전한가?**

**돤융핑**: "한 종목을 10년 동안 보유할 생각이 없다면, 단 하루도 보유하지 마라."

### 4단계: 포트폴리오 차원 분석

#### 4.1 집중도 분석

| 지표 | 현재 값 | 권장 범위 | 판단 |
|------|-------|---------|------|
| 최대 보유종목 비중 | | <40% | |
| 상위 3개 보유종목 비중 | | 50-80% | |
| 총 보유종목 수 | | 5-15개 | |
| 현금 비중 | | 10-30%(시장 환경에 따라) | |

**리루의 기준**: 핵심 보유종목 3-5개, 상위 3개가 80%+. **단, 이는 종목 하나하나를 철저히 연구했다는 전제가 필요하다.**

**버핏의 기준**: 핵심 보유종목은 10개를 넘지 않지만, 더 많은 위성 비중은 허용한다.

#### 4.2 상관성 점검

보유종목 사이의 숨은 연관성을 식별한다:

| 보유종목 A | 보유종목 B | 연관 유형 | 위험 |
|-------|-------|---------|------|
| 텐센트 | 콰이쇼우 | 둘 다 중국 인터넷 | 규제 위험 동조 |
| 엔비디아 | TSMC | AI 공급망 상·하류 | AI Capex와 같은 방향으로 변동 |
| 메이퇀 | 핀둬둬 | 둘 다 중국 소비 | 거시 소비와 같은 방향으로 변동 |

**체크리스트**:
- [ ] 비중의 50% 이상이 동일한 테마/산업에 노출되어 있는가?
- [ ] 비중의 50% 이상이 동일한 국가/통화에 노출되어 있는가?
- [ ] 미·중 관계가 악화되면 포트폴리오는 얼마나 손실을 보는가?
- [ ] 글로벌 경기침체가 오면 포트폴리오는 얼마나 손실을 보는가?

#### 4.3 기회비용 분석

이것이 버핏의 가장 핵심적인 사고방식이다——**돈 한 푼 한 푼이 수익이 가장 높은 곳에 놓여야 한다**.

모든 보유종목을 "기대 연환산 수익률" 순으로 정렬한다:

| 순위 | 종목 | 현재 비중 | 기대 연환산 수익률 | 확실성 | 기대 수익률×확실성 |
|:----:|------|:-------:|:----------:|:------:|:--------------:|
| 1 | | | | | |
| 2 | | | | | |
| ... | | | | | |

기대 수익률 추정 방법(`tools/financial_rigor.py three-scenario` 로 계산):
- **간이 공식**: 기대 연환산 ≈ FCF Yield + 기대 성장률(주된 방법)
- **가치형 검증**: 안전마진 회귀 + 이익 성장률 + 배당수익률
- **성장형 검증**: 이익 성장률 × 적정 PE의 변화

**핵심 질문**: 순위가 가장 낮은 보유종목의 기대 수익률이 현금(무위험 이자율 ~4%)보다 높은가? 그렇지 않다면 매도해서 현금으로 바꿔야 한다.

#### 4.4 스트레스 테스트

| 시나리오 | 가정 | 포트폴리오 예상 영향 | 최대 낙폭 |
|------|------|-----------|---------|
| 글로벌 경기침체 | 기업 이익 20-30% 감소 | | |
| 미·중 갈등 격화 | 중국 관련주 50% 할인 | | |
| 금리 급등 | 10년물 국채→6% | | |
| 기술주 버블 붕괴 | 기술주 PE 40% 압축 | | |

시나리오마다 정성 평가+개략 추정을 한다(각 보유종목의 산업 속성과 과거 밸류에이션 변동 범위에 근거):
- 어떤 보유종목이 가장 큰 충격을 받는가? 대략적인 영향 방향과 규모 범위
- 포트폴리오 전체가 견딜 수 있는가?
- 헤지가 필요한가?

## 핵심 원칙

- **돈 한 푼 한 푼에 기회비용이 있다** — 평범한 종목을 보유하는 비용은 우수한 종목을 놓치는 것이다
- **집중이 위험이 아니라 무지가 위험이다** — 깊이 이해하는 3개 종목을 보유하는 것이 어설프게 아는 30개 종목을 보유하는 것보다 안전하다
- **현금도 하나의 비중이다** — 좋은 기회를 찾지 못할 때 현금을 보유하는 것은 부끄러운 일이 아니다
- **포트폴리오 차원 > 개별 종목 차원** — 좋은 종목도 잘못된 비중에서는 발목을 잡는다
- **정기적으로 점검하되 과도하게 매매하지 않는다** — 분기에 한 번 점검하면 충분하다. 매일 시세를 보며 비중을 조정하지 않는다
