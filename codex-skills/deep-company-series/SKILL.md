## 2. 시리즈 편목 템플릿

### 편수는 회사 복잡도에 맞춘다(편수를 먼저 정하고 편목을 정한다)

**편수는 8로 고정되어 있지 않다.** 8편은 텐센트처럼 "다수 사업 + 조 단위 투자 포트폴리오 + 20년 경영진 스토리"를 가진 회사라야 감당할 수 있는 용량이다. 쓰기 전에 먼저 묻는다: 이 회사에는 "날카로운 질문 하나"로 독립된 글이 될 수 있는 주축이 몇 개인가? 있는 만큼만 쓴다.

| 복잡도 | 특징 | 편수 | 예 |
|--------|------|------|------|
| 높음 | 여러 사업 라인이 각각 하나의 사업 + 숨은 자산/투자 포트폴리오 + 경영진 사료가 풍부 | 7-8편 | 텐센트 |
| 중간 | 사업 라인 2-3개 + 중대한 시대 변수 하나 | 4-6편 | — |
| 낮음 | 주력 사업이 분명하고 핵심 질문이 적고 집중됨 | **3편** | 콰이쇼우 |

**3편의 표준 합치기 방식**(아래 8개 주축은 여전히 체크리스트이며 전부 다뤄야 한다. 다만 3편 안에 접어 넣는다):

| # | 편명 방향 | 접어 넣는 주축 |
|---|---------|-----------|
| 01 | 당신은 X를 이해했다고 생각한다(서두 + 사업과 해자) | 인식 재설정 + 해자 + 이익 엔진 개요 |
| 02 | X의 최대 변수(현재의 서사/숨은 자산) | 숨은 자산 + AI/시대 변수 |
| 03 | 얼마면 살 만한가, 어떤 신호면 반드시 팔아야 하는가(재무 + 의사결정 종장) | 재무 심층 + 경영진 요점 + 밸류에이션 의사결정 |

판단 신호: 어떤 편을 반쯤 쓰다가 "분량 채우기"(같은 사실이 표현만 바꿔 반복 등장)를 하고 있음을 깨달으면 편수를 너무 많이 잡은 것이다——합친다. 반대로 어떤 편이 12,000자를 넘어도 다 담기지 않으면 쪼갠다.

### 8개 주축 전체 템플릿(복잡한 회사용. 단순한 회사는 체크리스트로 삼아 접는다)

| # | 편명 템플릿 | 핵심 질문 | 글자 수 |
|---|---------|---------|------|
| 01 | 당신은 X를 이해했다고 생각하지만, 사실은 아니다 | 인식 재설정: 흔한 착각 3가지를 깬다 | 4,000-5,000 |
| 02 | X의 해자——`<사업 본질 한 문장>` | 해자는 깊은가, 향후 5/10년에도 남아 있는가 | 6,000-8,000 |
| 03 | X의 최대 이익 엔진——`<가장 돈 되는 사업>` | 주력 사업은 무엇이고 왜 지속될 수 있는가 | 6,000-8,000 |
| 04 | X의 장부에 숨은 또 하나의 회사——`<숨은 자산>` | 투자 포트폴리오 / 자회사 / 숨은 가치 | 8,000-10,000 |
| 05 | AI(또는 현재의 서사) 시대, X는 승자인가 패자인가 | 시대 변수: 사업별로 AI 영향을 분해 | 8,000-10,000 |
| 06 | 버핏의 방식으로 X의 실적을 해부한다 | 재무 심층: 매출총이익률/FCF/ROE/SBC | 8,000-10,000 |
| 07 | `<경영진 명언>`——X의 경영진은 맡길 만한가 | 자본 배분 규율 + 성실성 검증 + 후계자 | 8,000-10,000 |
| 08 | 얼마면 살 만한가, 어떤 신호면 반드시 팔아야 하는가(시리즈 종장) | DCF 3개 시나리오 + 레드라인 목록 + 포지션 프레임 | 10,000-12,000 |

`00-시리즈안내.md` 한 편을 목차 색인으로 추가하며, 발행하지 않는다.

**편목은 반드시 회사에 맞춘다**: 템플릿은 텐센트에서 자라난 것이지 틀에 끼워 맞추는 도구가 아니다. 어떤 편에 독립된 내용이 없으면(예: 투자 포트폴리오가 없는 회사는 04를 쓸 수 없다) 그 회사 고유의 주축(예: 콰이쇼우의 Kling AI, 이커머스)으로 대체하거나, 위의 합치기 방식대로 더 적은 편수에 접어 넣는다. 판단 기준: 이 한 편이 "날카로운 질문 하나"로 독립된 글이 될 수 있는가.

## 2.5. 편 내부 구조 템플릿(《看懂腾讯》 본문 8편에서 추출)

각 편은 자유 작문이 아니라 고정된 뼈대가 있다. 공통 구조:

- **머리 인용 블록**: `> 《X-제대로알기》 시리즈 · 제0N편 · <주축>`, 서두에 읽는 시간을 붙인다
- **첫 절은 언제나 훅이다**: 통념을 뒤집는 숫자 한 묶음 / 이상한 곡선 하나 / 시장을 걱정시키는 숫자 하나. 배경 설명은 깔지 않는다
- **각 편의 끝**: `## 이번 편 요점 정리`(5-8개, 숫자는 본문과 엄격히 일치) + `## 다음 편 예고`(날카로운 질문으로 예고하고 결론은 스포일러하지 않는다)
- **맺음 두 줄 이탤릭**: `*이 글은 《X-제대로알기》 시리즈 제0N편이다...*` + `*본 시리즈는 공개 정보와 가치투자 프레임에 기반한 연구이며, 어떠한 투자 권유도 아니다.*`

편별 전용 뼈대:

| 편 | 뼈대 |
|---|------|
| 01 서두 | 주가가 시장에 의해 거듭 "재규정"되어 온 역사 곡선 → 흔한 착각 세 가지(각각 실적 데이터로 깬다) → "안경을 동시에 몇 개 써야 하는가" 읽기 지도 표(02-08로 링크) → 밸류에이션 훅 숫자 표(궁금증만 남기고 결론은 주지 않는다) |
| 02 해자 | 도전자 실패 명단(이름·연도 명시) → 이전 비용의 본질(사용자가 옮겨 가지 못하는 것은 무엇인가) → 생태계 플라이휠 → 5년/10년 뒤에도 해자는 남아 있는가 → 역방향 사고 실험 하나("내게 1000억이 있다면 이것을 복제할 수 있는가") |
| 03 이익 엔진 | 통념을 뒤집는 숫자로 시작 → 핵심 제품은 왜 장수하는가(가격결정력 층위까지 분해) → 성장 여지의 정량화(점유율 경로 + 반대 논거: 스토리가 작동하지 않을 가능성) → 조직 역량(왜 제품을 계속 내놓을 수 있는가) → 시장은 왜 저평가하는가 → AI/시대 변수가 이 사업에 미치는 영향 → 5년 뒤의 그림 |
| 04 숨은 자산 | TOP 보유 종목 표(**연결되지 않은 부분만 집계**, 연결 대상은 별도로 설명해 이중 계산을 막는다) → 회계 처리의 차이(무엇이 손익계산서에 들어가고 무엇이 들어가지 않는가) → "팔지 않을 것 vs 줄일 수 있는 것" 분류 → 시장은 왜 할인하는가(항목별) → 뜻밖의 발견 몇 가지 → 할인율을 추정하는 간단한 방법 |
| 05 AI/시대 변수 | 시장을 걱정시키는 숫자 → 사업별로 승자/패자를 분해(심하게 갈리므로 전체 결론은 내지 않는다) → 핵심 반문("X가 단일 지점 싸움에서 졌다면, 그래도 이길 수 있는가") → 5-10년 내 우회당하는 시나리오 추론(항목별로 반박하거나 인정한다) → 5개 시나리오 → 향후 1년 모니터링 신호 목록 |
| 06 재무 | 이상한 곡선 하나로 시작 → 손익계산서(매출총이익률 변화의 원인 분해) → 기준 선택(Non-IFRS vs GAAP, 왜인가) → EPS와 자사주 매입 → 재무상태표(순현금) → 현금흐름과 FCF Yield → 주주환원을 "1달러 테스트"로 본다 → ROE 변화는 좋은 것인가 나쁜 것인가 → 밸류에이션 횡단+역사 비교 → 가치투자 10항목 Checklist를 하나씩 통과시킨다 → 실적을 세 문장으로 압축한다 |
| 07 경영진 | 핵심 팀 표 → 핵심 인물의 장기 기여(형용사가 아니라 구체적 결정으로) → 이해 일치(지분/보수의 이익 대비 비중) → **성실성 검증: 실제 위기 하나를 골라 대응을 본다** → 5년 약속 이행률(당시 발언 원문과 항목별 대조) → 자본 배분 규율 → 후계자 우려(회피하지 않는다) → "사람을 사는 세 가지 질문"(정직/유능/열정) → 종합 평점 |
| 08 의사결정 | SOTP 부문별 밸류에이션("당신이 사는 것이 도대체 무엇인가"를 분명히 한다) → 역사적 밸류에이션 분위 + **"백미러는 내비게이션이 아니다"를 반드시 경고** → 미래 이익 3개 시나리오 표(낙관/중립/보수 + 내재 성장률, "예측이지 사실이 아님"을 명시) → 레드라인 목록(발동≠반드시 매도, 단 반드시 재심) → 배당률(odds) 사고로 마무리 |

## 3. 글쓰기 스타일 규범

### 어조

- **직설적이고 날카롭게, 군더더기 없이**——첫 문장부터 숫자나 통념을 뒤집는 결론을 준다
- **가치투자 프레임**——버핏/멍거/돤융핑/리루의 관점을 섞어 넣는다(단, 명언을 쌓아 올리지 않는다)
- **입장을 미리 정하지 않는다**——먼저 데이터를 놓고, 다음에 논리를 전개하고, 마지막에 결론을 얻는다
- **정반 양면을 제시한다**——핵심 판단마다 "그러나 다른 한편으로..."의 반대편을 붙인다
- **공식계정 체감**——첫 18-20자가 반드시 독립적으로 설 수 있어야 한다(모바일 미리보기)

### 금지어

| 금지 | 이유 | 대체 |
|------|------|------|
| 당연히 / 필연적으로 / 틀림없이 | 주관적 절대화 | 데이터에 따르면 / 증거는 ~을 보여준다 |
| 내 생각에는 / 내가 보기에 | 주관적 말투 | 삭제하거나 "본 프레임에 따르면"으로 바꾼다 |
| 교과서급 / 신의 한 수 | 조회수용 찬사 | 구체적 사실을 서술한다 |
| 심각한 불일치 / 심각한 저평가 | 강한 주관어 | 구체적인 할인율(%)을 제시한다 |
| 완벽 / 흠잡을 데 없음 | 일방적 판단 | 반대편 관찰을 덧붙인다 |

### 제목 스타일

- **대비되는 숫자**나 **컨센서스에 반하는 결론**으로 훅을 건다("15년간 7번의 도전이 전부 실패", "연봉 4292만은 이익의 1만분의 1.65에 불과")
- 부제는 중립적으로 내용을 요약한다("——`<본질 판단>`")
- **조회수용 비유를 피한다**: "작은 버핏", "중국판 X", "YYDS"는 일절 쓰지 않는다
- 전문 독자에게 익숙한 용어를 쓴다("버핏"이 아니라 "버크셔", 사람 이름보다 회사 이름)

## 4. 엄격한 사실 검증 Checklist(핵심 IP)

### 쓰기 전부터 경계해야 할 "가짜 정밀" 함정

1. **확률 가중 기댓값**: `30% × A + 50% × B + 20% × C = 기대 +X%` 같은 계산은 거의 전부 쓰레기다——확률 배분은 순전히 주관이며 독자에게 잘못된 정밀감을 준다. **시나리오 + 발동 조건 + 방향만 나열하고 가중 기댓값은 계산하지 않는다**.
2. **제3자 추정 MAU/점유율**: QuestMobile/七麦/CBNData 등은 기준 차이가 매우 크다(같은 시점에 2-3배까지 차이 날 수 있다). **가장 신뢰할 만한 두 개만 비교해 anchor로 쓰고 나머지는 정성적으로 서술한다**.
3. **과거 성장률의 선형 외삽**: `2025년 +33% × 5년 복리 → 2030년 X`는 금융 문맹식 예측이다. **시나리오 가정 + 상/하단 구간 + 약속이 아님**.
4. **공개되지 않은 지분율**: 바이트댄스, Halti 같은 비상장사 지분율은 **공개된 적이 없다**. **구간으로 제시하고 "알 수 없음"으로 표기한다**.
5. **강한 원인 귀속**: 경쟁사의 실패 = X 때문이다. 복합적인 원인을 모두 나열하고, **본 글은 단일 원인 귀속을 하지 않는다**.

### 수정 시 반드시 돌리는 7가지 점검

```
□ 1. 편 간 숫자 일관성: 총 시가총액, Non-IFRS 순이익, 핵심 지분율 %를 시리즈 전체에서 맞춘다
□ 2. 기준 표기: Non-IFRS / GAAP / Non-IFRS-SBC / FCF 중 어느 것을 쓰는지 전문에서 분명히 한다
□ 3. 이중 계산 스캔: 이미 연결된 자회사는 "투자 포트폴리오"에 넣지 않고, SOTP에서 이중 계산하지 않는다
□ 4. 횡단 비교의 공정성: "주력 사업 PE(현금+포트폴리오 제외)" vs "경쟁사 PE(제외 안 함)"는 안 된다
□ 5. 확률 가중 전부 삭제: 위 항목 참조
□ 6. 절대화 표현 전부 약화: grep "당연히|필연적|심각|교과서|완벽"
□ 7. 제3자 데이터 출처 표기: 실적 외 데이터마다 뒤에 "(출처: X)"를 붙인다
```

### 모델 편향

쓰기 전에 **알려진 치명적 오류 리스크를 먼저 나열한다**:
- 과거 수익 배수: 반드시 누적 투입 기준을 쓴다(예: Riot은 58배가 아니라 33배)
- 지분율: 반드시 최신 富途(Futu)/실적 기준을 본다(예: 텐센트의 메이퇀 지분은 6.4%가 아니라 1.5%)
- "현물배당 분배" 회계 처리: 간주 처분이익은 IFRIC 17에 따라 배당 선언일에 인식한다(예: 징둥은 2021년, 메이퇀은 2022년이지만 금액이 작다)
- 총 주식 수는 반등한다: SBC가 연초에 집중 부여되면 주식 수가 단기적으로 늘어난다

## 5. 실행 흐름

### 1단계: 조사(01-02편을 쓰기 전에 완료)

1. 회사의 최근 5년 연간보고서와 최신 분기보고서를 읽는다
2. 독립적인 셀사이드 리서치 보고서를 최소 3건 읽는다(컨센서스 + 반컨센서스를 찾는다)
3. `/investment-team` 또는 `/investment-research`로 내부 연구초안을 먼저 생성한다
4. 사용자와 8편의 핵심 논점을 확인한다(다 쓰고 나서야 방향이 틀렸음을 발견하는 일을 막는다)

### 2단계: 집필(01→마지막 편 순서로 쓰고 건너뛰지 않는다)

- 각 편을 다 쓰면 먼저 `reports/{회사명}/《{회사명}-제대로알기》/0X-XX.md`에 저장한다
- **디렉터리 충돌 규칙**: `reports/{회사명}/《{회사명}-제대로알기》/`가 이미 존재하면(구판 시리즈) 덮어쓰지 않고 섞어 두지도 않는다——새 시리즈는 날짜 접미가 붙은 새 폴더 `reports/{회사명}/《{회사명}-제대로알기》-{YYYYMMDD}/`에 쓰고, 기존 폴더는 그대로 보존한다
- 바로 GitHub에 푸시하지 않는다——사용자 검토를 기다린다
- 사용자가 수정 의견을 내면 수정한다
- 수정이 끝난 뒤에야 git push 한다

### 3단계: 편 간 일관성 스캔(모든 편을 다 쓴 뒤)

Explore agent를 보내 시리즈 전체를 병렬 스캔하며 아래를 점검한다:
1. 같은 숫자(시가총액, 순이익, 지분율)가 편 간에 일치하는가
2. 같은 용어(FBS, SBC, Non-IFRS)가 처음 나올 때 설명되어 있는가
3. 인용 관계: 02편에서 "자세한 내용은 06편 참조"라고 했다면 실제로 대응하는가
4. 요점 정리 vs 본문의 숫자가 일치하는가

### 4단계: 발행 전 최종 검증

```bash
# 푸시 전에 반드시 로컬에서 grep을 한 번 돌린다(ai-berkshire 프라이버시 규칙에 따라)
grep -r "<로컬 사용자명>\|/Users/\|<개인 신원 정보>" reports/ | head
```

문제가 없음을 확인한 뒤에야 `git pull --rebase && git commit && git push` 한다.

## 6. 수정 의견 처리 흐름

사용자가 수정 의견을 주면 아래 순서로 처리한다:

### 1. 먼저 사실을 검증한다(곧바로 고치지 않는다)

사용자가 "X 데이터가 틀렸다"고 하면 먼저 Bash/Read로 원본 데이터를 찾아 교차 검증한다:
- ai-berkshire 프로젝트 안의 같은 회사 earnings/실적 보고서를 본다
- 富途(Futu)/공식 공시를 본다
- "사용자가 말한 데이터 vs 내가 찾은 데이터 vs 내가 이전에 쓴 데이터" 3자 비교를 제시한다

### 2. 수정 등급을 판단한다

| 등급 | 유형 | 처리 |
|------|------|------|
| 🔥 치명적 오류 | 숫자 오류, 원인 귀속 오류, 기준 오류 | 반드시 고친다. 망설일 필요 없다 |
| ⚠️ 주관화 | 강한 주관어, 절대화, 조회수용 비유 | 약화하거나 삭제한다 |
| 🔬 세밀도 | 출처 표기, 기준 세분화 | 우선순위 낮음. 가독성과 균형을 맞춘다 |
| ❓ 신뢰 불가 | 제3자 추정치의 편차가 큼 | **고치는 것보다 지우는 편이 안전하다**(사용자의 명시적 지시) |

### 3. 수정 후 연동 점검

한 곳을 고치기 전에 먼저 "이 숫자/개념을 또 어디서 인용하는가"를 생각한다. 예:
- 총 시가총액을 고쳤다 → 시리즈 전체에서 PE / 주력 사업 PE / 할인율 / FCF Yield를 연동 수정한다
- 지분율 %를 고쳤다 → TOP 10 순위 + 과거 지분 표 + 지분 축소 목록을 고친다
- 용어 기준을 고쳤다 → 최초 정의 + 이후 인용 + 요점 정리를 고친다

### 4. 푸시 후 즉시 보고

```
푸시 성공(commit hash).
[N]건 수정 요약 [표 포함]:
- 무엇을 고쳤는가
- 무엇을 연동 수정했는가
- 아직 고치지 않은 것은 무엇인가

다음 단계는 지시를 기다린다.
```

## 7. 본 skill이 하지 않는 일

- **독자를 대신해 투자 결정을 내리지 않는다**——모든 편의 끝에 "투자 권유가 아니다"를 붙인다
- **주가를 예측하지 않는다**——"시나리오 + 발동 조건"만 준다
- **"기대 연환산 수익률" 가중값을 계산하지 않는다**——주관적 확률 배분은 독자를 오도한다
- **"X 거물도 보유 중"이라고 쓰지 않는다** —— 남의 보유 종목으로 자기 판단을 보증하는 것은 가치투자에 반한다
- **8편을 다 쓰라고 강요하지 않는다**——어떤 편에 충분한 독립 내용이 없으면(예: 어떤 회사의 경영진이 그다지 특별하지 않다) 다른 편에 합치거나 편수를 줄인다

## 8. 컴플라이언스와 프라이버시

- 모든 공개 보고서는 **공개 정보만 쓴다**(실적, 공식 공시, 증권사 리서치, 저명한 제3자 기관)
- 어떠한 **사용자 개인 정보**도 쓰지 않는다(사내 닉네임, 내부 메신저, 공개되지 않은 보유 정보)
- 푸시 전에 반드시 grep으로 로컬 사용자명 / `/Users/` / 실명 등 프라이버시 필드를 스캔한다
- 공개 서명은 사용자의 다층 신원 전략을 따르고 섞어 쓰지 않는다
