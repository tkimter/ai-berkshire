# 공급망 병목 사냥꾼: AI 기반 글로벌 산업 사슬 병목 차익거래

$ARGUMENTS 슈퍼 트렌드에 대해 공급망 병목 스캔과 차익 기회 발굴을 수행한다.

## 핵심 이념

"AI가 어떤 주식을 추천하는가"를 묻지 않고, "이 트렌드가 계속 확장되면 어느 고리가 가장 먼저 모자라게 되는가?"를 묻는다.

전통적인 투자 연구는 선두 기업과 이미 알려진 분야를 본다. 이 시스템은 반대로 간다: **물리적 공급망의 목줄 위치에서 출발해, 아무도 주목하지 않지만 일단 공급이 끊기면 업계 전체가 멈춰 서서 기다려야 하는 회사를 찾는다**.

초과수익의 원천: 1층 병목(GPU, HBM, 전력)은 이미 충분히 가격에 반영됐다. 진짜 alpha는 **2층, 3층**에 있다——광모듈, 레이저, InP 기판, SOI 웨이퍼, 에피택시 장비, 웨이퍼 레벨 테스트, IC 기판, 특수 유리섬유 등.

## 1단계: 슈퍼 트렌드 확인

### 1.1 트렌드 선별 기준

작은 유행 속에서 환상을 찾지 않고, 아래 조건을 모두 충족하는 슈퍼 트렌드만 좇는다:

| 기준 | 요건 | 검증 방법 |
|------|------|---------|
| 지속성 | 최소 3-5년의 확실한 성장 | 산업 전망, 자본적 지출 계획 검색 |
| 물리성 | 실제 하드웨어/소재/장비 구축이 필요 | "소프트웨어 업그레이드"와 "물리적 증설"을 구분 |
| 규모성 | 글로벌 자본적 지출 >500억 달러/년 | 선두 플레이어의 capex 가이던스 검색 |
| 가속성 | 수요 증가율 > 공급 증설 속도 | 수요 증가율 vs 생산능력 확장 계획 비교 |

### 1.2 현재 추적 중인 슈퍼 트렌드 목록

실행할 때마다 갱신한다. 초기 목록:

1. **AI 인프라 구축** — 데이터센터, GPU 클러스터, 네트워크 인터커넥트, 전력
2. **에너지 전환** — 원전 재가동, 전력망 업그레이드, 에너지 저장
3. **국방 현대화** — 서방 군비 상승 사이클, 공급망 재편
4. **반도체 재산업화** — 미국·유럽·일본의 보조금 기반 공장 건설, 장비/소재 병목
5. **우주 경제** — 위성 인터넷, 발사 빈도 급증

사용자가 구체적인 트렌드(예: "AI 인프라")를 지정했다면 해당 트렌드에만 집중한다.

## 2단계: 공급망 물리적 분해

### 2.1 계층별 분해 프레임워크

**개념 수준에 머물지 않고 물리적 실체까지 분해한다**.

```
Layer 0(최종 단계): 최종 제품/서비스
    │
Layer 1(핵심 부품): 시장이 이미 충분히 주목하는 핵심 하드웨어
    │                 ⬆ 충분히 가격에 반영, alpha 제한적
    │─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    │                 ⬇ 관심도 낮음, alpha 집중 구간
    │
Layer 2(하위 부품/소재): 핵심 부품을 떠받치는 부품과 소재
    │
Layer 3(업스트림 장비/원료): 하위 부품 제조에 필요한 장비와 원재료
    │
Layer 4(인프라): 전력, 냉각, 토지, 인재, 인증
```

### 2.2 AI 인프라를 예로 든 분해 템플릿

```
Layer 0: AI 모델 학습/추론 서비스
Layer 1: GPU/가속기, HBM 메모리, 서버, 데이터센터
Layer 2(중점 스캔 구간):
  ├─ 네트워크 인터커넥트: 광모듈, 광섬유, 스위치 칩, 구리 케이블
  ├─ 광통신 핵심: 레이저(EML/VCSEL/CW), 변조기, 광검출기
  ├─ 반도체 소재: InP 기판, GaAs 기판, SOI 웨이퍼, SiC 기판
  ├─ 첨단 패키징: CoWoS 기판, HBM TSV, ABF 기판 필름
  ├─ PCB/기판: 고주파 고속 PCB, IC 기판, 특수 유리섬유 직물
  ├─ 테스트: 웨이퍼 레벨 테스트(Probe Card), 번인 테스트, ATE
  ├─ 방열/냉각: 액체 냉각 시스템, CDU, 침지 냉각액
  └─ 전력 연결: 버스덕트, UPS, 배전반, 변압기
Layer 3:
  ├─ 에피택시 장비: MOCVD, MBE
  ├─ 노광/식각: 특수 파장 노광, InP 식각
  ├─ 원재료: 고순도 금속(인듐, 갈륨, 게르마늄), 특수가스, 타깃재
  └─ 인증/표준: MSA 표준, Telcordia 인증
Layer 4:
  ├─ 전력: 원자력, 천연가스 발전, 송변전
  ├─ 냉각수/방열 인프라
  └─ 데이터센터 토지/인허가
```

## 3단계: 병목 식별——"목줄" 찾기

### 3.1 병목 판정 6가지 기준

Layer 2-3의 고리마다 항목별로 평가한다:

| # | 기준 | 질문 | 점수 |
|---|------|------|------|
| 1 | **공급 집중도** | 글로벌 공급업체 ≤3곳? | 🔴 ≤2곳 / 🟡 3-5곳 / 🟢 >5곳 |
| 2 | **증설 주기** | 신규 생산능력에 얼마나 걸리는가? | 🔴 >2년 / 🟡 1-2년 / 🟢 <1년 |
| 3 | **대체 난이도** | 다른 기술/소재로 대체할 수 있는가? | 🔴 대체 불가 / 🟡 부분 대체 가능 / 🟢 대체 용이 |
| 4 | **가동률** | 현재 가동률은? | 🔴 >90% / 🟡 70-90% / 🟢 <70% |
| 5 | **수요 증가율** | 다운스트림 수요 증가율은? | 🔴 >50%/년 / 🟡 20-50% / 🟢 <20% |
| 6 | **고객 검증 주기** | 신규 공급업체 진입에 검증이 얼마나 걸리는가? | 🔴 >1년 / 🟡 6-12개월 / 🟢 <6개월 |

**병목 등급**:
- 🔴🔴🔴 ≥4개 → **S급 병목**(단일 장애점 수준, 최고 우선순위)
- 🔴🔴 3개 → **A급 병목**(심각하게 제약됨)
- 🔴 1-2개 → **B급 병목**(압박은 있으나 통제 가능)
- 🔴 없음 → 병목 아님, 건너뛴다

### 4.1 S급·A급 병목마다 관련 상장사를 모두 찾는다

검색 방식:
- WebSearch "{병목 고리} supplier listed company"
- WebSearch "{병목 고리} manufacturer stock"
- WebSearch "{병목 제품} market share company"

### 4.2 1차 선별 기준(빠른 필터링)

| 기준 | 요건 | 이유 |
|------|------|------|
| 상장 상태 | 상장 완료(A주/홍콩/미국/일본/대만/유럽) | 거래 가능 |
| 병목 사업 비중 | 매출의 >30%가 병목 고리에서 발생 | 순도 |
| 시가총액 | <100억 달러 우선 | 대형주는 이미 충분히 가격에 반영됨 |
| 유동성 | 일평균 거래대금 >100만 달러 | 진입·청산 가능 |

### 4.2.1 밸류에이션 점검(반드시 수행, 건너뛸 수 없음)

**병목이 진짜라는 것 ≠ 투자 기회.** 회사마다 반드시 PS, PE를 계산해 보고서에 표기한다. 아래의 조합 조건으로 밸류에이션이 선반영 과다인지 판단한다:

#### 밸류에이션 빨간불(하나라도 해당 → 신호 강도 상한 ★★, "⚠️ 밸류에이션 선반영 과다" 표기)

1. **시가총액 > TAM의 20%**: 회사 시가총액이 도달 가능한 시장 규모의 20%를 이미 넘었다면 성장 기대가 과도하게 내재화된 것이다
2. **PS > 30x 이면서 매출 증가율 < 100%**: 밸류에이션은 높은데 증가율이 받쳐주지 못한다. 증가율 >100%인 회사는 PS 빨간선을 면제할 수 있으나, 여전히 "⚠️ 고밸류에이션은 높은 증가율의 지속 검증이 필요"라고 표기해야 한다
3. **시가총액 > 5년 낙관 매출 전망의 10배**: 가장 낙관적인 가정이 모두 실현돼도 현재 가격은 여전히 지나치게 높다
4. **증자 후 60일 이내 주가 두 배**: 심리 주도의 특징이 뚜렷하다. 신호 강도를 한 단계 낮춘다

#### 밸류에이션 노란불(추가 설명이 필요하며, 없으면 강등)

1. **적자 + PS > 15x**: ★★★ 진입은 허용하되 흑자 전환 경로와 일정을 반드시 설명한다
2. **PS가 동종업계 흑자 회사의 5배 이상**: 프리미엄의 원천(시장점유율, 증가율 격차, 장벽 차이)을 반드시 설명한다
3. **PE > 80x**: PEG를 계산하고 증가율이 받쳐주는지 설명해야 한다

#### 밸류에이션 초록불(가점 항목)

- PS < 10x 이면서 매출이 성장 중 → 신호 강도를 한 단계 올릴 수 있다
- PE < 30x 이면서 해자가 있음 → "밸류에이션에 안전마진이 있음"이라고 표기한다

#### 밸류에이션 합리성 검증(필수)

종목마다 다음에 답한다: "현재 시가총액에 매수하고, 가장 낙관적인 시나리오가 모두 실현된다고 가정해, 10년 뒤 25x PE로 엑시트하면 연환산 수익률은 얼마인가?" 연환산 수익률 <10% → "현재 가격에는 안전마진이 없음"이라고 표기한다.

**주의**: 밸류에이션 점검의 목적은 "PS 100배의 적자 회사"를 추천하는 식의 명백한 오류를 막는 것이지, 고밸류에이션 초기 회사를 모두 배제하는 것이 아니다. 핵심은 증가율, TAM, 경쟁 구도가 현재 밸류에이션을 받쳐줄 수 있는가이며, 일률적으로 자르지 말고 구체적으로 분석해야 한다.

**대만 주식 종목 데이터 조회**: 공급망 스캔은 대만 주식(4자리 숫자 코드, 예: 2330, 3661)에 자주 닿는다. 시세/PER/시가총액/월 매출은 `python3 tools/twstock_data.py`로 통일해 가져온다(FinMind 데이터 출처, 사용법은 `skills/financial-data.md` 대만 주식 장 참조). 대만 주식은 매월 10일 이전에 전월 매출을 의무 공시하며, 월 매출 전년 동기 대비 증가율은 병목의 "물량·가격 동반 상승"을 검증하는 가장 빠른 공개 신호다.

### 4.3 심층 선별 차원

1차 선별을 통과한 회사를 하나씩 평가한다:

```
## {회사명}({코드})

**병목 포지셔닝**:
- 공급망에서의 구체적 위치
- 시장점유율: 글로벌 X위, 비중 XX%
- 고객 명단(알려진 것)

**생산능력과 확장**:
- 현재 생산능력 / 가동률
- 증설 계획 / 일정
- 증설에 필요한 자금 vs 보유 현금

**재무 스냅숏**:
- 시가총액 / 매출 / 이익 / 증가율
- 병목 사업 매출 비중
- 매출총이익률 추세(병목이 조일수록 매출총이익률은 올라가야 한다)

**리스크 체크리스트**:
- [ ] 대체 기술 리스크: 우회될 수 있는가?
- [ ] 희석 리스크: 대규모 증자/전환사채가 있는가?
- [ ] 지정학 리스크: 민감 지역에 있거나 수출 통제를 받는가?
- [ ] 경영진 리스크: 불량 이력이 있는가?
- [ ] 고객 집중 리스크: 단일 고객에 지나치게 의존하는가?
- [ ] 밸류에이션 선반영 과다: 현재 밸류에이션이 이미 3년 성장을 반영했는가?

**병목 지속성 판단**:
- 이 병목은 언제 해소되는가?
- 해소된 뒤 이 회사에는 무엇이 남는가?
- 일회성인가 지속적인가?
```

### 5.1 정방향 검증

| 검증 항목 | 질문 | 검색 방식 |
|--------|------|---------|
| 고객 검증 | 선두 고객이 이미 계약/도입했는가? | 회사 공시, 고객 실적 발표에서의 언급 검색 |
| 매출 검증 | 병목이 이미 매출 성장에 나타났는가? | 최근 2-3개 분기 실적 검색 |
| 가격 검증 | 제품 가격이 오르고 있는가? | 업계 시세, 애널리스트 보고서 검색 |
| 생산능력 검증 | 생산능력이 정말로 빠듯한가? | 리드타임 데이터, 고객 불만 검색 |
| 자본 검증 | 증설 자본적 지출이 있는가? | 회사 capex 가이던스 검색 |

### 5.2 역방향 검증(멍거식 부정)

| 역방향 질문 | 의미 |
|---------|------|
| 똑똑한 사람들은 왜 이 주식을 사지 않는가? | 알려진 bearish 논점을 찾는다 |
| 이 병목은 우회될 수 있는가? 어떤 대체 경로가 있는가? | 기술 경로 리스크 |
| 중국/다른 플레이어가 생산능력을 빠르게 복제할 수 있는가? | 공급 충격 리스크 |
| 최종 수요가 50% 둔화하면 이 회사는 어떻게 되는가? | 하방 민감도 |
| 경영진이 과거 고점에서 증자로 희석한 적이 있는가? | 경영진 신뢰도 |
| 현재 밸류에이션에는 어떤 성장 가정이 내포되어 있는가? | 밸류에이션 합리성 |

### 5.3 신호 교차 검증

- 같은 병목의 여러 회사가 모두 오르고 있는가?(업종 검증)
- 다운스트림 고객이 실적 발표에서 공급 부족을 언급했는가?(고객 검증)
- 업종 협회/연구기관에 관련 데이터가 있는가?(제3자 검증)

## 6단계: 출력——병목 기회 대시보드

### 6.1 병목 기회 순위표

| 순위 | 회사 | 코드 | 시가총액 | 연 매출 | PS | PE | 병목 고리 | 병목 등급 | 시장점유율 | 매출 증가율 | 신호 강도 | 밸류에이션 판단 |
|------|------|------|------|--------|-----|-----|---------|---------|---------|---------|---------|---------|
| 1 | | | | | x | x | | S/A | | | ★1-5 | 합리/다소 높음/선반영 과다 |

**필수 필드**: 시가총액, 연 매출, PS, PE는 필수 항목이며 "확인 예정"으로 건너뛸 수 없다. 재무 데이터를 얻을 수 없으면 신호 강도는 ★★를 넘을 수 없다.

신호 강도 등급(밸류에이션 점검 결과가 등급에 직접 영향을 준다):
- ★★★★★ 다중 교차 검증, 고객 도입 완료, 매출에 이미 반영, 밸류에이션 초록불(PS 합리적+흑자 또는 흑자 근접)
- ★★★★ 검증 대부분 통과, 밸류에이션 초록불 또는 노란불(설명 첨부 필요)
- ★★★ 논리는 성립하나 일부 검증 대기, 밸류에이션 노란불은 수용 가능(예: 고성장 초기 회사)
- ★★ 초기 신호, 또는 병목 논리는 성립하나 밸류에이션 빨간불(시가총액>TAM 20%, PS>30x이면서 증가율 부족, 시가총액이 5년 전망을 크게 초과 등)
- ★ 순수 콘셉트, 미검증

## 7단계: 기존 항목 갱신——병목 지도의 동적 유지보수

### 7.1 실행할 때마다의 증분 갱신

1. 이미 식별한 병목이 여전히 성립하는지 점검한다
   - 신규 공급업체가 진입했는가?
   - 생산능력이 병목을 해소할 만큼 확장됐는가?
   - 대체 기술에 돌파구가 있었는가?

2. 새로 나타난 병목을 스캔한다
   - 최근 7일의 supply chain / shortage / bottleneck 뉴스를 검색한다
   - 실적 시즌의 공급망 관련 disclosure를 점검한다

3. 병목 등급을 갱신한다(상향/하향/해소)

### 7.2 상태 파일

`reports/bottleneck-map/` 디렉터리에서 유지한다:
- `master-map.md` — 병목 전체 지도(지속 갱신)
- `watchlist.md` — 관찰 목록(지속 갱신)
- `YYYY-MM-DD/` — 하루에 폴더 하나, 그날의 모든 스캔 보고서를 담는다
- `deep-dive/` — 심층 분석한 회사는 파일을 따로 만든다

## 매시간 스캔 모드(예약 작업용)

매시간 한 번 실행하며, "내용이 있을 때만 보고서를 낸다"는 방식을 따른다:

### 스캔 절차(매시간)

1. **뉴스 스캔**: 지난 1-2시간의 공급망 관련 뉴스를 검색한다
   - 키워드: supply chain bottleneck, shortage, capacity constraint, allocation, lead time, sole source, 瓶颈, 缺货, 产能, 涨价
   - 범위: 영어+중국어 출처
2. **시장 신호**: 추적 중인 회사의 주가 변화를 점검한다(특히 >5%의 이상 변동에 주목)
3. **실적/공시**: 병목 관련 회사가 실적이나 중대 공시를 발표했는지 점검한다
4. **밸류에이션 기회**: watchlist의 회사 중 시장 전체 하락 등의 이유로 매수 구간에 들어온 곳이 있는지 점검한다
5. **보고서를 낼지 판단한다**:
   - 새 병목 신호가 있음, 명확한 종목 기회가 있음, 중대한 상태 변화가 있음 → **보고서를 낸다**
   - 새로운 발견 없음 → **보고서를 내지 않고**, 로그에만 "이번 회차 신규 신호 없음"이라고 기록한다

### 보고서 출력 규칙

**하루에 폴더 하나**: `reports/bottleneck-map/YYYY-MM-DD/`

**파일 명명 규칙**(파일명만 보고 종목이 있는지 한눈에 알 수 있게 한다):

| 상황 | 파일명 형식 | 예시 |
|------|-----------|------|
| 명확한 종목 발견 | `HH-MM-종목코드1-종목코드2.md` | `09-00-FORM-IBDN.md` |

## AI 연구 편향 자각

| 편향 | 양상 | 대응 |
|------|-----|------|
| 선두 기업 선호 | 검색 결과가 대형주로 채워진다 | 소형주 공급업체를 의도적으로 검색하고 "small cap" 키워드를 추가한다 |
| 영어 선호 | 일본·한국·대만 회사를 놓친다 | 일본/한국/대만 시장의 공급업체를 반드시 검색한다 |
| 서사 선호 | "AI 콘셉트" 라벨에 끌린다 | 실제 공급망 위치만 보고 시장 라벨은 보지 않는다 |
| 확증 편향 | 병목을 찾은 뒤 긍정적 증거만 찾는다 | 역방향 검증(5단계)을 강제로 수행한다 |
| 시의성 편향 | 낡은 정보에 의존한다 | 최근 30일의 데이터를 우선 검색한다 |

## 핵심 원칙(최고 우선순위)

1. **AI에게 주식을 추천시키지 않고, 공급망을 분해시킨다** — 질문이 답보다 중요하다
2. **물리 우선** — 실제 물리적 제품/소재/장비가 필요한 고리에만 주목한다
3. **2층, 3층** — 이미 충분히 가격에 반영된 선두 기업은 좇지 않는다
4. **교차 검증** — 결론마다 최소 2개의 독립 출처
5. **불확실성을 정직하게 마주한다** — 데이터를 찾지 못하면 "데이터 부족"이라고 쓰고, 추측으로 채우지 않는다
6. **병목에는 유효기간이 있다** — 모든 병목은 해소된다. 핵심은 시간 창을 판단하는 것이다
7. **소형주≠좋은 기회** — 소형주도 형편없는 회사일 수 있으며, 반드시 재무 건전성 관문을 통과해야 한다
8. **병목이 진짜라는 것≠투자 기회** — 회사가 가장 조이는 병목 위에 앉아 있을 수는 있지만, PS>30x이거나 여전히 적자라면 현재 가격은 매수 시점이 아니다. **밸류에이션은 절대 문턱이며, 병목 순도, 신호 강도, 서사의 매력으로 덮을 수 없다.** 오른 병목주 하나를 놓칠지언정, PS 100배에 적자 회사를 사지는 않는다
9. **CLAUDE.md 객관성 원칙을 따른다** — 강세를 전제하지 않고, 데이터가 먼저고 결론은 나중이다
